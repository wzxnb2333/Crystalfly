## 中文

# 三段跳（娇小玩偶）

该模组为《空洞骑士丝之歌》新增一个**黄色工具**，装备后可使用三段跳。

## ✨ 功能

- 装备 **“娇小玩偶”** 后，在空中使用二段跳后可以再次按下跳跃键执行三段跳。
- 与原版移动机制无冲突，不影响冲刺、蹬墙跳等其他动作（下批，登墙不刷新三段跳bug已解决，二段跳冲刺时不能三段跳已解决）。
- 使用三段跳需要拥有二段跳和滑翔（若提前获取装备没这两个技能也不能增加一次跳跃）。
- 获取方式：第三幕触发后，前往费耶山山顶获取二段跳的琴前面，有一个可拾取的光点，拾取即可获得娇小玩偶。

---

## 📥 安装

1. 确保已安装 BepInEx 和 Needleforge  
2. 将本模组文件夹解压至游戏目录下的 `BepInEx\plugins` 文件夹中。

## ⚙️ 配置

模组的参数可由mod文件夹内的 `TripleJump.json` 文件控制。你可以用任意文本编辑器修改其属性。

### 默认配置文件

```json
{
    "Name": "娇小玩偶",
    "Desc": "由天空飘落的羽毛编织的雪灵玩偶,可加强供奉者的能力。\n\n增加一次跳跃能力。",
    "Type": "Yellow",
    "Icon": "TripleJump.png",
    "MapID":"Peak_08b",
    "Position":[281,102],
    "state":"act3_wokeUp"
}
```

### 配置项说明

- `Name`：工具名称，可自定义。
- `Desc`：工具描述，可自定义。
- `Type`：工具类型，红，黄，蓝。
- `Icon`：工具图标，可自定义图标文件名，建议144x144像素左右，或者直接改我的图标（太小会显示一小个图标，太大没尝试，我是直接用的其他工具图标改的）。
- `MapID`：地图ID，在哪个地图生成改工具（Peak_08b为费耶山山顶）。
- `Position`：工具生成的坐标，在地图中的坐标（[281,102]为获取二段跳的琴的位置）。
- `state`：玩家状态，当玩家拥有该状态时才能触发（act3_wokeUp为第三幕开始后）。

## 中文

# 三跳（娇小玩偶）

该模组为《空洞骑士：丝之歌》添加了一种新的**黄色工具**。装备后，你将获得在空中进行**第三次跳跃**的能力。

## ✨ 特性

- 配备「娇小玩偶」后，连续按下跳跃按钮两次，即可执行三连跳。
- 与原版移动系统无冲突——冲刺、墙跳及其他操作均不受影响。  
  *(修复：墙抓不再错误地重置三连跳；修复：在冲刺后的双跳后可正常使用三连跳。)*
- 三连跳需要同时具备「双跳」和「滑翔」能力。（早期获取工具不会额外提供跳跃次数，若缺少上述技能则无效。）
- 获取方式：当进入第 3 关卡时，前往 **法伊山** 的顶端，在提供双跳能力的竖琴正前方会出现一个发光的拾取物品——收集即可获得「娇小玩偶」。

## 📥 安装

1. 确保已安装 **BepInEx** 和 **Needleforge**。
2. 将模组文件夹提取到游戏的 `BepInEx\plugins` 目录中。

## ⚙️ 配置

模组的参数由模组文件夹内的 `TripleJump.json` 文件控制。你可以使用任意文本编辑器对其进行编辑。

### 默认配置文件

```json
{
    "Name": "娇小玩偶",
    "Desc": "由天空飘落的羽毛编织的雪灵玩偶,可加强供奉者的能力。\n\n增加一次跳跃能力。",
    "Type": "Yellow",
    "Icon": "TripleJump.png",
    "MapID":"Peak_08b",
    "Position":[281,102],
    "state":"act3_wokeUp"
}

```


### 配置选项

- `Name`：工具名称，可自定义。
- `Desc`：工具描述，可自定义。
- `Type`：工具类型，红色、黄色或蓝色。
- `Icon`：工具图标，可以是自定义图标文件名，但建议为 144x144 像素或更大，或者你可以替换为我的图标（太小会显示一个小图标，太大我尚未测试）。
- `MapID`：地图 ID，指定工具生成的位置（Peak_08b 是法伊的峰顶）。
- `Position`：工具位置，在地图坐标系中（[281,102] 是赋予双跳能力的竖琴位置）。
- `state`：玩家状态，只有当玩家拥有该状态时才能触发工具（act3_wokeUp 表示第三章开始）。
