# Darkness Mod

restricts the player's field of vision to an extremely close. 

### Manual Installation

1.  Download the file .
2.  Unzip the `.zip` file.
3.  Copy the extracted folder to your game's `BepInEx/plugins` folder.
    * Example: `D:\steam\steamapps\common\Hollow Knight Silksong\BepInEx\plugins\Silksong.Darkness\Darkness.dll`
