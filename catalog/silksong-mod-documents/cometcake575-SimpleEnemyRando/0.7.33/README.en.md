## SimpleEnemyRando

SimpleEnemyRando is a Silksong enemy and boss randomiser, made using the [Architect](https://thunderstore.io/c/hollow-knight-silksong/p/cometcake575/Architect/) level editor.

Not all enemies are currently in the pool, and you may encounter some issues as replacing enemies can cause a lot of unexpected behaviour.

As this mod uses Architect to spawn enemies, more enemies will be added automatically when Architect updates.
