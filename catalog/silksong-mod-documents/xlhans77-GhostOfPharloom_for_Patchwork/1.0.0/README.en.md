Purely cosmetic mod for Hollow Knight: Silksong. Contains spritesheets for Hornet with alt cloak color (dark blue in reference to the Knight's cloak color) + Knight mask.



Ver. 1.0.0

Supports most of the main animations. A few specific animations lack the mask.

Hunter Crest and Wanderer Crest fully supported. For all other Crests recolor of Hornet's cloak only.

Detailed list of features and changelog below.





:: REQUIRED ::

* BepInEx 5
* Patchwork



:: MANUAL INSTALLATION ::

1\. download BepInEx 5, open game folder and place BepInEx at its root, run the game once and let it create the necessary folders.

2\. download Ashiepaws' Patchwork, place Patchwork folder containing Patchwork.dll in BepInEx/plugins, run the game once more and let it create its folders.

3\. place GhostHornet folder inside HollowKnightSilksong/BepInEx/plugins/Patchwork/Spritesheets

4\. enjoy!



:: FEATURES AND CHANGELOG ::



* Ver. 1.0.0

Base version release

Intended for Wanderer Crest playthrough



Features:

\- All idle and movement animations

\- Needolin neutral stance

\- Bellhouse animations

\- Special animations for taking damage and death

\- All attack animations for Hunter Crest (base crest)

\- All attack animations for Wanderer Crest (in reference to Hollow Knight moveset)

\- Recolor only for other crests attack animations



Currently excluded (no mask, recolor only):

\- Map reading animations (might be added in the future)

\- Swim animations (might be added)

\- Tool throw animations (might be added)

\- Needolin special songs (not added in the foreseeable future)

\- Full support for all other crests attack animations (unlikely to be added)
