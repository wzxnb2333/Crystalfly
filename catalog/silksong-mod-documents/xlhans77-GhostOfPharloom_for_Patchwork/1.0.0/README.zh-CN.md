空洞骑士：丝之歌 的纯装饰性模组。包含大黄蜂角色的替代表面（暗蓝色，参考骑士的披风颜色）以及骑士面具。

版本 1.0.0

支持大部分主要动画。少数特定动画缺少面具。

猎人纹章和流浪者纹章完全支持。对于其他所有纹章仅对大黄蜂披风进行上色。

下方为详细功能列表及更新日志。




:: 必需组件 ::

* BepInEx 5
* Patchwork



:: 手动安装步骤 ::

1\. 下载 BepInEx 5，打开游戏文件夹并将 BepInEx 放置在根目录下，运行游戏一次以创建必要的文件夹。

2\. 下载 Ashiepaws 的 Patchwork，将包含 Patchwork.dll 的 Patchwork 文件夹放入 BepInEx/plugins 中，再次运行游戏并让其创建对应文件夹。

3\. 将 GhostHornet 文件夹放置于 HollowKnightSilksong/BepInEx/plugins/Patchwork/Spritesheets 目录下

4\. 开始享受吧！



:: 功能与更新日志 ::


* 版本 1.0.0

基础版本发布

适用于流浪者纹章玩法路径

功能：

\- 所有站立和移动动画  
\- 需要林中立姿态  
\- 贝尔屋动画  
\- 受伤及死亡的特殊动画  
\- 猎人纹章（基础纹章）的所有攻击动画  
\- 流浪者纹章（参考空洞骑士动作设定）的所有攻击动画  
\- 其他纹章攻击动画仅进行上色处理

目前未包含（无面具，仅上色）：

\- 地图阅读动画（未来可能添加）  
\- 游泳动画（未来可能添加）  
\- 工具投掷动画（未来可能添加）  
\- 需要林特殊歌曲（短期内不会添加）  
\- 完全支持所有其他纹章的攻击动画（极不可能添加）
