# 商店中更多消耗品  

本模组为商店菜单添加了更多的消耗品项目，部分物品需要满足特定条件才能解锁。  

| 项目                  | 价格 | 解锁条件                                                  |
| ----                  | ----- | -------------------                                                  |
| 破损的念珠丝          |  50   | 无                                                                 |
| 念珠丝                |  80   | 无                                                                 |
| 念珠项链              |  140   | *在Threadspun Town祈愿*                                          |
| 重型念珠项链          |  240   | 根据NPC而异（详见下表）                                        |
| 淡色念珠项链          |  360   | 根据NPC而异（详见下表）                                        |
| 片段束                |  50   | 无                                                                 |
| 生物碎片              |  90   | 已进入第 2 关卡                                                  |
| 纯净核心              |  140   | 已完成第十二位建筑师的挑战，并获得建筑师之曲                  |
| 大黄蜂雕像            |  200   | *希望之象征*祈愿 或 访问被摧毁的Bone Bottom（在第 3 关卡中） |

*\*浅纹珠项链要求同时满足其解锁条件和重纹珠项链的解锁条件。*

此外，弗雷仍保留原版设定，即在商店出售念珠或贝壳碎片补给前必须完成 *我的失联快递员* 希望；摩尔塔则在商店出售贝壳碎片补给前必须完成 *朝圣者休息包* 希望。

仅使用本模组时，无法看到对褐斑斯卡商店的任何变化，因为他会在你解锁其他贝壳碎片补给之前死亡。他被包含进来是为了应对可能有人制作出类似 [Immortal Architect](https://thunderstore.io/c/hollow-knight-silksong/p/OrderOfTheGoons/Immortal_Architect/) 的模组，以及为了保持一致性。他的商店功能正常，我已使用 Unity 探索者进行过测试。

每项商品的售价，以及是否能在商店中找到，均可在配置设置中更改。
