## 手动安装

1. [Install BepInEx](https://docs.bepinex.dev/articles/user_guide/installation/index.html#installing-bepinex-1)  
2. 如果在 Steam 上运行于 [*nix](https://en.wikipedia.org/wiki/Unix-like) 系统，需 [set up launch options](https://docs.bepinex.dev/articles/advanced/steam_interop.html#2-set-up-permissions)  
3. 从 [GitHub releases](https://github.com/Bergbok/Silksong-Mods/releases?q=Guts) 或 [Thunderstore](https://thunderstore.io/c/hollow-knight-silksong/p/Bergbok/Guts) 下载模组  
4. 将下载的归档文件解压至 `silksong_path/BepInEx/plugins`  
5. 启动游戏  
6. 使用 BepInEx 的配置管理器（默认 F1 键）进行 [Edit mod configs](https://docs.bepinex.dev/articles/user_guide/configuration.html#configuring-plugins)，或直接编辑 `silksong_path/BepInEx/plugins` 中的文件  

请考虑给它 [on GitHub](https://github.com/Bergbok/Silksong-Mods) 一个星标！
