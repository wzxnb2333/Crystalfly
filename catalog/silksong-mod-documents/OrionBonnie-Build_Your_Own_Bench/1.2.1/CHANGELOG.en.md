**Version 1.2.1**

- Add a function to rename a mod bench in UI as well as a config option to enable rename prompting after building a bench

**Version 1.2.0**

- In-game Manager UI added, you can now use the UI to delete a modded. Press F2 by default to open it during gameplay
- Teleport config entry added, this will add a modded bench teleportation option in UI
- Linux supported

**Version 1.1.1**

- Fix an issue where the game refuse to load if you sit on a modded bench in one specific scene Weave_07.
- Add custom bench sprite. You can now create your own bench sprite for modded bench. Destroyed bench now also has its own sprite instead of becoming a phantom
- Add a panic button to allow player to force reload a scene if this mod cause a black screen when respawn.

**Version 1.1.0**

- Add a modded bench pin manager into the mod. When a modded bench is created, a modded pin will also be placed on the map.
- Change the way to tackle the bench removal issue. Instead of resetting player respawn point to the original starting place, the destroyed bench will now turn into a bench phantom, which serves as a temporary respawn point and disappear when you sit on another bench.
- Optimize logic to prevent certain error from occurring
