# HP 闪烁颜色模组

敌人受到攻击时，其闪烁颜色会根据剩余生命值百分比发生变化。

## 🎮 使用方法

**生命值渐变效果**：当敌人受到伤害时，其击中闪光颜色会从初始颜色（满血状态）过渡到目标颜色（低血量状态），为玩家提供敌方生命值状态的视觉反馈。

> 默认设置：白色（255,255,255）→ 红色（255,0,0）<br>  
> 两种颜色均可通过 BepInEx 配置文件进行自定义配置。

**调试模式**：启用详细日志记录，以监控颜色计算和生命值追踪过程。

## 配置

编辑 `BepInEx/config/Mhz.hpflashcolor.cfg`：

- `InitialColor`：全血量时的 RGB 值（默认：“255,255,255”为白色）
- `TargetColor`：低血量时的 RGB 值（默认：“255,0,0”为红色）
- `EnableDebugLog`：调试日志记录（默认：false）

## 安装

1. 安装 BepInEx  
2. 将 `HPFlashColor.dll` 放入 `BepInEx/plugins/` 文件夹  
3. 启动游戏

# 血量闪烁颜色MOD

根据敌人剩余血量百分比改变受击闪烁颜色。

## 🎮 使用说明

**血量渐变效果**：敌人受到攻击时，闪烁颜色从初始颜色（满血）渐变到目标颜色（低血量），提供敌人血量的视觉反馈。

> 默认：白色 (255,255,255) → 红色 (255,0,0)<br>  
> 两种颜色均可通过BepInEx配置文件自定义。

**调试模式**：启用详细日志记录，监控颜色计算和血量追踪过程。

## 配置设置

编辑 `BepInEx/config/Mhz.hpflashcolor.cfg`：

- `InitialColor`：满血时RGB颜色值（默认："255,255,255" 白色）
- `TargetColor`：低血量时RGB颜色值（默认："255,0,0" 红色）
- `EnableDebugLog`：调试日志（默认：false）

## 安装方法

1. 安装 BepInEx
2. 将 `HPFlashColor.dll` 放入 `BepInEx/plugins/` 文件夹
3. 启动游戏
