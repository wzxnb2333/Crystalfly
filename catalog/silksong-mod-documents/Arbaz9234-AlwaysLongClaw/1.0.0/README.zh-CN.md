# Always Longclaw

## 概述

**Always Longclaw** 是为 _空洞骑士：丝之歌_ 制作的模组，可使你的工具始终拥有 **长爪效果**，而无需装备长爪工具。

这让你在任何时候都能享受更远的攻击范围，同时保留工具槽位用于其他工具。

## 特性

- 永久施加 **长爪效果**
- 无需装备长爪工具
- 解放一个工具槽位，供其他工具使用
- 可配置范围缩放（正常 / 1.5x / 2x），以增强 LongClaw 效果。

## 安装

1. 安装 **Hollow Knight: 丝之歌** 的 BepInEx
2. 将模组文件解压至 BepInEx/plugins/ 目录
3. 启动游戏

## 兼容性

- 需要 **BepInEx**
