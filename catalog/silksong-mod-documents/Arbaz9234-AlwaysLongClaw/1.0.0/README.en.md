# Always Longclaw

## Overview

**Always Longclaw** is a mod for _Hollow Knight: Silksong_ that makes the **Longclaw effect permanent** on your tools without needing to equip the Longclaw tool.

This lets you enjoy increased attack range at all times while keeping your tool slots free for other tools.

---

## Features

- Permanently applies the **Longclaw effect**
- No need to equip the Longclaw tool
- Frees up a tool slot for other tools
- Configurable range scaling (Normal / 1.5x / 2x) to have increased LongClaw effect.

---

## Installation

1. Install **BepInEx for Hollow Knight: Silksong**
2. Extract the mod files into BepInEx/plugins/
3. Launch the game

## Compatibility

- Requires **BepInEx**
