# 快速传送

为丝之歌制作的一个基础场景传送菜单，用于与 [DebugMod](<https://github.com/hk-speedrunning/Silksong.DebugMod>) 一起使用。

用法：按 F5 键，选择一个地图区域，然后选择场景，再进行传送。你可能需要暂停游戏，以便鼠标可以与菜单交互。

配置：打开 `<game files>/BepInEx/config/io.github.hk-speedrunning.quickwarp.cfg` 并修改 `Toggle Quickwarp Menu` 设置。

安装方法：参见 [Latest Release](<https://github.com/hk-speedrunning/Silksong.QuickWarp/releases/latest>)。
