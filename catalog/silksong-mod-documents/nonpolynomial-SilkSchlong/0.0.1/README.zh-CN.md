# 丝之歌 - Buttplug.io 模组 for SilkSong

Day 1 丝之歌 后缀模组！

... 这大概和你预期中一个我只花了一小时制作的 Day 1 模组的效果相当。

## 特性

- 治疗成功时震动  
- 添加丝线时震动（i.e. 对敌人造成伤害）

想要更多功能？请提交问题！添加新功能应该相当简单，同时也可以支持其他玩具，例如刺激器。

如果知道如何在 Steam Deck 上加载 BepInEx 模组，该模组应在 Windows x64 或 Linux/Steam Deck 上正常运行。

## 如何使用

1. 安装 BepInEx 5，可以从 [Github](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.3)（下载适用于您操作系统的版本，很可能是 win_x64，然后将其放入您的丝之歌游戏目录中，很可能位于 `C:\Program Files (x86)\Steam\steamapps\common\Hollow Knight Silksong`）或 [Thunderstore](https://thunderstore.io/c/hollow-knight-silksong/p/BepInEx/BepInExPack_Silksong/) 获取  
2. 启动游戏  
3. 退出游戏  
4. 从我们的发布页面下载最新 zip 文件  
5. 解压到 `C:\Program Files (x86)\Steam\steamapps\common\Hollow Knight Silksong\BepInEx\plugins\`  
6. 安装 [Intiface Central](https://intiface.com/central)  
7. 启动丝之歌，确保 Intiface Central 显示“Silkschlong Connected”消息  
8. 开始游戏！

## 如何编译

只要您已将 Silksong 安装在默认位置（`C:\Program Files (x86)\Steam\steamapps\common\Hollow Knight Silksong`），并且已经安装了 BepInEx，该操作就应“直接成功”。需要注意的是，`Buttplug.dll` 依赖项可能需要手动复制，因为目前我仍在研究 Rider 如何处理依赖项和模组。
