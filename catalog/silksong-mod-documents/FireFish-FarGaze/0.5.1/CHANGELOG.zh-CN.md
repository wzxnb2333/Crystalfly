# Changelog

## 0.5.1

- 将控制器预设轮播替换为直接按钮捕获：选择控制器行，然后按下所需按钮。
- 增加了对玩家当前游戏绑定的实时冲突验证，适用于键盘和控制器。
- 与现有操作冲突的候选选项将被拒绝，且不会覆盖原有的远视（Far Gaze）绑定，包括游戏本身的挑衅/挑战动作。
- 在游戏中持续检查冲突，因此即使后续在游戏自身控制菜单中更改设置，也不会导致远视与其他操作同时触发。
- 简化了设置页面为三个功能行；仅当存在绑定冲突时才会显示解释性文字。
- 控制器行现在会显示断开连接状态或已连接控制器家族的按钮图标，并直接捕获下一个物理按键。
- 控制器绑定按检测到的控制器家族独立存储；每个新出现的家族默认使用左摇杆点击。
- 统一了键盘/控制器行的字体样式，并将模式名称缩短为“点按”和“长按”。

## 0.5.0

- 在“选项”→“模组”中新增了一个原生风格的“远眺”设置页面，由 Silksong.ModMenu 驱动 0.7.6。
- 增加了实时键盘重新绑定功能；默认按键仍为 B。
- 增加了支持跨平台控制器绑定的功能，适用于 PS4/PS5、Xbox 和任天堂手柄布局，并提供未绑定选项。
- 默认的控制器绑定是此前未使用的左摇杆点击：PlayStation 上为 L3，Xbox 上为 LS，任天堂手柄上为左摇杆点击。
- 增加了“按下模式”（上升沿切换）和“保持模式”（在组合键盘/控制器信号持续高电平时激活）。
- 键盘与控制器绑定可同时生效，更改内容通过现有的 BepInEx 配置保存。

## 0.4.0

- 将垂直摄像机视角与远距离注视方向正交：向上/向下和右摇杆的垂直输入在持续移动摄像机的同时，大黄蜂仍保持面向背景的姿势。
- 使用游戏重新映射的输入动作、原生 0.85 秒键盘/控制器转向延迟、即时右摇杆行为以及房间视角限制。
- 将摄像机标志与视角动画标志分离，以确保 `TurnToBG` / `Idle BG` 始终保持视觉优先级。
- 在已处于垂直视角时进入远距离注视状态，会保留原有的上下摄像机位置。

## 0.3.0

- 在启用远距离注视时，渲染当前视口高度处的远景背景，分辨率默认限制在 2160p。
- 调整模糊采样半径以适应更高分辨率纹理，确保过渡仍从大约原始模糊强度开始。
- 保持高分辨率纹理直到模糊恢复完成，之后返回游戏原有的分辨率和内存使用。
- 通过信任权威的 `onGround + idle + zero movement` 状态而非临时的空中与方向子标志，减少了 false 输入被拒绝的情况。
- 每次被拒绝的 B 键按下操作，现在都会将其具体原因、当前动画以及相关状态记录到日志中。

## 0.2.0

- 修复了动画所有权问题：模组现在会在使用 `PlayClipForced` 前停止游戏的自动动画控制器，然后通过匹配的版本令牌恢复控制。
- 将无效的 `LightBlur.blurSize` 假设替换为一个 Harmony 补丁，该补丁会持续缩放游戏的 `_BlurInfo` 采样偏移量。
- 检测到 `LightBlurredBackground` 实际在运行时使用的 `LightBlur` 和 `BlurPlane` 对象。
- 通过动画控制状态、当前剪辑、模糊通道数量和模糊程度提升了 F8 调试信息。
- 直接基于已安装的游戏程序集构建（Steam 版本 22479045）。

## 0.1.0-预览

- 首个可离线构建的原型版本。
- 增加了 B 键上升沿触发，并带有严格站立状态门控。
- 增加了 `TurnToBG` / `Idle BG` / `TurnToFG` 动画流程及中断退出功能。
- 增加了平滑的摄像机模糊程度以及 BlurPlane 的备用过渡效果。
- 增加了 F8 运行时诊断功能以及场景/卸载恢复保护机制。
