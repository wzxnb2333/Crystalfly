# Karmelita Prime

对空洞骑士：丝之歌中的斯卡里辛·卡梅利塔进行重制，使其变得异常困难且更具攻击性。专为喜欢卡梅利塔挑战性的玩家设计。<br>

# 安装

该模组可通过 Thunderstore 的模组管理器下载，或者手动安装：

1. 从 https://github.com/BepInEx/BepInEx/releases 下载 BepInEx 的最新稳定版本；
2. 将 BepInEx 提取到游戏的根目录（即包含 空洞骑士 Silksong.exe 的文件夹）；
3. 启动游戏以生成 BepInEx 所需的文件和文件夹；
4. 将 dll 文件放入 BepInEx/plugins 文件夹中。

# 通用变更

- 战斗前的敌对竞技场完全被跳过。
- 当卡尔梅莉塔不攻击时，其接触伤害已关闭。
- 钉子碰撞现在会生成丝线，并对首领造成伤害（包括对射出的弹幕）。
- 她的角色图像进行了完整重绘。
- 名称变更及多语言翻译。

<strong>WARNING:</strong> 其他非葡萄牙语和英语的语言翻译由AI完成，更多详情请参见报bug部分。
