# 被破坏的巨蜂

在恶瘴湖中添加第三场野性巨蜂战斗。

*Nexus Mods：*
https://www.nexusmods.com/hollowknightsilksong/mods/536

*Thunderstore：*
https://thunderstore.io/c/hollow-knight-silksong/p/JngoCreates/MuckedBeastfly/

*GitHub 发布版：*
https://github.com/jngo102/Silksong.MuckedBeastfly/releases/latest

## 安装说明

### Thunderstore

1. [Install the r2modman mod manager.](https://github.com/ebkr/r2modmanPlus/releases/latest)
2. 通过选择《空洞骑士：丝之歌》作为你的游戏来设置模组管理器，然后创建一个新的配置文件。
3. 在应用程序左侧的「模组」部分，选择「在线」并搜索 `MuckedBeastfly`。
4. 打开模组链接，点击 *下载*，然后在弹出的窗口中点击 *下载并包含依赖项*。
5. 点击应用程序左上角的「启动模组」按钮以启动并游玩模组游戏！

### 手动下载

1. [Download and install BepInEx](https://docs.bepinex.dev/articles/user_guide/installation/index.html)
2. 确保游戏已运行至少一次，以便在 `BepInEx` 文件夹中生成一个 `plugins` 文件夹
游戏可执行文件。
3. 从上述列出的任一来源下载 .zip 文件。
4. 将.zip文件解压到生成的 `plugins` 文件夹中。
5. 启动游戏并享受吧！
