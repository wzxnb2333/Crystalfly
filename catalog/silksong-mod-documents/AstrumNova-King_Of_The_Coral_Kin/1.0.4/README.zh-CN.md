# 珊瑚族之王  
甲壳王卡恩正得到他应得的加成

# 安装  
压缩包包含 KingOfTheCoralKin.dll，将其放置在 BepInEx/plugins/（此处）。  
该模组需要 FSMUtils 才能正常运行，否则将无法加载，您可以在 thunderstore 找到它  
- https://thunderstore.io/c/hollow-knight-silksong/p/silksong_modding/Silksong_FsmUtil

# 首领战  
- 战斗通常更快，空闲时间更短，恢复时间更少  
- 大多数模式通过在不同位置添加尖刺来增强，使战斗更具挑战性  
- 三个阶段，每个阶段都有独特的变化和模式  
- 设计难度与 act 3 心脏首领相当，不是普通空洞骑士模组首领的平均水平

# 配置
- 禁用接触伤害（默认开启）
- 开启首次使用丝线飞行时直接传送至首领（默认开启）
