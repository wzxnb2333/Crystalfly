# Rosaries And Shell Stay Safe from Spikes

## Description
This mod ensures that all Shell Shards and Rosaries, including all variants, are safe from spikes. Collectibles will no longer be lost when touching spikes, allowing smoother exploration and collection.

Thanks to Magnetite Brooch, you can now pull Rosaries out of spikes, and with other compatible mods, you can retrieve Shell Shards that would otherwise be unreachable.

## Compatibility
- Fully compatible with other mods that interact with collectibles.
- Works with all shard sizes: Small, Medium, Big.
- Does not interfere with enemies, environmental objects, or core gameplay mechanics.

## Notes
- Quality of life mod type.
- No configuration needed.
- Version 1.1.0

## Installation
1. Ensure BepInEx is installed for Silksong.
2. Place `KeepShellShardsAndRosariesSafe.dll` into the following folder:  
\Hollow Knight Silksong\BepInEx\plugins
3. Launch the game. The mod works automatically with no configuration required.
