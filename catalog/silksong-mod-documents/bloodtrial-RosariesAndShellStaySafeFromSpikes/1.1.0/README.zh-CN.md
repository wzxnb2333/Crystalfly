# Rosaries And Shell Stay Safe from Spikes

## 描述  
本模组确保所有贝壳碎片和念珠（包括所有变体）不会被尖刺伤害。触碰尖刺时，收集品将不再丢失，从而实现更流畅的探索与收集。

得益于纹章磁石，你现在可以将念珠从尖刺中拉出，配合其他兼容模组，还可获取原本无法触及的贝壳碎片。

## 兼容性  
- 与其他与收集品交互的模组完全兼容。  
- 支持所有碎片大小：小、中、大。  
- 不会干扰敌人、环境物体或核心游戏机制。

## 注意事项  
- 便捷性模组类型。  
- 无需配置。  
- 版本 1.1.0

## 安装  
1. 确保已为丝之歌安装 BepInEx。  
2. 将 `KeepShellShardsAndRosariesSafe.dll` 放入以下文件夹：  
\空洞骑士 丝之歌\BepInEx\plugins  
3. 启动游戏。该模组会自动生效，无需任何配置。
