# 所有纹章的必中效果

无论使用哪种纹章，均触发必中效果！

## 特性

- **暴击伤害**：暴击时造成 3x 点伤害  
- **可配置概率**：自定义暴击概率（默认值：2%）  
- **通用兼容性**：适用于所有纹章，不仅限于流浪者纹章  
- **与流浪者纹章的协同效果**：你仍可以使用流浪者纹章，并拥有 100% 的暴击概率。  
  - _提示：使用 LongClaw 可以弥补流浪者纹章攻击范围较短的问题_
