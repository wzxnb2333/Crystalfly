# Critical Hit for All Crests

Deal critical hits regardless of which crest you're using!

## Features

- **Critical Hit Damage**: Deal 3x damage with a critical hit
- **Configurable Chances**: Customize your critical hit probability (Default: 2%)
- **Universal Compatibility**: Works with all crests, not just the Wanderer
- **Wanderer Synergy**: You can still play with the Wanderer crest and have 100% chance of a critical hit.
  - _Tip: Use LongClaw to compensate for the Wanderer crest's short attack range_

## v2.1.0

- Fixed crits triggering without a full silk bind
- Crit eligibility now correctly requires ≥ 9 silk

## Compatibility

- **Requires**: BepInEx

## Configuration

After running the game once with the mod installed, you can adjust settings in the config file to customize:

- Base critical hit chance
