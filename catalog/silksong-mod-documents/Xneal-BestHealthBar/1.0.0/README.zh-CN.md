

# HealthBar 模组 for 丝之歌

该模组可通过在屏幕顶部创建一个简单的条形显示，让你看到首领和敌人的生命值。

此外，还提供了一些快捷键。通过这些快捷键，你可以调整生命值条的布局大小以及其在屏幕上的位置。

快捷键：
按住 Ctrl + ↑ 可将整个首领生命值条向上移动 0.1 像素。
按住 Ctrl + ↓ 可将整个首领生命值条向下移动 0.1 像素。
按住 Ctrl + ← 可将首领生命值条向左移动 0.1 像素。
按住 Ctrl + → 可将整个首领生命值条向右移动 0.1 像素。
按住 Ctrl + 数字键盘 + 可将首领生命值条的缩放比例增加 0.1（不推荐）。
按住 Ctrl + 数字键盘 - 可将整个首领生命值条的缩放比例减少 0.1（不推荐）。
按住 Ctrl + 非数字键盘 + 可将首领生命值条的水平长度增加 0.1。
按住 Ctrl + 非数字键盘 - 可将首领生命值条的水平长度减少 0.1。
按住 Ctrl + [ 可将首领生命值条的垂直宽度增加 0.1。
按住 Ctrl + ] 可将首领生命值条的垂直宽度减少 0.1。
每次调整后，生命值条的位置都会实时刷新。
对普通敌人的调整同样适用，但需按 Alt 而非 Ctrl。
Ctrl + 数字键盘 5：重置首领生命值条。
Ctrl + 数字键盘 6：重置普通敌人生命值条。
