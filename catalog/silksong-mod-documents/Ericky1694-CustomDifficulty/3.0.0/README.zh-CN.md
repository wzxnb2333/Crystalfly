# 自定义难度

专为 **空洞骑士：丝之歌** 制作的难度自定义模组。

- **版本:** `3.0.0`
- **作者:** `Ericky1694`
- **模组菜单:** `F8`
- **依赖项:** BepInEx 5 用于丝之歌

Custom Difficulty 可实时调整主线任务的难度，独立设置大黄蜂、敌人和首领，使用特殊变体，并将完整组合保存至预设文件中。

## 主要功能

- 实时生效的设置。
- 每个选项均可独立开启或关闭。
- 值可通过 `−` 和 `+` 键位或直接输入修改。
- 支持单列或双列的响应式界面。
- 可视化显示角色难度、分数和风格概览。
- 支持收藏夹功能，可快速访问已选择的选项。
- 内置预设及支持无限数量的文件预设。
- 一次仅允许一个预设处于激活状态。
- 难度可视化的模组系统。
- 根据游戏使用的语言自动识别界面语言。
- 全局恢复功能，包含确认提示和变更计数器。
- 设置、收藏夹、语言及预设状态均保存为 JSON 文件。

## 界面控制

| 控制 | 动作 |
| --- | --- |
| `F8` | 打开或关闭菜单 |
| `Esc` | 关闭菜单或取消确认 |
| `Q` / `E` | 在分类间导航 |
| `Page Up` / `Page Down` | 通过替代方式在分类间导航 |
| `Ctrl + F` | 聚焦到分类搜索框 |
| `F` | 将光标下的选项添加或移出收藏夹 |
| `Enter` | 确认已输入的值 |

当字段失去焦点、切换分类或关闭菜单时，也会进行字段验证。

## 类别

### 概览

当前配置文件的仪表盘，包含：

- 难度评级。
- 预估分数。
- 主导风格。
- 激活的模组数量。
- 生存、伤害、机动性、敌人、首领和治疗等各项指标。

### 喜欢的配置

显示所有标记为星标的配置快捷入口。卡片保留相同的控制选项，并标明原始类别。恢复配置时，喜欢的配置会保持不变，且可作为用户保存的预设的一部分。

### 玩家

- **最大生命值：** 从 1 到 20 面具。
- **受到的伤害：** 从 1 到 20。
- **环境伤害：** 从 1 到 20。
- **单击击杀模式：** 任何受到的伤害都会移除全部正常和蓝色生命值。
- **治疗数量：** 每次 Bind 可恢复 1 到 20 面具。
- **治疗消耗成本：** 每次治疗消耗 1 到 18 单位丝线。
- **无敌时间：** 从 `0,1x` 到 `20,0x`。

### 伤害与工具

- **针的基准伤害：** 从 1 到 100。
- **每次升级提升的伤害增幅：** 每获得一次升级，伤害增加 0% 至 100%。
- 各种丝线技能的个体消耗成本，从 1 到 18，适用于六种丝线技能。
- 各丝线技能的伤害倍率。
- 丝线长矛的特定配置，其默认伤害为 `3x`，默认消耗成本为 4。
- 包含各自图标的一览图，展示白色、红色、蓝色和黄色工具。

可使用的丝线技能：

1. 丝线长矛。
2. 丝线漩涡。
3. 十字点。
4. 锐利箭矢。
5. 环纹狂怒。
6. 淡色尖刺。

### 敌人

- **普通敌人的生命值：** 从 `0,1x` 到 `20,0x`。
- **普通敌人的移动速度：** 从 `0,1x` 到 `1,1x`。
- **攻击间隔时间：** 从 `0,1x` 到 `20,0x`。
- **攻击性与侦测范围：** 从 `0,1x` 到 `20,0x`。

首领敌人不采用“敌人”类别的配置；它们使用专属类别。

### 首领

- **首领的生命值：** 从 `0,1x` 到 `20,0x`。
- **受到的首领伤害：** 从 `0,1x` 到 `20,0x`。
- **首领的移动速度：** 从 `0,1x` 到 `1,1x`。
- **首领攻击间隔时间：** 从 `0,1x` 到 `2,0x`。
- **首领暴击模式：** 每次首领攻击有 10% 的概率造成额外 1 面具伤害，且战斗期间治疗会恢复 1 面具的减少量。
- **首领无治疗模式：** Bind 可消耗丝线，但战斗中不会恢复生命值。
- **首领期间的治疗：** 仅乘以战斗中获得的生命值恢复量。

### 敌人编辑器

用于对已分类的敌人和首领进行独立编辑的区域。该区域显示的选项在个体实现未完成时将被锁定。

### 奖励

- 收集硬币所获得的念珠倍率：从 `0,1x` 到 `20,0x`。
- 收集碎片所获得的奖励倍率：从 `0,1x` 到 `20,0x`。

### 经济系统

- 商店价格：从 `0,1x` 到 `10,0x`。
- 银行及 Bellway 站点价格：从 `0,1x` 到 `10,0x`。
- 死亡时失去的念珠比例：从 0% 到 200%。

超过 100% 的数值可能导致念珠余额变为负数。当余额低于所需价格时，无法完成任何购买操作。在复活时，会返还死亡前存在的最大正余额。

### 移动

- 大黄蜂的步行与冲刺速度：从 `0,1x` 到 `2,0x`。
- 跳跃蓄力时间：等级为 1 至 20。

等级 1 保持正常行为。等级 2 设置一个 0,1 秒的等待时间，后续每级均将此时间翻倍。

## 模组

模组是应用于常规设置的特殊规则：

| 模组 | 主要效果 |
| --- | --- |
| 无治疗 | 整个战役期间移除治疗能力 |
| 低重力 | 保持大黄蜂的重力为 `0,5x` |
| 双倍伤害 | 敌人和场景造成双倍伤害；大黄蜂的伤害不变 |
| 玻璃炮 | 生命值最大值为 1，针刺伤害为 30，面具碎片可获得 1.000 念珠 |
| 敌人快速移动 | 敌人的速度，包括首领，提升至 `1,1x` |
| 防御型敌人 | 所有敌人的生命值乘以 `3x` |
| 攻击性敌人 | 伤害提升至 `2x`，速度提升至 `1,1x` |
| 敌人生命随机 | 敌人生命值在 `0,1x` 到 `5,0x` 之间随机生成 |
| 富裕世界 | 钱币念珠乘以 `30x` |
| 贫乏世界 | 提供一半的金币念珠 |
| 商店昂贵 | 商店、银行和车站的价格乘以 `10x` |
| 死亡无损失 | 保留念珠，且不生成茧 |
| 首领狂暴 | 首领造成 `2x` 伤害，并以 `1,1x` 的速度移动 |
| 无情模式 | 消耗所有念珠，不生成茧，直接返回游戏开始 |
| 战斗持久化 | 首领造成 1 面具伤害，并拥有 `10x` 更多生命值 |

## 预设

### 模组内包含的预设

- 极简单。
- 简单。
- 正常。
- 困难。
- 非常困难。
- 恐怖模式。
- 农场模式。

每个预设都可以开启或关闭。当另一个预设被激活时，前一个预设会自动关闭。当关闭当前激活的预设时，模组将恢复激活之前的状态。

### 你的预设

- **保存文件**：创建一个包含所有类别当前设置的 JSON 文件。
- **加载文件**：将选定的预设添加到界面列表中，但不会自动激活。
- **从标签页移除**：移除界面中的快捷方式，但保留该预设的 JSON 文件在预设文件夹内。
- 列表没有人为设定的数量限制。
- 兼容的旧版预设在加载时会转换为当前格式。

预设文件位于：

`BepInEx/plugins/CustomDifficulty/Presets`

可用的语言：

- 英语。
- 法语。
- 德语。
- 西班牙语。
- 意大利语。
- 巴西葡萄牙语。

翻译文件位于：

`BepInEx/plugins/CustomDifficulty/Localization`

## 配置文件

主要设置：

`BepInEx/config/CustomDifficulty/settings.json`

## 手动安装

1. 安装与空洞骑士：丝之歌兼容的 BepInEx 5。
2. 解压包 `CustomDifficulty-3.0.0.zip`。
3. 将解压出的文件夹 `BepInEx` 复制到游戏主目录中。
4. 确认存在以下文件：

   `BepInEx/plugins/CustomDifficulty/CustomDifficulty.dll`

5. 启动游戏并按 `F8` 打开菜单。

## 兼容性

该模组使用 Harmony 以及运行时控制器来修改：

- 大黄蜂的生命值和伤害。
- 缚丝的治疗、丝线消耗及无敌状态。
- 缚丝技能的伤害与丝线消耗。
- 敌人的生命值、移动速度、攻击冷却时间及感知值。
- 首领的特殊规则。
- 念珠的奖励、价格及丢失机制。
- 跳跃移动和冲刺的移动速度与冷却时间。
- 变异器的特殊规则。

若其他模组修改了游戏中的相同方法或数据，可能会导致冲突。在组合大量模组修改前，请备份配置文件和预设设置。

## 界面与分辨率

界面已准备如下：

- `1280 × 720`：一列卡片布局。
- `1600 × 900`：当空间充足时，采用两列布局。
- `1920 × 1080`：在两列布局中使用更宽的卡片。

长文本会使用省略号，并在提示框中完整显示内容。系统选项卡会展示所选语言的预览效果。

## 恢复

- 单项重置按钮仅影响所选的配置。
- 类别重置仅影响当前类别。
- **恢复全部** 需要确认，并显示将被恢复的变更数量。
- 喜好项和预设文件在全局恢复时会被保留。

## 版本管理

该项目采用以下格式：

`MAIOR.MENOR.CORREÇÃO`

- 第一个数字：重大更新。
- 第二个数字：小规模更新。
- 第三个数字：错误修复。

该次重大更新的全部开发工作均保留在版本 `3.0.0` 中，直至正式发布。
