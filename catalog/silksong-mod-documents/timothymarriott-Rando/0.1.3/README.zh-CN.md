# 丝之歌-随机化

一个专为《空洞骑士：丝之歌》设计的随机化模组。  
这是一个非常早期的项目，不要期待完美的体验，且许多功能尚未完善。

当前逻辑应确保你可以获得织女女王结局。

## 如何使用  
1. 从发布版本页面或 Thunderstore 安装模组。  
2. 启动游戏，并在游戏模式选项中选择“随机化”。  
3. 检查项将被随机化。

## 快捷键
`F11 + Y`加载每个房间并搜索检查点。找到的检查点将保存到存档文件夹中`rando/locations.json`本文件遵循与……相同的格式`Resources/locations.json`.

`F11 + B`将每个已加载包内的名称和资源写入存档文件夹中`rando/bundles.json`.

`F11 + S` 加载每个房间并将它们的尺寸写入到 `rando/scenes.json` 中。这用于在地图上添加图标。

`F11 + R` 使用新的种子重新随机化一切，**这是一个面向开发者的调试功能，使用此功能会导致游戏异常**。

`F11 + c`切换在左下角打印场景调试信息。

`T`循环地图模式，参见[map modes](#map-modes)下方。

## 地图模式  
在地图界面中，按 `T` 可切换地图模式。  
 - **无地图**\  
    使用原版地图，不显示新图标。  
 - **检查地图**\  
    显示每个随机化检查的位置及其对应的原版物品。  
 - **开发者地图**\  
    主要用于逻辑开发，详情请参见 `LogicFile.cs` 中的颜色说明。  
 - **剧透地图**\  
    显示所有随机化检查及其被替换的物品。
