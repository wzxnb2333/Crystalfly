# CorruptedHealth

**🎮🕹️👾**

**通过这个依赖生命值的游戏速度模组，挑战你的极限并考验自己！**

- 大黄蜂的生命值决定游戏速度。
- 在生命值满时，游戏速度会高于原版。
- 可以单独使用该模组，也可以与其他模组搭配使用。
- 展示 [YouTube](https://www.youtube.com/shorts/gmckPxWEKio) 视频。如果可以，请点赞。
