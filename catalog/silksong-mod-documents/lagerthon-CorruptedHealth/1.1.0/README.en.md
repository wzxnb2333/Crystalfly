# CorruptedHealth

**🎮🕹️👾**

**Push your limits and challenge yourself with this health dependent game-speed mod!**

- Hornet's health decides the game speed.
- Speed is higher than vanilla game speed at full health.
- Use the mod in a standalone gameplay or pair it with other mods​.
- Showcase [YouTube](https://www.youtube.com/shorts/gmckPxWEKio) video. Hit a like if you can.
