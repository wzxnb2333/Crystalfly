# 工具返还

工具返还会在你死亡时恢复已消耗的工具。

## 安装

本模组需要  
[BepInEx 5](https://thunderstore.io/c/hollow-knight-silksong/p/BepInEx/BepInExPack_Silksong)，并安装至你的 `BepInEx/plugins` 目录。  
可使用 [配置管理器](https://thunderstore.io/c/hollow-knight-silksong/p/Yukikaco/BepinExConfigurationManager)) 与本模组配合使用。

## 使用方法

一旦安装了此模组，默认情况下，使用工具后死亡将恢复自上次休息或自动存档以来所使用的全部工具。

可以通过编辑其配置文件位于 `BepInEx/config/Esper89.ToolRefund.cfg` 处，或通过配置管理器在 `[General]` 部分中设置 `Enabled = false` 来禁用此模组。
