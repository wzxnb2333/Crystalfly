# OriSkinForHornet
Replace Hornet's appearance with a little white spirit.

## Prerequisites
* silksong_modding-BepInExPack_Silksong-1.0.3
* SilksongSkinCreators-Stitchwork-0.8.6
* Tested on Hollow Knight: Silksong version 1.0.30000.

## Features
* Replacement of Hornet's textures when players use the Hunter, Reaper, Wanderer, Beast , or Architect crests.
* Replacement of certain icon textures that feature Hornet.
* Replacement of some in-game sound effects (SFX).
* Replacement of some in-game text for simplified Chinese only.

## Unmodified Content
* Video cutscenes
* The remaining crests and cloakless Hornet (in the Slab sequence)
* Some tools

## Installation Instructions
1. Install **[BepInEx](https://thunderstore.io/c/hollow-knight-silksong/p/silksong_modding/BepInExPack_Silksong/)** first, then the prerequisite mod **[Stitchwork](https://thunderstore.io/c/hollow-knight-silksong/p/SilksongSkinCreators/Stitchwork)**. Please refer to Stitchwork's mod page and its wiki for installation instructions.
2. Place the **`Dalias_ORI_Main_1.1.X`** folder, along with all other folders in the same extracted directory, into the game's root directory:  
   `Hollow Knight Silksong\BepInEx\plugins`
3. After reaching the game's main menu, press the **`1`** key on your keyboard to open the skin pack manager.
4. Use the up/down arrow buttons to the left of the entries to ensure **`Dalias_ORI_Main_1.1.X`** is placed at the very bottom of all packs.
5. In the list of packs, toggle the switch to the right of each pack entry to the **`ON`** position, then click the **`Apply`** button in the bottom-right corner.

Alternatively, use the mod installers (thunderstore/Gale/r2modman), this package should be compatible with automatic installation.

# 丝之歌奥里皮肤
用一只白色小精灵对大黄蜂进行外观替换

## 前置模组
* silksong_modding-BepInExPack_Silksong-1.0.3
* SilksongSkinCreators-Stitchwork-0.8.6
* 开发使用的空洞骑士：丝之歌版本为：1.0.30000

## 功能
* 当玩家使用猎手、收割者、漫游者、野兽与建筑师纹章进行游戏时，对大黄蜂的贴图进行替换。
* 皮肤包还替换了部分包含大黄蜂元素的标志贴图。
* 皮肤包替换了游戏内的部分简体中文文本。
* 皮肤包还对游戏内部分音效进行了替换。

## 未修改内容
* 视频过场动画
* 其余纹章以及无斗篷大黄蜂（监狱特殊剧情中）
* 部分工具

## 安装方法
1. 先后安装前置模组 **[BepInEx](https://thunderstore.io/c/hollow-knight-silksong/p/silksong_modding/BepInExPack_Silksong/)** 和 **[Stitchwork](https://thunderstore.io/c/hollow-knight-silksong/p/SilksongSkinCreators/Stitchwork)**。请参照 Stitchwork 的模组页面及 wiki 获取安装说明。
2. 将 **`Dalias_ORI_Main_1.1.X`** 文件夹，以及同目录下所有其他文件夹一起放入游戏根目录：**`Hollow Knight Silksong\BepInEx\plugins`** 。
3. 进入游戏主菜单后，按下键盘数字键 **`1`** 调出皮肤包管理器。
4. 使用条目左边的上下箭头按钮，确保 **`Dalias_ORI_Main_1.1.X`** 在所有包裹的最下方。
5. 在包列表内将各个包裹条目右边的开关打开，并按下右下角 **`应用`** 按钮。

* 如果你使用 r2modman / Gale 等模组管理器，本模组也支持自动安装。
