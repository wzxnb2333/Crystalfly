# GlitchDebug

丝之歌的 DebugMod 的异常扩展，用于练习所有异常的快速通关。  

_普通用户可能无需此模组且不应安装它_，因为它可能导致意外行为。

## 特性

- 在存档中添加了复制项与漏洞存储：
  - 跳跃蓄力、无敌状态、无碰撞以及长椅存储均会被保存。
- 增加了用于切换漏洞状态的快捷键绑定。
- 增加了一个信息面板入口，可显示所有已加载场景的完整列表。

## 使用方法

GlitchDebug 增加了以下设置，可在 BepInEx 配置或 ModMenu 中编辑：
- 保存复制存档：启用此选项以开启复制存档的保存功能。也可在键位绑定中访问。
- 启用旧版强制复制：启用此选项可加载 GlitchDebug v0.1 创建的复制存档。_该功能将在未来版本中被移除，请迁移您的存档包！_

所有功能均添加到键位绑定面板底部：
- 切换长椅存储、跳跃存储、无碰撞模式
- 复制/取消复制当前房间及将 MMS 复制至长椅
- 重置全部场景数据
