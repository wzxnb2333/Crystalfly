# SilksongFaah  
一个轻量级的《空洞骑士：丝之歌》模组，在大黄蜂死亡时播放“Faah”音效。为什么我制作了这个模组？我仍在寻找那个答案……

## 特性  
- 首领死亡时播放“Faah”音效。就这样而已。  
- 通过 Thunderstore 方便安装。

## 安装  
**Thunderstore:** [install from thunderstore here.](https://thunderstore.io/c/hollow-knight-silksong/p/MikeyMods/SilksongFaah/)  

**如果手动安装：** 在你的游戏 `BepInEx/plugins` 文件夹中创建一个 `SilksongFaah` 文件夹，并将内容放入其中（需要 BepInEx 模组加载器）。
