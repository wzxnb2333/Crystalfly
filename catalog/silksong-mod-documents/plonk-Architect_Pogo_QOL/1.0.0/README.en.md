# INSTALLATION

For the mod you'll need to install [BepInEx](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.4), <br>
Then simply drag and drop the .dll provided in the folder into a new folder in ...\BepInEx\plugins<br>

# USAGE

Equip the Architect crest and try pogoing.<br>
Uncharged pogo attack swipes in an 80 degree arc. <br>
Charged pog attack swipes in a 40 degree arc. <br>
Both pogo attacks no longer give any horizontal momentum while attacking. <br>
