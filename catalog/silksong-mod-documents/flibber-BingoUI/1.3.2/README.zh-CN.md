# BingoUI

一个《空洞骑士：丝之歌》模组，用于在屏幕上显示各种游戏统计数据的计数。该模组主要作为Bingo比赛的工具使用。

设置可以在BepInEx配置文件中进行配置，或通过 [ModMenu](https://thunderstore.io/c/hollow-knight-silksong/p/silksong_modding/ModMenu/) 进行设置。

## 用尽的念珠计数器

用尽的念珠计数器显示已消耗的念珠数量。HUD中的计数器和主背包页面上的计数器可以分别开启或关闭。
（在念珠炮上有一个独立的念珠显示，无法转换为用尽的念珠计数器。）

## 对抗计数器

* 跳蚤计数器显示 `current_fleas(fleas_in_current_area)`。Vog、Kratt 和 大跳蚤 都包含在内。
* 地图计数器显示已获得的地图总数。
* 帽扣计数器显示 `current_lockets(total_obtained_lockets)`。
* 工具计数器（全部、红色、黄色、蓝色）显示已获取的工具数量。丝线技能在此不计入工具范畴。
* 任务计数器显示每种类型任务完成的数量。全局任务计数器仅包含非主线任务，递送类任务仅计算一次。特殊任务（例如蘑菇先生）属于此类计数。狩猎计数器包含“狩猎”和“大狩猎”两类任务。
* 递送任务计数器显示 `num_delivery_quests{num_distinct_delivery_quests}`。快递员的火腿递送不包含在该计数器中（我认为是这样）。
* 壳碎片、野兽碎片、念珠丝线与念珠项链计数器分别统计 `num_in_inventory(num_ever_picked_up)`。括号内的数字仅包括作为稀有物品拾取的数量，不包含从机器或商店购买的物品。丝线/项链计数器包含所有类型的丝线/项链，e.g。破损念珠丝和普通念珠丝均计入丝线计数器。
* 阿什克拉地点计数器显示与阿什克拉互动过的不同场景数量。
* 神圣遗物计数器统计已获得的遗物数量。全局遗物计数器显示 `num_relics{num_distinct_relic_types}`。诗篇/神圣圆筒不包含在该统计中。诗篇/神圣圆筒计数器同时包含两种类型。
* 工具金属与丝食者计数器显示 `num_owned(num_ever_obtained)`。此计数包括从商店获得的工具金属以及从斯提克斯获得的丝食者。
* 念珠计数器显示已消耗的念珠数量（库存中的念珠数量空间不足）。默认为关闭状态，是替代“已消耗念珠追踪器”的选项。

## 添加新的计数器

若想添加或请求新增计数器，欢迎提交 Pull Request、创建 Issue，或在模组、速通或 bingy 的 Discord 中联系我。  
（实际上，即使你提交了 PR 或创建了 Issue，也建议在 Discord 中私信我）。

要制作新的图标，请使用本仓库 assets 文件夹中的模板。提供图标将有助于加快新计数器的添加进度。
