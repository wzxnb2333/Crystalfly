在战斗中切换两个纹章，而不是只能使用一个纹章。  
与其他纹章切换模组不同，本模组旨在让切换行为像一个功能特性，而非开发者工具。

需要注意的事项：  
- 键位绑定是可自定义的 Unity KeyCode。（控制器支持，但建议搜索 Unity 的 KeyCode 图表以适配你所使用的控制器）  
- 消耗 1 丝线刻度  
- 绑定增益（例如收割者模式）会在主槽和副槽之间传递。  
- 独立工具槽：你可以为主槽配备一套完整工具，为副槽配备另一套完整工具。（Vesticrest 槽位是共享的。）

使用说明：  
1. 安装 BepInEx  
2. 将模组文件夹放入 Hollow Knight Silksong/BepInEx/plugins  
3. 运行游戏一次以生成配置文件，然后退出  
4. 打开 BepInEx/config 文件夹中的配置文件，并设置你希望的主槽和副槽  
5. 开始尝试各种奇葩的搭配组合。（尽管我清楚地知道你们所有人其实只是用这个来切换 Pogo……）
