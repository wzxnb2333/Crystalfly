Swap between two crests in combat, rather than being stuck with only one.
Unlike other crest swapping mods, this one is meant to feel like a FEATURE, rather than a dev tool.

Things to note:
- Keybind is a remappable Unity KeyCode. (controller works, but google a unity KeyCode diagram for your preferred controller)
- Costs 1 silk notch
- Bind buffs (such as Reaper Mode) transfer to and from your alt slot.
- Independent tool slots: You can have a whole set of tools in your main slot, and a whole set in your alt slot. (Vesticrest slots are shared.)

Instructions:
1. Install BepInEx
2. Place mod folder in Hollow Knight Silksong/BepInEx/plugins
3. Run the game ONCE to generate the config file, then EXIT
4. Open the config file in BepInEx/config and set your desired main slot and alt slot
5. Enjoy trying out all the wacky build combos. (although i know for a fact all of you are just using this to change pogos...)
