
Using this mod you get infinite bottles of flea brew to throw at enemies.
Mainly intended to be used for challenge runs.

After 10 hits you get 1 silk (changeable in config).
Each crafting kit adds 2 to the flea brew damage (changeable in config).

How to change values:
- Navigate to the games install folder
- Open `BepInEx/config/com.fabbeyond.hornetaddict.cfg`
- Change the values and save the file
- Restart the game

How to change skins:
- Download Patchwork from `https://thunderstore.io/c/hollow-knight-silksong/p/Ashiepaws/Patchwork/`
- Navigate to the games install folder
- Open `BepInEx/plugins`
- Create a new folder called `Patchwork`
- Put both `Patchwork.dll` and `patchwork.assetbundle` in the newly created folder
- Start the game and once it loaded, close it
- Navigate to `BepInEx/Plugins/Patchwork/Sprites`
- Paste the `T2D` folder from the Skins into the `Sprites` folder (Skins are located in the same folder as the `HornetAddict.dll` file)
