# 塑钢之魂

塑钢之魂让你在非“塑钢之魂”模式下访问钢之魂专属的游戏内容。

## 安装

本模组需要  
[BepInEx 5](https://thunderstore.io/c/hollow-knight-silksong/p/BepInEx/BepInExPack_Silksong) 和  
[I18N](https://thunderstore.io/c/hollow-knight-silksong/p/silksong_modding/I18N)，并安装到你的 `BepInEx/plugins` 目录中。  
可以使用 [配置管理器](https://thunderstore.io/c/hollow-knight-silksong/p/Yukikaco/BepinExConfigurationManager)) 与本模组配合使用。

## 使用方法

一旦安装了此模组，您将默认可以通过多种方式访问所有 Steel Soul 独有游戏内容。在非 Steel Soul 模式下，

- 钢之先知 Zi 可以在被毁阶梯的相同位置获取，并提供与 Steel Soul 模式相同的 _A Vassal Lost_ 希望。召唤救世主的首领战完全一致，获得的生长石也正常运作。
- 贝壳包可在 Songclave 的 Jubilana 处购买，完成 _The Lost Merchant_ 希望后，可花费 290 念珠购买。
- Skynx 可在 Sinner's Road 中 Styx 栖息地以东的位置获取，并继续提供以丝食者换取念珠的服务。Styx 依然健康存活。
- Chrome Bell Lacquer 可用于装饰您的 Bellhome。您仍然可以选择使用白铃漆。

以上各项功能均可通过编辑此模组的配置文件位于 `BepInEx/config/Esper89.PlasteelSoul.cfg` 或使用配置管理器来禁用。

## 语言

本模组为游戏添加了新的文本。如果您的语言未被本模组支持，您可以自行添加支持：将 `languages/en.json` 复制到 `languages/xx.json`（其中 `xx` 是您语言的英文小写两位代码），并翻译所有文本内容。
