# RosaryCannonCraftBind 

A Hollow Knight: Silksong mod.\
With this mod Rosary Cannon reloads on Craft(Architect) Bind. But there is a catch. One rosary string(or frayed one) is taken for the reload and grants 60(15+ in case of frayed) bullets(rosaries). If less than 60(for frayed) rosaries are needed to reload, the rest are just flig away and can be taken back.
