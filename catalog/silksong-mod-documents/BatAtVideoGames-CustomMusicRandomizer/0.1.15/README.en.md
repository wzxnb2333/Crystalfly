# Custom Music Randomizer

Randomizes area, battle, boss, menu, and fanfare music using custom tracks, vanilla tracks or both.
Made with the Silksong AP Randomizer in mind since it links to seeds so randomized music stays the same throughout a playthrough but can be used outside of that too. 

The mod is disabled by default. Launch once, enable it in `BepInEx/config/moriko.silksong.custommusicrandomizer.cfg`, then restart Silksong to create the custom-track folders.

Add `.ogg`, `.wav`, `.mp3`, `.m4a` or `.flac` files to the generated `CustomMusic/Area`, `Battle`, `Boss`, `Menu` or `Fanfare` folders inside this mod's installed package folder. Long tracks loop, fanfares play once. Category, pool, display and seed options are in the config.
