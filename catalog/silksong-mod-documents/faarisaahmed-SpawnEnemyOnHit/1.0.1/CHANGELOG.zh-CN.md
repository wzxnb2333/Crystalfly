# Changelog

## 1.0.1

仅图标显示，无游戏玩法或行为变化。

- 藤蔓洞穴不再模糊，因此人物背后的背景清晰可见。
- 修复了大黄蜂面具被擦除的问题。由于删除了接近白色像素导致背景切割，而她的面具是白色的，因此会穿透头部形成孔洞，使她呈现为黑色轮廓。现在背景从边缘向内被清除，仅移除真正与边框相连的背景部分，保留内部完整的白色区域。
- 花边和加尔蒙德已自带透明度，因此在合成时直接保持原样，不再经过可能对其造成损害的背景去除处理。

## 1.0.0

首次发布。

- 受击会召唤一个敌人，该敌人仅从你已遭遇过的敌类型中随机生成。
- 怪物生成会根据房间几何结构进行验证：不会穿过墙壁、超出边界、落入深渊或进入地形内部。
- 当切换房间时，被召唤的敌人会被清除，因此没有任何房间会变得无法通行。
- `F4` 切换挑战模式，`F3` 切换计数器。
