# 受击时生成敌人

**每次受到攻击，都会在你身边出现一个敌人。**

但这也正是这个模组的核心所在：

> ### 它只会生成你已经见过的敌人。
>
> 没有任何敌人是从虚空中凭空出现的。该模组会默默记录你在每个房间中遇到过的所有敌类型，每当受到攻击时，就会随机召唤其中一种。因此，**你探索得越深入，受到攻击的风险就越高。**

在苔藓洞穴的第一小时，一个失误会让你失去一只爬行者；到了第20小时，同样的失误会追溯到你曾经战斗过的所有敌人，并随机选择其中一个。你通过游戏本身构建了自己的难度曲线。

这也意味着，模组绝不会突然出现你完全不知道如何应对的敌人。它所投放给你的每一个敌人都曾与你有过交集——只是你未曾预料到它们会出现在这里。

## 反馈循环

受到攻击会使得房间中出现另一个敌人。房间中的敌人越多，就越容易被击中。走廊中一个粗心的失误，可能演变成一场必须真正赢得战斗。

以下两条规则防止这种情况变得不公平：

- **每次攻击仅产生一个敌人**。因果关系清晰明确。压力来自敌人的不断累积，而非攻击频率的加速。
- **离开房间会清除所有敌人**。门总是可以作为逃生出口，因此没有任何房间会变得永久无法通过。逃跑始终是一个真实的选择，有时甚至是正确的选择。

## 控制方式

| 键位 | 功能 |
|------|------|
| `F4` | 在运行中开启或关闭挑战 |
| `F3` | 显示或隐藏计数器 |

计数器显示模组是否已激活、已学习的敌人类别数量、受到的击打次数，以及最近召唤的对象。

## 怪物生成的位置

在你身边，且仅限于敌人实际可以站立的地方。生成位置从大黄蜂向外延伸，直到遇到第一堵墙，检查该位置是否位于房间内，向下探测是否存在地面，并拒绝任何被地形覆盖的点位。它不会将敌人生成穿过墙壁、落入虚空，或因你恰好在跳跃时而悬空出现。

生成位置距离你 2.5–5 个单位——足够近，立刻成为你的威胁；又足够远，让你能在敌人到达之前看到它出现。

## 设置

所有内容均位于 `BepInEx/config/com.faaris.spawnenemyonhit.cfg` 中，首次运行时创建。

| 设置项 | 默认值 | 作用说明 |
| --- | --- | --- |
| `EnemiesPerHit` | `1` | 每次攻击出现的数量 |
| `MaxActiveSpawns` | `25` | 同时召唤敌人的上限——这是一个帧率限制，而非难度调节器 |
| `MaxEnemyHp` | `0` | 跳过比此值更强大的敌人。`0` 表示无限制，这会使首领类敌人保留在池中 |
| `MinDistance` / `MaxDistance` | `2.5` / `5` | 怪物生成的最近距离 |
| `ClearOnRoomChange` | `true` | 离开场景时清除召唤物。关闭此项将移除你的逃生途径 |
| `CooldownSeconds` | `0.35` | 防止单次伤害事件被计为两次攻击 |
| `HarvestIntervalSeconds` | `3` | 房间重新扫描以发现新敌人类型的频率 |

### 关于 `MaxEnemyHp` 的重要提示

保持在 `0` 时，一旦你击败过某个首领，该首领即被纳入可选池中。楼梯间的首领仅会带来一次有趣的体验。将其设置为大约 `200` 可将敌怪池限制在普通敌人范围内。

## 安装

**使用模组管理器：** 安装该模组，BepInEx 依赖项会自动包含在内。

**手动安装：** 安装 [BepInExPack Silksong](https://thunderstore.io/c/hollow-knight-silksong/p/BepInEx/BepInExPack_Silksong/)，然后将 `SpawnEnemyOnHit.dll` 放入 `BepInEx/plugins/SpawnEnemyOnHit/`。

## 注意事项

- 所有生命值损失都会被计入，包括突降和糟糕的落地。该模组会持续监控你的生命值，而不是仅拦截某一条伤害路径，因为大黄蜂会通过多种方式失去生命值，若只拦截单一路径则会遗漏其他情况。对于挑战模式而言，任何一次攻击都算作一次攻击。
- 角色列表在每次会话开始时为空，并在你移动后几秒内逐渐填充。如果你的第一次受到伤害发生在尚未获取信息之前，日志会明确说明这一点，此时不会有任何单位生成。
