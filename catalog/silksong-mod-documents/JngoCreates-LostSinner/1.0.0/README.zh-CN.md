## 安装说明

### 手动下载
1.  [Download and install BepInEx.](https://docs.bepinex.dev/articles/user_guide/installation/index.html)
2. 确保游戏已运行至少一次，以便在 `plugins` 文件夹中生成一个 `BepInEx` 文件夹，该文件夹位于游戏可执行文件旁边。
3. 从上述列出的任一来源下载 .zip 文件。
4. 将.zip文件解压到生成的 `plugins` 文件夹中。
5. 启动游戏并享受吧！

### 重要说明
- 该模组首领仅在游戏第 3 关可访问。
- 一个存档文件 `user3.dat` 位于首领房间外的旁边。
- 在 `Miscellaneous files` 部分中，位于 [Nexus Mods page](https://www.nexusmods.com/hollowknightsilksong/mods/169?tab=files) 下。
- 在 [Thunderstore](https://thunderstore.io/c/hollow-knight-silksong/p/JngoCreates/LostSinner/) 的 .zip 文件内部。
- 可从 [GitHub releases](https://github.com/jngo102/Silksong.LostSinner/releases/latest) 下载。
- 要使用存档文件，请前往你的《空洞骑士：丝之歌》游戏的存档文件夹，将 user3.dat 移动到与其他 user#.dat 文件相同的文件夹中。
    - Windows: `%USERPROFILE%/AppData/LocalLow/Team Cherry/Hollow Knight Silksong/`
    - macOS: `~/Library/Application Support/unity.Team-Cherry.Silksong/`
    - Linux: `~/.config/unity3d/Team Cherry/Hollow Knight Silksong/`
