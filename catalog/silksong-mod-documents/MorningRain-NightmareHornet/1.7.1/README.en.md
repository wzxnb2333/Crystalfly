# Nightmare Hornet
A Grimm Troupe inspired Hornet skin mod for *Hollow Knight: Silksong*.

## Features
* Completed Hornet sprites for a regular playthrough using any Crests, tools, and Silk Skills.
* Custom Red Memory contents (sorry Vespa).
* Cogflies get a new look.
* Custom inventory sprites and descriptions.
* Custom title screen backgrounds.
* ...and more!

## Planned for Future Updates
* Anything that I missed (if you find one please let me know)
* Sea of Sorrow related contents (when is it coming out anyways)


## Things That Probably Won't Change
* Bellway travel animations
* Cutscene animations

## Installation
1. Install using any mod manager that connects to the Thunderstore database or by manually placing the extracted folder inside your `BepInEx\plugins\` directory.
2. Once you are in the game's Main Menu, press `1` to bring up the Pack Manager.
3. Arrange the packs and set conditions.

| Pack (in this order) | Reload | Condition |
| -------- | -------- | -------- |
| NHWitch  | hot reload  | `crest != "Cursed"` AND `pack == "NHMain"` |
| NHRedMemory  | on scene  | `scene == "Memory_Red"` AND `pack == "NHMain"`  |
| NHMain | - | - |

![GIF](https://raw.githubusercontent.com/AM-Rain/ImageStuff/refs/heads/main/NH/PackSettings.gif)
