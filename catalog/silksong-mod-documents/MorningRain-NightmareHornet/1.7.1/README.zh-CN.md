# 夜魇大黄蜂  
一个受克里姆剧团启发的大黄蜂皮肤模组，适用于《空洞骑士：丝之歌》。

## 特性
* 完成了一次常规游戏流程中使用任意纹章、工具和丝线技能的大黄蜂角色插图。
* 自定义红记忆内容（抱歉 Vespa）。
* 小飞虫获得了新的外观。
* 自定义物品图标和描述。
* 自定义标题画面背景。
* …以及更多！

## 计划中的未来更新

* 与《悲伤之海》相关的部分（它到底什么时候发布呢）

## 安装  
1. 使用任何连接到 Thunderstore 数据库的模组管理器进行安装，或手动将解压后的文件夹放入你的 `BepInEx\plugins\` 目录中。  
2. 进入游戏主菜单后，按 `1` 打开包管理器。  
3. 安排包的顺序并设置条件。

| 包（按此顺序） | 重新加载 | 条件 |
| -------- | -------- | -------- |
| NHWitch  | 热重载  | `crest != "Cursed"` 且 `pack == "NHMain"` |
| NHRedMemory  | 场景加载  | `scene == "Memory_Red"` 且 `pack == "NHMain"`  |
| NHMain | - | - |

![GIF](https://raw.githubusercontent.com/AM-Rain/ImageStuff/refs/heads/main/NH/PackSettings.gif)

完成设置后，包管理器应显示如下效果：

![Pack Order](https://raw.githubusercontent.com/AM-Rain/ImageStuff/refs/heads/main/NH/pack_order.png)

  ![Pack Condition](https://raw.githubusercontent.com/AM-Rain/ImageStuff/refs/heads/main/NH/pack_condition.png)

  关于包条件的更详细信息，请访问 Stitchwork [wiki](https://thunderstore.io/c/hollow-knight-silksong/p/SilksongSkinCreators/Stitchwork/wiki/5474-aex1-conditional-activation)。
