# 返回长椅  
添加一个返回长椅的菜单选项

## 源代码
GitHub: [https://github.com/DemoJameson/Silksong.ReturnToBench](https://github.com/DemoJameson/Silksong.ReturnToBench)

## 安装方法

### Thunderstore
一切都会被自动处理。

### 手动安装
首先将 BepInEx 安装到你的 Silksong 文件夹中，
（注意：这会破坏 Thunderstore 的正常运作）

你可以从以下位置找到它：
https://github.com/BepInEx/BepInEx/releases
当前最新稳定版本为 5.4.23.4

解压后，运行游戏一次，以生成 BepInEx 的文件夹结构
（即：除了仅包含 `core` 的文件夹外，还应存在其他文件夹）

然后将此 DLL 文件或包含 DLL 的文件夹拖入到  
`Hollow Knight Silksong\BepInEx\plugins`
