# 空洞纹章  
* 当前自动解锁（暂时如此）  
* 使你周围的世界变暗（字面意义）（可在配置中关闭，以免视野过于困难）

# 缚丝  
* 使用空洞纹章进行缚丝 **将不再为你提供治疗效果**  
* 在缚丝期间，你将 **获得无敌状态**  
* 在缚丝期间受到攻击，将会对敌人造成 **反制伤害**，该伤害基于你的针刺伤害计算  
  * （反制伤害 = 针刺伤害 × 2，击中不会生成丝线）  
* 每次在缚丝期间造成反制伤害，将获得 1 空洞质点

# 空之质

* 丝线轮下方有一个黑色卷轴，用于记录空之质的数量，最多可达 **10**  
* 每次使用丝线技能时，若拥有至少 1 的空之质，则消耗 1 空之质以触发“虚化”效果，使丝线技能的伤害翻倍  
* 按下缚丝 + 上键将消耗你所有的空之质，释放一次强大攻击，其威力根据消耗的空之质数量而提升  
* 执行缚丝 + 上键攻击后，恢复相当于所消耗空之质一半的治疗值（向下取整）  
* 在长椅上休息会使空之质重置为 0（显然的原因）

# 空洞插槽  
* 此纹章仅包含空洞插槽，一个空洞插槽可容纳**任何工具，无论其颜色**  
  * 注意：当使用需要通过缚丝触发的工具（I.e，红色工具）时，每个缚丝插槽最多只能持有 1 个工具

# 技能组合  
* 当前仅包含女巫的技能组合，但没有典型的冲刺攻击  
* 取代冲刺攻击的是，你现在可以穿过敌人进行攻击，对敌人造成伤害而自身不会受到伤害，伤害值与针刺伤害相关  
  * （冲刺伤害 = 针刺伤害 × 0.5，击中时不会生成丝线）

# 特殊工具协同效果  
* 注射带  
  * 通过缩短缚丝持续时间削弱了缚丝效果  
  * 为了补偿，当你在缚丝状态下受到伤害时，会获得 1 额外的虚空质量  
  * 同时提升缚丝反制伤害由 50%  
    * （叠加计算，最终为 250% 的钉刺伤害，而非 300%）

* 多重缚丝器  
  * 现在不再使你连续两次进入缚丝状态  
  * 每当你通过冲刺攻击敌人或触发缚丝反制造成伤害时，会生成与普通针击相同的丝线  
  * 同时提升缚丝反制伤害由 50%  
    * （叠加计算，最终为 250% 的钉刺伤害，而非 300%）

* 防护铃铛  
  * 因为你已经无视缚丝造成的伤害，因此该物品完全无用  
  * 只是额外提供 +100% 的缚丝反制伤害

* 丝速踝带  
  * 现在也提升冲刺伤害由 50%  
    * （叠加计算，最终为 100% 的钉刺伤害，而非 75%）

* 加重腰带  
  * 现在也提升冲刺伤害由 75%  
    * （叠加计算，最终为 125% 的钉刺伤害）

* 等离子药瓶  
  * 现在不再提供蓝色面罩，而是使用时给予你 1 虚空质量

# 配置  
* 在首次加载本模组启动游戏后，若前往游戏文件夹/BepInEx/config 并打开 io.dervorce.voidcrest.cfg，您将找到许多配置选项，包括修改此处提到的几乎所有数值，甚至可以更改基础纹章。

## P.S. 你可以在配置中关闭黑暗光环，也可以在大黄蜂角色上关闭黑暗着色器，如果它太烦人的话！！
