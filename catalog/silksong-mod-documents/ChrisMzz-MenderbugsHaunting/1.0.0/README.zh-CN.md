# 空洞骑士的幽灵

> 版权声明！本模组是 flibber-hk 的 [Menderbug's Revenge](https://github.com/flibber-hk/HollowKnight.MenderbugsRevenge) 在空洞骑士中的改编版本。我并未提出该想法，但我希望在丝之歌中也能看到它，因此制作了这个模组。

Menderbug 再次回归丝之歌！破坏任何物品都将导致大黄蜂死亡。  
你可以通过配置菜单将大黄蜂受到的伤害设置为你想要的任意数值（包括 0），但你是否愿意为对 Menderbug 所犯下的罪行感到悔恨呢？默认情况下，伤害值为 100。

游戏中可能存在一些无法继续进行的区域，如有此类情况，请及时向我反馈。在等待反馈期间，你可以临时将某部分区域的大黄蜂伤害设置为 0。
