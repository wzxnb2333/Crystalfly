# Infinite Cogflies

This mod removes that cap of 4 cogflies active at a time.
There is also an option to remove the attack cooldown.

To remove/re-add the attack cooldown do the following steps:
1. Navigate to your Silksong Game Files Folder
2. Open the BepInEx folder
3. Open the config folder
4. Open com.fabbeyond.infinitecogflies.cfg
5. Change the instantAttack value to true/false
6. Restart your game
