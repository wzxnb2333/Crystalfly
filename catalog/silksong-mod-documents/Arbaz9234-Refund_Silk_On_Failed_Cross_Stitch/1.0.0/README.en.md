# Refund Silk on Failed Cross Stitch

Refunds the Silk cost of **Cross Stitch** if you fail to parry, removing the punishment for unsuccessful timing.

---

## Overview

In the base game, failing to parry with Cross Stitch results in **lost Silk and no damage**, which discourages using the skill.

This mod refunds Silk when Cross Stitch fails, so you can retry without being punished.

---

## Features

- Refunds Silk when Cross Stitch fails
- No Silk loss when no damage is dealt
- Encourages learning and mastering Cross Stitch
- Makes Cross Stitch more viable compared to other Silk skills

---

## Compatibility

- Requires **BepInEx for Hollow Knight: Silksong**
- Compatible with most gameplay mods
