# 失败刺绣时退还丝线成本

如果未能格挡，将退还**刺绣**的丝线消耗，消除因时机失误而受到的惩罚。

## 概述

在原版游戏中，未能使用刺绣格挡会导致**丝线消耗且不造成伤害**，这会抑制玩家使用该技能。

本模组在刺绣格挡失败时返还丝线，因此你可以无需受到惩罚而反复尝试。

## 特性

- 当十字绣失败时，返还丝线  
- 未造成伤害时不会损失丝线  
- 鼓励学习并精通十字绣  
- 使十字绣相比其他丝线技能更具可行性  

---

## 兼容性

- 需要 **BepInEx for Hollow Knight: Silksong**
- 与大多数游戏模组兼容
