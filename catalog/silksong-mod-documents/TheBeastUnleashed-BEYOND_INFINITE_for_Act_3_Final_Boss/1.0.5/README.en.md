### GENERAL INFORMATION

This mod replaces Lost Lace's theme with "[BEYOND](https://youtu.be/MQwozcIX9b0) [INFINITE](https://youtu.be/BsplQD1HVFs)", batman arkham vengeance tm's remix of "Infinite" from Sonic Forces, composed and arranged by Tomoya Ohtani, with lyrics and performance by Tyler Smyth and Andy Bane of Dangerkids, and guitars by Jun Senoue. (Takahito Eguchi also composed "Cutscene - Infinite's Beginning," which was used in the opening of it.) Why did I make this? I was rather curious. :)



It comes packaged with [Ol1vver](https://github.com/Ol1vver)'s [BepInEx Sound Mod](https://github.com/Ol1vver/bepinex-soundmod), replacing sounds in the game at start-up by matching the file names.





### MANUAL INSTALLATION

1\. Refer to the install instructions of BepInExPack Silksong beforehand.

2\. Extract bepinex\_soundmod.dll and the sounds folder inside of the ZIP file into the plugins one.

3\. Run the game and profit.
