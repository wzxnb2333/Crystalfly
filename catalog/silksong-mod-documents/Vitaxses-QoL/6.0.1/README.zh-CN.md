# 生活品质

一款专为《空洞骑士：丝之歌》设计的生活品质模组

## 特性

- 保存的跳蚤计数器
- 快速设置
+ 更快的菜单
+ 立即文本
+ 更快的拾取
+ 瞬时杠杆
- 贝尔韦
+ 更快的旅行动画
+ 更快的铃方式站购买
+ 铃兽始终清醒
+ 铃兽始终位于你所在位置
+ 更快的幼兽召唤
- 维特里卡
+ 更快的旅行动画
+ 更快的Ventrica站购买
- 非玩家角色
+ 更快的NPC介绍
+ 更快的首领登场
- 场景动画
+ 跳过场景动画
+ 跳过梦境场景
+ 完全跳过梦境场景
+ 跳过弱点场景
+ 跳过教程工具消息
- 旧补丁
+ 旧浮点数覆盖
+ 无披风爪线
+ 旧电压容器
+ 绑定冲刺刷新
+ Pimpillo 跳跳
+ 老式碎壳者
+ 旧雾
+ 跳过 Trobbio
+ 杠杆跳过
+ 没有需要之袍的法德之cloak
+ 老腐朽的管道木板
