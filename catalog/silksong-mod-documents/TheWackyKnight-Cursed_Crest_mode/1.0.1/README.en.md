# Cursed Crest Mode

Start the game with the cursed crest permanently! No more tools, skills, or heals! Use F9 to toggle on and off!
---
## Features
- The Cursed Crest disables tools, silk skills, and healing.
- Use F9 to toggle the mod on and off, switches to Hunter Crest when toggled off
