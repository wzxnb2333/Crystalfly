# Silk SomeMOD - Death Teleport Back MOD | 死亡回溯传送MOD

## Features | 功能介绍

**English:**
This MOD automatically teleports you back to your death location after respawning, saving you time from walking back to where you died.

**中文：**
这个MOD会在你复活后自动传送回死亡位置，省去重新走回死亡地点的时间。

### Main Features | 主要功能

**English:**
- **Death Location Recording**: Automatically records your position when you're about to die
- **Smart Teleport Back**: After respawning, teleports you back to your death location with a 3-second countdown
- **Cancellable Teleport**: Press N key or Gamepad B button during countdown to cancel teleport
- **Safe Teleportation**: Uses the game's built-in scene transition system for stability

**中文：**
- **死亡位置记录**：当你即将死亡时自动记录死亡位置
- **智能回传**：复活后显示3秒倒计时，然后传送回死亡位置
- **可取消传送**：倒计时期间按N键或手柄B键可取消传送
- **安全传送**：使用游戏内置的场景切换系统，确保稳定性

## Installation | 安装方法

**English:**
1. Make sure BepInEx is installed in your game
2. Download the `Silk_SomeMOD.dll` file
3. Place it in your game's `BepInEx/plugins/` folder
4. Launch the game and enjoy!

**中文：**
1. 确保游戏已安装BepInEx
2. 下载 `Silk_SomeMOD.dll` 文件
3. 将文件放入游戏的 `BepInEx/plugins/` 目录
4. 启动游戏即可使用！
