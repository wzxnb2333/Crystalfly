# Silk SomeMOD - Death Teleport Back MOD | 死亡回溯传送MOD

## 特性 | 功能介绍

**中文：**
此模组会在你重生后自动将你传送到死亡位置，避免你需要步行返回死亡地点而浪费时间。

**中文：**
该模组会在你复活后自动传送到死亡位置，避免你需要重新走回死亡地点的时间。

### 主要功能

**中文：**
- **死亡位置记录**：在你即将死亡时自动记录你的位置
- **智能返回传送**：重生后会将你传送到死亡位置，并伴有 3 秒的倒计时
- **可取消传送**：在倒计时期间按 N 键或手柄 B 按钮以取消传送
- **安全传送**：使用游戏内置的场景切换系统以确保稳定性

**中文：**
- **死亡位置记录**：当你即将死亡时自动记录死亡位置
- **智能回传**：复活后显示3秒倒计时，然后传送回死亡位置

## 安装方法 | Installation Method

**中文：**
1. 请确保 BepInEx 已安装到你的游戏中
2. 下载 `Silk_SomeMOD.dll` 文件
3. 将其放入游戏的 `BepInEx/plugins/` 文件夹中
4. 启动游戏并享受吧！
