# MapUnlocker

一款适用于空洞骑士：丝之歌的 BepInEx 模组，可让你解锁地图并控制游戏过程中地图的可见性。

## 特性

- **独立地图控制**：可单独解锁特定地图，或一次性解锁所有地图  
- **独立标记控制**：可单独解锁特定标记，或一次性解锁所有标记  
- **独立标记控制**：可单独解锁特定标记，或一次性解锁所有标记  
- **笔工具**：启用或禁用地图绘制的笔工具  
- **自动解锁**：在开始新游戏时，可自动解锁所有地图和标记  
- **地图重置**：在离开游戏时，可恢复地图和标记的原始状态  
- **调试模式**：提供详细日志以用于问题排查  
- **可配置**：所有选项均可通过 BepInEx 配置菜单进行设置

## 安装

1. 安装 [BepInEx](https://github.com/BepInEx/BepInEx) 用于 空洞骑士：丝之歌  
2. 从发布页面下载最新版本  
3. 将 `MapUnlocker.dll` 文件提取到你的 `BepInEx/plugins/` 文件夹  
4. 启动游戏

## 配置

该模组通过 BepInEx 配置菜单提供了多个配置选项：

### 通用设置

- **调试模式**：启用详细日志记录以进行问题排查
- **离开游戏后重置地图**：退出游戏时恢复地图的原始状态
- **拥有羽毛笔**：启用或禁用地图绘制的羽毛笔工具

### 单个地图设置

每个地图、标记点和标记都有独立的开关用于解锁/锁定：
- **全部启动解锁**：每次加载存档时，每个区域都有针对所有物品的主开关。
- **现在全部解锁**：每个区域在其分类下都有针对所有物品的主开关。
- 每个地图、标记点和标记均有独立的开关。

## 它是如何工作的

该模组使用 Harmony 修补技术来：
1. 游戏启动时拦截地图数据
2. 将你的配置设置应用到解锁所需地图
3. 可选地在存档/离开时恢复原始地图状态
4. 通过配置菜单提供实时地图解锁功能

## 兼容性

- **游戏版本**：兼容 空洞骑士：丝之歌
- **BepInEx 版本**：需要 BepInEx 5.4.21 或更高版本
- **依赖项**：使用 Silksong.GameLibs 1.0.2-silksong1.0.28561

## 常见问题排查

如果遇到问题：

1. 在配置文件中启用 **调试模式** 以查看详细日志  
2. 检查 BepInEx 控制台中的错误信息  
3. 确保你使用的是兼容版本的 BepInEx  
4. 确认模组已正确安装到 `BepInEx/plugins/` 文件夹中
