

# 消散的幽灵  
________________________________________  
* 重新设计了幽灵首领的战斗，使敌人更具挑战性。  
* 首领的攻击速度、生命值以及部分伤害数值已提升，攻击方式也进行了调整。  
* 已针对后期 2 至中期 3 的阶段进行平衡调整。

## 安装
1. 下载并安装 BepInEx，然后解压 ZIP 文件，并将其放入游戏根目录。
2. 运行游戏一次以生成 BepInEx 文件。
3. 下载本模组，解压文件夹并放入 BepInEx 插件文件夹中。

## 存档文件  
* 在本模组的文件夹内，包含一个位于后期关卡 2 的存档文件，其中包含了你需要对抗首领的所有内容。  
* 该存档默认会设置为第三个存档，但可以通过重命名进行更改。
