
# Faded Phantom
________________________________________
* Rework of Phantom's bossfight, making the boss more challenging.
* The boss's attack speed, health and some damage values have been increased, and attacks have been changed.
* Balanced for Late act 2 to act 3.

## Installation
1. Install BepInEx by downloading it, then extracting the zip file and placing it in the game root directory.
2. Run the game once to generate BepInEx files.
3. Download this mod, extract the folder and place it in the BepInEx plugins folder.

## Save File
 * Inside the folder of this mod there is a save file in late act 2 with everything you need to fight the boss.
 * The save will be set as the third save file by default, but can be changed by renaming.
