# Fiendlord's Pure Vessel

Replaces Hornet with an adapted Pure Vessel design inspired by Pure Vessel from Hollow Knight.

## Features

- Replaces Hornet with a Pure Vessel-inspired design
- Updated sprite sheets
- Compatible with Patchwork

## Requirements

- BepInExPack Silksong
- Patchwork

## Installation

Install using Thunderstore Mod Manager or manually by installing the required dependencies and enabling the mod through Patchwork.
