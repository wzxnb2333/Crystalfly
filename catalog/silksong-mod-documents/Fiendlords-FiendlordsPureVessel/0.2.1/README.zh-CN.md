# 恶魔领主的纯净容器

用一种受《空洞骑士》中纯净容器启发的改良设计，替换大黄蜂。

## 特性

- 用受纯容器启发的设计替换大黄蜂
- 更新了精灵图集
- 与 Patchwork 兼容

## 要求

- BepInExPack 丝之歌
- Patchwork

## 安装

通过 Thunderstore 模组管理器安装，或手动安装所需依赖项，并通过 Patchwork 启用该模组。
