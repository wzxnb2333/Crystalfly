# 白色自动机  
白色自动机将第二哨兵改造成一个 4 阶段格挡为主的战斗，实际上与护盾之盾类似，此模组本意是重制/重构该模组。

# 安装  
将 PaleAutomaton.zip 的内容解压至你的 BepInEx/plugins 目录

## 依赖项：
> 警告！如果手动安装这些依赖项，请确保安装每个列出的依赖项，并将其内容放入相应的文件夹中。例如，如果下载的 zip 文件包含 "core" 或 "patchers" 文件夹，则应将这些文件夹的内容放入 bepinex 目录下的 "core" 和 "patchers" 文件夹中，**不要**将所有内容放入 plugins 文件夹中！

# 通用信息  
该模组在设计时并未考虑接触伤害和格挡冻结帧，也未实现无敌状态，主要聚焦于格挡机制。战斗期间竞技场将变为无限走廊，一旦击败首领或玩家死亡，竞技场将恢复原状。

## 机制  
相位 3 和 4 配备了自定义的跳跃击框，即围绕玩家的圆形区域。这使得空中跳跃格挡更加一致。  

空中格挡需配合“跳跃 > 方向斩击 > 上斩击”的连段才能实现空中战斗，因为跳跃格挡会重置攻击冷却时间，但不会重置跳跃冷却时间，因此要格挡快速的空中连击，需要执行类似“跳跃 > 方向斩击 > 上斩击”的操作。

## 阶段 1（1800 HP）：
首领将主要保持原版行为，仅首攻击组合的第一个攻击会被修改。此阶段旨在作为操作时机的教程，且提供充足的时间进行恢复。

## 阶段 2（1600 HP）：
该阶段以首领怒吼开始，随后是一个假防御动作，接着他会快速斩击你。此阶段延续了第一阶段的连招和后续动作，每个连招均取决于初始攻击，其中部分连招存在混用情况，但所有混用的防御时机应保持一致（我已对此进行了彻底测试）

## 阶段 3（800 HP）：
该阶段开始时，首领会传送离开，地面会出现尖刺，随后首领再次出现。本阶段包含 5 种全新的攻击连招，旨在替代阶段 2 的攻击连招，这些连招专为完全空中战斗而设计。

## 阶段 4（400 HP）：
该阶段开始时，首领会释放一次巨大的风斩，摧毁地面和尖刺。此阶段完全为空中战斗，与阶段 3 并无新内容。首领无法通过格挡击杀，必须受到直接打击才能将其击败。
