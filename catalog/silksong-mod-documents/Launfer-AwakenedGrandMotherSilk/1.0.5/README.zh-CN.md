存档文件指南

\=================================

- Steam 在 Windows 上：打开文件资源管理器，点击侧边栏中的“此电脑”下的你的电脑。

- 从这里导航到 “Users” -> [你的账户名称] -> "AppData"（可能需要在文件资源管理器设置中启用隐藏文件夹）-> "LocalLow" -> "Team Cherry" -> "空洞骑士 丝之歌" -> [一个名为数字字符串的文件夹]。

- 将文件重命名为符合你期望存档槽位的名称。当前文件对应存档槽位 4 ("user4.dat")。例如，一个对应存档槽位 2 的文件名示例为 "user2.dat"。

- 将 .dat 文件拖入名为数字字符串的文件夹中。

- 安装完成。

卸载时只需删除该文件夹中的文件。你可能还希望删除标题中包含 "user[存档槽位 N]" 的其他文件（例如 "user4.dat.bak1"）。

\=================================

使用方法

\=================================

正常进入游戏并遭遇丝之歌母亲以战斗其觉醒形态。如果模组无法生效，可能需要移除加载资源的其他模组。
