BepInEx mod heavily altering the Hollow Knight: SilkSong boss Grand Mother Silk

\=================================

SAVE FILE GUIDE

\=================================

-STEAM on WINDOWS: Open File Explorer and click on your PC under "this PC" in the sidebar.

-From here navigate to "Users" -> [your account name] -> "AppData" (may need to enable hidden folders in file explorer settings) -> "LocalLow" -> "Team Cherry" -> "Hollow Knight Silksong" -> [a folder named a string of numbers].

-Rename the file to fit your desired save slot. The file currently fits save slot 4 ("user4.dat"). An example of a file fitting save slot 2 would be "user2.dat".

-Drag the .dat file into the folder named a string of numbers.

-Installation complete.

To Uninstall simply delete the files from the folder it's placed in. You may also want to delete other files with "user[Save Slot N]" in the title (such as "user4.dat.bak1").

\=================================

USAGE

\=================================

Simply encounter Grand Mother Silk in game as normal in game to fight the Awakened version. If the mod doesn't work you may need to remove any other mods that load assets.
