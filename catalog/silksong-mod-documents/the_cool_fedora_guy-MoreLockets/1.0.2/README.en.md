# More Lockets

Adds new Memory Lockets to find throughout Pharloom. Great for mods that add new crests.

## Locations
One in Bone Bottom  
One in the Abyss  
One in Sinner's Road  
One in Mt. Fay  
One in Sands of Karak  
One in Weavenest Alta  
One in Far Fields  
One in Greymoor  
One in the Cradle  
  
A Steelsoul Exclusive one in High Halls  
A Normal Mode Exclusive one in Blasted Steps
