# 纹章潜水缚丝

使纹章潜水功能更接近于荒芜潜水。同时移除缚丝下坠距离/时间的上限，并将注射带的下坠速度提升为缚丝的两倍。

该模组对 I18N 存在软依赖关系，用于更新纹章描述。它被列为 Thunderstore 上的必需模组，但如果你不想使用它，此模组仍可在没有 I18N 的情况下正常运行。

## 行为  
下潜缚丝包含两个伤害区域。第一个伤害区域（下潜伤害区域）较小，造成 0.75x 针状伤害。第二个伤害区域（冲击波伤害区域）较大，造成 2.5x 针状伤害。这两个伤害均受到电压丝线和祭司纹章的丝线技能伤害倍率影响，且在使用电压丝线时会附加 1 电击伤害持续效果。

接触地面后，获得 0.4 秒的无敌帧，与荒芜下潜相同。

## 损伤计算  
假设装备了伏特丝线，使用最高级的针，并且敌人拥有 1x 损伤加成，则第一次攻击造成 (21)(0.75)(1+0.4+0.25)(1)=26 损伤，第二次攻击造成 (21)(2.5)(1+0.4+0.25)(1)=87 损伤，总计 118 损伤（因为伏特丝线的电击伤害每帧额外增加 +5）。  

作为参考，这是与其他丝之歌技能的伤害对比：

| 丝之歌技能                 | 伤害       |
| -------------------------- | ---------- |
| 神秘怒气                   | 78-215 |
| 白色指甲                   | 109     |
| 缝合之刺                   | 110     |
| 丝线长矛                   | 114     |
| 绑缚下潜                   | 118     |
| 丝线风暴（未扩展）         | 118     |
| 锐刺                      | 127     |
| 丝线风暴（扩展版）         | 142     |

*部分伤害数值可能因游戏对以 ".5" 结尾的值进行四舍五入而有轻微偏差，且神秘怒气的数值可能存在误差，因其伤害计算更为复杂。*
