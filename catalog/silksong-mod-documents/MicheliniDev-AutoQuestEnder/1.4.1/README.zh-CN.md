# 自动任务完成器  
一个提升游戏体验的模组，会在开始无聊的任务（愿望）时自动将其结束。

## 重要信息  
- 本模组与主线任务（如抵达要塞、获取三首旋律等）不兼容；  
- **BepInEx 配置管理器** 可在游戏过程中启用或禁用该模组，无需重新启动即可关闭；  
- 会跳过游戏中几乎所有的任务，并自动将奖励给予玩家；  
- 救援类任务需要重新进入房间，新NPC才会出现；  
- 与 NPCs 对话将自动完成所有尚未完成的任务，此行为可在设置中禁用；  
- 本模组可能导致大黄蜂陷入贝珠债务状态，因为它会始终允许完成捐赠任务，即使玩家没有足够的资源。

## 异常情况  
本模组不会跳过设置中启用的 **重生仪式**、**大师之油**、**感染行动**、**丝与灵魂** 以及首领任务。  
<img width="622" height="335" alt="Settings" src="https://raw.githubusercontent.com/MicheliniDev/AutoQuestEnder/refs/heads/main/Settings.png"/>  

BepInEx 需要配置管理器才能选择不跳过的首领任务。 <br>  
此功能适用于喜欢挑战特定首领且不想因任务跳过而错过这些内容的玩家。

## 更新日志  
如果发现任何错误或与任务的奇怪交互，请务必在 GitHub 仓库的 <a href="https://github.com/MicheliniDev/AutoQuestEnder/issues">问题页面</a>中提交报告。 <br>  
若遇到“未收到 x 物品”的bug，尝试重新打开存档文件或完成另一个任务，你应该会自动获得该物品。
