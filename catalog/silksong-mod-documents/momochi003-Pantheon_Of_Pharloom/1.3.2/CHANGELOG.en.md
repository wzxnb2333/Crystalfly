# Changelog

All notable changes to this project will be documented in this file.  
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),  
and this project adheres to [Semantic Versioning](https://semver.org/).

---

## [1.3.2] - 2025-11-03

## Changed

* Restored compatibility with Knight in Silksong mod.
    * Added some fixes for Widow/Phantom causing knight to disappear.
* Fixed hornet visual glitch after beating LL.

## [1.3.1] - 2025-11-03

## Fixed

* Fixed Lace not existing in her room.

## [1.3.0] - 2025-11-03

## Added

* Added ability to set cursed, toggle float/faydown cloak, and change tools' capacity/damage.
* Added bindings for nail, mask, silk, skills, and tools.
* Added attuned, ascended (2x damage), and radiant (no-hit) difficulty modes for bosses.

## Fixed

* Fixed bug where hazard respawing right before transition would cause boss rush to break.
* Fixed bad HP scaling for Fourth Chorus.
* Fixed HP scaling and phase transitions point for these bosses.
    - Lace, Widow, Moorwing, Double Mossmother, Bell Beast, Signis & Gron, Sister Splinter, Last Judge, Cogwork Dancers,
    Trobbio, First Sinner, and Flower Lace.
* Fixed Shakra not spawning in her boss room.
* Fixed input mapping for boss selection.
* Fixed big area title showing up in boss encounters.
* Fixed being transitioned to Cogworks Dancers room instead of last spawnpoint after beating them.
* UI visual and audio improvements.

## [1.2.0] - 2025-10-20

## Added

* Added custom spawn points for all the bosses. Players don't have to do any platforming to get to the bosses now similar to Godhome in HK.
* Added missing boss fights: Moss Mother 2, Garmond and Zaza, Lost Garmond, Shakra, Savage Beastfly 2, Voltvyrm and Plasmified Zango.
* Added simple HP scaling to Act1 and Act2 bosses.
    * NOTE: Some bosses that have a fake death might not be scaled properly in their second phase right now. It'll likely be fixed in the future.
* Added a feature that lets players customize the Act 1, Act 2, and Act 3 boss rushes. See the README.md for how to customize.

## Changed

* Dying now restore cocoon automaticallly.
* Changed name of boss rushes to be more fitting as they are not stictly tied to their acts now.

## Fixed

* Fixed being able to select inactive first encounters.
* Fixed tutorial prompts showing up when doing boss rush.
* Fixed volt vessel transforing to stick form.
* Fixed bug where you could open menu right after dying which caused scene issues.
* Fixed being able to open UI as the player is spawing which caused UI issues.
* Fixed weird platform in LL arena.
* Fixed not being able to control Hornet after finishing boss rush.

## [1.0.1] - 2025-10-17

### Fixed
- Fixed being able to select undefeated bosses in Bosses menu.
- Fixed infinite loading after dying to a boss rush.
- Fixed respawning logic after finishing a boss rush.
