# Silksong Voidsong mod

## 关于本模组  
本模组几乎将所有敌人替换为带有丝线的变体，甚至让首领也拥有游戏初期的攻击方式。在制作过程中，我使用了人工智能辅助创作，作为一名新手，我对模组开发经验有限，但并非完全依赖代码，而是通过AI辅助完成的创作 :D

## 更新日志  
1.2.0 版本更新说明：  
- 修复了战斗竞技场的问题，现在游戏在技术上可以正常进行游玩  
- 生命值倍率现已改为 2 倍生命值，而非之前的 3，因为后期敌人使用 3 倍生命值会过于强大  
- 其他一些较小的修复

## 问题  
目前的问题当然不仅限于以下几点：  
- 生命值倍率已修复，但在一些首领战中，机械舞者仍过于容易，因为它们会自行设定生命值  
- 部分敌人未获得任何效果（例如，花叶舞者对某些原因无效）  
- 黑线色调有时显示不正确  
- 战斗中的敌人有时完全无法使用

## 有趣的创意方案
