# Revolt And Devotion
First Sinner and Widow double bossfight

# Installation
The zip contains RevoltAndDevotion.dll, place it in BepInEx/plugins/(here)
The mod requires FSMUtils to work, without that it just wont load, you can find it on thunderstore
- https://thunderstore.io/c/hollow-knight-silksong/p/silksong_modding/FsmUtil/
> Note that there has been an update to FSMUtil and if you have an old version it will not work properly, make sure to install the latest one from the link above!

# Bossfight
- Shared HP
- Phase/death sync
- Deflected bells can hit First Sinner and interrupt her, dealing 30 damage

# Phases
- Initial HP: 1300
- Widow phase 1.5 HP: 1000
- Both phase 2: 630 HP
