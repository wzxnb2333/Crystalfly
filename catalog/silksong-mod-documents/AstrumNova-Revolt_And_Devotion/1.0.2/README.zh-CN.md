# 反抗与奉献  
第一罪人与寡妇的双首领战斗

# 安装  
压缩包包含 RevoltAndDevotion.dll，将其放置在 BepInEx/plugins/（此处）  
该模组需要 FSMUtils 才能正常运行，缺少它将无法加载，您可以在 thunderstore 找到它  
- https://thunderstore.io/c/hollow-knight-silksong/p/silksong_modding/FsmUtil/  
> 注意 FSMUtil 已经更新，如果您使用的是旧版本，将无法正常工作，请务必从上述链接安装最新版本！

# 首领战  
- 共享生命值  
- 阶段/死亡同步  
- 被反弹的铃铛可击中第一位罪人并打断其行动，造成 30 损伤

# 阶段  
- 初始生命值：1300  
- 女巫阶段 1.5 生命值：1000  
- 双重阶段 2：630 生命值
