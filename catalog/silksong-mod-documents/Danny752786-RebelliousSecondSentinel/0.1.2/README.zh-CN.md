# RebelliousSecondSentinel

一个改变了次席戍卫攻击行为的模组，共包含两个阶段，比原版更难，但又不会太难

# 安装

从 Thunderstore 下载文件，解压，然后放到 BeplnEX/plugins 文件夹里，模组需要 silksong_modding-FsmUtil 作为前置依赖

从 Thunderstore 下载文件，解压，然后放到 BeplnEx/plugins 文件夹里。  
确保你已安装 silksong_modding-FsmUtil 模组作为依赖！

# Instruction for the mod:

次席戍卫现在有1500血，在800血时开启二阶段
别用十字绣！使用十字绣时首领会立即改变战术，这是一个BUG，但我喜欢就保留了下来（变成了特性）
在挑战之前强烈建议备份存档或使用不必要的存档，以免引发未知的 bug

第二哨兵现在拥有1500点生命值，当生命值降至800点时进入第二阶段。
不要在战斗中使用缚丝。如果使用了缚丝，首领会改变其攻击方式。这是一个bug，但我喜欢这个特性，所以保留了下来。
该模组可能存在bug，因此强烈建议在战斗前备份你的存档或使用不必要的存档，并启用重战模组。
