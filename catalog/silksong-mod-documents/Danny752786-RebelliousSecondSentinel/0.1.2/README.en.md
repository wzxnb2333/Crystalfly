# RebelliousSecondSentinel

一个改变了次席戍卫攻击行为的模组，共包含两个阶段，比原版更难，但又不会太难

A silksong mod that changes the action of second sentinel, containing two phases and making the fight harder, but not too hard for everyone to challenge!

# Installation

从thunderstore上下载文件，解压，然后放到BeplnEX/plugins文件夹里，模组需要silksong_modding-FsmUtil作为前置

Download the mod from thunderstore. Unzip the folder and put it at the BeplnEx/plugins folder.
Make sure you have the silksong_modding-FsmUtil mod as the dependency!

# Instruction for the mod:

次席戍卫现在有1500血，在800血时开启二阶段
不要用十字绣！，用十字绣时boss会立刻变招，这是一个bug但我很喜欢就保留了下来（变成了特性）
在挑战之前强烈建议备份存档或者使用不必要的存档，以免带来未知的bug

Second Sentinel now has 1500HP and phase2 starts in 800HP.
DON'T USE CROSS STITCH during the fight. The boss will change its attack way once if you use the cross stitch. It's a bug though but I like it and kept.
The mod might have bugs, so strongly recommend to backup your saves or use unnecessary save before fight and use refight mod.
