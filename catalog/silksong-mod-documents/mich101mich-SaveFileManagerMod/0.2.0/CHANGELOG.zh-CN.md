# 更新日志

本项目的所有显著变更都将记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/en/2.0.0/)，  
且本项目遵循 [Semantic Versioning](https://semver.org/spec/v2.0.0.html)。

## [0.2.0]

### 修改内容
- 移除了对 ModMenu 和 DataManager 的依赖。
- 将依赖项 BepInExPack 更新至 silksong_modding 版本。

### 修复内容
- 移除了对 I18N 的误标必需依赖。目前它已作为可选依赖，具体说明见 README 文件。

## [0.1.0]

### 新增功能
- 为每个存档槽位添加了“重命名”按钮，可用来为存档命名。
- 为每个存档槽位添加了“归档”按钮，可将存档归档到另一个槽位，或从归档中加载其他存档。
