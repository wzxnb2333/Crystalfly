# RandomTeleport

This mod teleports Hornet to a random room every 3 minutes by default.
If you get hit the timer will loose 10 seconds.
Both of these values can be changed in the mods config file.
You can also manually teleport Hornet by pressing the "P" key. This will NOT reset the timer.
The timer can also be paused/unpaued by pressing the "O" key.

Additionally there is also a Teleport on hit option.
If this is enabled, Hornet will be teleported to a random room every time she gets hit.
This option can also be toggled in the config file.


How to change values:
- Navigate to the games install folder
- Open BepInEx/config/io.github.fabbeyond.randomteleport.cfg
- Change the values and save the file
- Restart the game
