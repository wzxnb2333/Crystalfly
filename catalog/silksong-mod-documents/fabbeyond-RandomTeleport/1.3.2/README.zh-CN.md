# RandomTeleport

该模组默认每 3 分钟会将大黄蜂传送到一个随机房间。  
如果被击中，计时器将减少 10 秒。  
这两个数值都可以在模组配置文件中进行修改。  
你也可以通过按下 “P” 键手动传送大黄蜂。此操作不会重置计时器。  
此外，还可以通过按 “O” 键暂停或恢复计时器。

另外还提供一个“被击中时传送”的选项。  
如果启用该选项，每次大黄蜂被击中时都会被传送到一个随机房间。  
该选项也可以在配置文件中切换。

如何修改数值：  
- 进入游戏安装目录  
- 打开 BepInEx/config/io.github.fabbeyond.randomteleport.cfg  
- 修改数值并保存文件  
- 重新启动游戏
