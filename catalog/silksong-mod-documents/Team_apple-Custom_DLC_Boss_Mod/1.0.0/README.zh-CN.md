# 自定义DLC首领扩展  
一款针对《空洞骑士：丝之歌》的深度战斗模组，通过 BepInEx 和 Harmony 接口向游戏引擎注入全新的、极具挑战性的自定义首领遭遇。

## 主要特性  
* **自定义DLC首领战斗：** 与一个完全原创的、多阶段首领战对决，配备独特的AI行为模式。  
* **智能难度调整：** 首领会根据你当前激活的壳类变体和生命值阈值动态调整难度。  
* **模组管理器原生支持：** 完全优化，可与 Thunderstore 内部的其他自定义插件即时协同运行。

## 安装说明  
为了实现顺畅安装，我们强烈推荐使用 Thunderstore 模组管理器 或 r2modman。  

### 方案 A：自动配置（推荐）  
1. 打开你的 **Thunderstore 模组管理器** 应用。  
2. 在在线目录中搜索 `Custom DLC Boss Expansion`。  
3. 点击 **带依赖项安装**。  

### 方案 B：手动文件配置  
1. 从 Thunderstore 下载模组 `.zip` 归档文件。  
2. 找到你的 *空洞骑士：丝之歌* 安装路径。  
3. 将内容提取至以下路径内的本地目录中：  
`Silksong/BepInEx/plugins/`  
4. 确认 `SilksongBossMod.dll` 文件直接位于该文件夹内。
