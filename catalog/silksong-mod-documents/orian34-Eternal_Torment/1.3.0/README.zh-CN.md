丝之歌永恒折磨模组

版本 1.3

使用方法：将 dll 文件放入插件文件夹中。需要 BepInEx 5 与 ConfigManager。

# 永恒折磨

此模组会使每次受到伤害立刻导致你死亡。你需要在不被击中的情况下完成游戏，否则将死亡并重新尝试，直到成功为止。死亡不会结束本次运行。

可选配置：
死亡时保留一定数量的念珠，并从破除茧中获得一些贝壳碎片。使用最大生命值作为倍率（10 masks = 100% 念珠保留且获得 50 片贝壳碎片）。
