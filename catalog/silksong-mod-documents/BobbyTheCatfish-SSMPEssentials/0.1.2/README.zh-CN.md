# SSMP 必备组件

一个为丝之歌多人游戏（SSMP）提供的插件，增加了多个对多人游戏有用的工具。  
每个模块都可以通过命令禁用，因此即使你只想要其中一个功能，也可以使用它。

## 传送功能
是否曾想过快速传送到朋友身边，或者将所有人聚集到一个地点？那么你可真是幸运！

- `/tp <username>` 向其他玩家发送传送请求  
- `/tpa` (`/tpaccept`) 接收传送请求  
- `/tpd` (`/tpdeny`) 拒绝传送请求  
- `/back` 将你传送到上次传送或死亡前的位置  
- `/huddle` 将所有人传送到你所在的位置。需获得授权才能使用  
- `/huddle <username>` 将所有人传送到指定玩家的位置。需获得授权才能使用

## 观战/自由摄像
从其他玩家的视角观察 Pharloom 世界！只要你在同一个房间内，就可以查看任何玩家的视角。
此外，你还可以自由观战当前房间。

### 键位绑定
我建议你修改这些默认键位。你可以使用 BepInEx 配置管理器或 ModMenu。
- `2` - 观战上一位玩家
- `3` - 观战下一位玩家
- `4` - 退出观战/自由摄像模式
- `5` - 启用自由摄像

暂停游戏也会退出观战/自由摄像模式。

## 生命值条  
生命值条可以显示在玩家用户名上方。它们反映玩家的实际生命值条，显示当前生命值、缺失的面罩以及生命之罩。

## 死亡提示  
当你最终死亡时，游戏会发送一条死亡提示，通知其他玩家你的死亡。  
这些提示的样式与《我的世界》中的提示类似。

# 配置
`/essentials set <setting> <true/false>` (`/e set`) 会为所有玩家开启或关闭一个模块。

有效选项包括：
- `huddle` 开启或关闭执行 `/huddle` 的能力
- `tp` 开启或关闭执行 `/tp` 的能力
- `back` 开启或关闭使用 `/back` 的能力
- `tprequests` 若为 true，执行 `/tp` 需要一个 `/tpa` 响应；若为 false，玩家将立即被传送。
- `deathmessages` 开启或关闭死亡提示
- `healthbars` 开启或关闭所有生命条
- `spectate` 开启或关闭观看其他玩家的能力
- `spectateteam` 若启用，玩家只能观看其队伍中的其他玩家。
- `freecam` 开启或关闭使用自由摄像机的能力

默认情况下，所有选项（除观看队伍成员外）均启用。
