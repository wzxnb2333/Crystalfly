# 丝之歌全类型防反击  
本模组旨在让你在丝之歌中实现对所有伤害类型的完美防反击。

# 已知问题  
- 那个该死的、该臭的、该烂的伏特维姆球攻击，我根本找不到，我试了所有方法，根本无法修复，你们到底做了什么 TC  
- 有时 DamageHero 组件会被禁用，随后其父对象被销毁，而 DamageHero 会残留下来，无法对大黄蜂造成伤害，但仍然可以被格挡。显然它不应该可被格挡，不过这种情况只持续很短时间。可通过腐化管道、蚊子和第四合唱团掉落的岩石复现  
- 你甚至可以在烟雾路径处于非激活状态时格挡它  
- 赛斯对雷电工具有弱点，而且有时他没有接触伤害
