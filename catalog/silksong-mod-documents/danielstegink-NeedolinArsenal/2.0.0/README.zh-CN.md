# 大黄蜂武装

在游戏发布 2 个月后，我看到一个动画短片，其中大黄蜂将电压容器安装在她的纹章上，将其变成一把能播放摇滚音乐并发射激光束的电吉他。我心想：“我可以做出这样的东西。”

本模组通过为装备的工具添加新的协同效果，赋予纹章战斗能力。如果装备了以下任意一种或多种物品，模组将随机选择其一，并播放对应音乐片段并施加指定效果：

- 电压容器包裹丝线，使纹章播放摇滚音乐，并在大黄蜂周围生成闪电光束，如同特罗比奥烟花。
- 等离子药瓶包裹丝线，使纹章播放爵士音乐，并恢复生命值。
- 灵焰灯笼点燃丝线，使纹章播放乡村音乐，并在敌人附近生成灵焰。
- 针形徽章将丝线锐化为刀刃，使纹章播放传统日本三味线音乐，并对附近敌人生成交叉斩击。
- 蝙蝠镜（可装备多枚）反射光线至丝线，使纹章播放特罗比奥原声音乐，并在附近敌人身上生成烟花。
- 蜘蛛丝线降低纹章武装的冷却时间，使上述效果更频繁地触发。
