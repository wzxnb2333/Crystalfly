# Silksong Archipelago Randomizer

An Archipelago multiworld randomizer for *Hollow Knight: Silksong*.

## Required setup

Installing this package provides the Silksong game client. You must also install the matching `silksong.apworld` from the [v0.5.0 release](https://github.com/Batatvideogames/silksong-archipelago-randomizer/releases/tag/v0.5.0) into Archipelago's `custom_worlds` folder, then generate a new room with its Silksong YAML.

Use Archipelago 0.6.7 and keep the plugin, APWorld and generated room on compatible versions. Start a new Silksong save only after connecting it to the room. Vanilla saves remain separate.

See the [project repository](https://github.com/Batatvideogames/silksong-archipelago-randomizer) for setup details, releases, and issue reporting.
