# 丝之歌群岛随机化

一个专为 *空洞骑士：丝之歌* 设计的群岛多世界随机化模组。

## 必备设置

安装此包将提供丝之歌游戏客户端。您还必须安装对应的`silksong.apworld`来自[v0.5.0 release](https://github.com/Batatvideogames/silksong-archipelago-randomizer/releases/tag/v0.5.0)融入 Archipelago 的`custom_worlds`文件夹中，然后生成一个带有丝之歌 YAML 的新房间。

使用 Archipelago 0.6.7 并保持插件、APWorld 以及生成的房间在兼容版本上。只有在将存档连接到房间之后，才开始一个新的丝之歌存档。原版存档保持独立。

请参见 [project repository](https://github.com/Batatvideogames/silksong-archipelago-randomizer) 以获取设置详情、版本发布信息及问题报告方式。
