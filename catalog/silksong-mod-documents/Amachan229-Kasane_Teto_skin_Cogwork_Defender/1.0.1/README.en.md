Cosmetic mod for Hollow Knight: Silksong. Design by [DawNStar](https://x.com/0awN5tar)

Ver. 1.0.1

Installation:
1\. DownloadBepInEx 5 with Configuration Manager -> extract into root game folder -> run the game and exit (a BepInEx folder will appear).
2\. Download Silksong Customizer -> put it into 
\Hollow Knight Silksong\BepInEx\plugins\Customizer
(create the Customizer folder if it doesn’t exist) → run the game once and exit (a Mods folder will appear).
Like so:
\Hollow Knight Silksong\BepInEx\plugins\Customizer\Customizer.dll
4\. Download [CustomizerT2D.zip plugin](https://www.nexusmods.com/hollowknightsilksong/mods/203?tab=files) from this mod page (if skipped, some sprites won't change). Put into same \plugins\ folder like so:
\Hollow Knight Silksong\BepInEx\plugins\CustomizerT2D\CustomizerT2D.dll
Hollow Knight Silksong\
├─ BepInEx\
│  └─ plugins\
│     ├─ Customizer\
│     │  └─ Customizer.dll         (from Silksong Customizer)
│     └─ CustomizerT2D\
│        └─ CustomizerT2D.dll      (from this page)
└─ Hollow Knight Silksong_Data\
   └─ Mods\
      └─ Customizer\
         └─ CuteHornet <or your different modpack folder name>\            (pack folder or include into existing one, there can be only one folder) 
            ├─ Texture2D\          (PNGs for Texture2D)
            └─ ... other folders with sprite atlases, etc.
