# SilkShock

A Hollow Knight: Silksong mod that adds PiShock compatability via the MultiShock plugin DynamicShock.

## Dependencies
Requires:
- MultiShock v4 https://discord.com/channels/694191961170640926/1279980587792338964/1486174589158559816
- DynamicShock https://github.com/Aesteralias/DynamicShock

## Details

Currently Implemented Events:
- Taking Damage (Scales based on damage taken)
- Dying (Scales based on damage taken)
- Hard falling/Sprinting into walls (Default Disabled).
