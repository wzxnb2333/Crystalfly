# SilkShock

一个空洞骑士：丝之歌模组，通过 MultiShock 插件实现 PiShock 兼容性 DynamicShock。

## 依赖项
需要：
- MultiShock v4 https://discord.com/channels/694191961170640926/1279980587792338964/1486174589158559816
- DynamicShock https://github.com/Aesteralias/DynamicShock

## 详情

当前已实现的事件：
- 受到伤害（根据所受伤害量进行缩放）
- 死亡（根据所受伤害量进行缩放）
- 从高处坠落/冲刺撞墙（默认禁用）
