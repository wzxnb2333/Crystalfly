# ZaZa 在贝尔之家

此模组允许你在击败 Act 3 中的 Lost Garmond 后，将 ZaZa 带到你的贝尔之家。  
在与 Garmond 死亡处旁的 ZaZa 互动后，即可将其带入你的世界。当你进入贝尔之家时，他会位于床边的地垫上。

要更改 ZaZa 的位置，请按照以下步骤操作：  
1. 导航至你的 Silksong 游戏文件夹  
2. 进入 BepInEx 文件夹  
3. 打开 config 文件夹  
4. 打开 com.fabbeyond.zaza_in_bellhome.cfg  
5. 在正确的存档文件类别中修改 zazaPosition 的值  
6. 重启游戏  

位置说明：  
0：位于床边的地垫上  
1：位于床上方的栏杆上
