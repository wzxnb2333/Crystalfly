快速免责声明：这个模组对游戏剧情或进度没有任何实际影响，因此如果你担心这方面的问题，完全不用担心！此模组可以添加到已有的存档中而不会出现问题，我已在自己的存档上进行过测试。

也欢迎大家分享一下使用体验，帮助这个模组传播开来。

你们是否和我一样，在看到第十二建筑师的那一刻就立刻决定他/她是自己最喜欢的角色之一？

你们是否在购买了所有物品后，发现他们下一趟去工坊时已经死亡而感到难过？

你们是否在开启第 3 行动后前往工坊时，看到那令人不安的画面而意识到这一点？

你们是否曾希望这一切不必如此？

简单来说，这个模组会强制覆盖使他们死亡的存档标志，使其始终为 false，并相应地修改对话内容。是的，即使在第 3 行动中，他们依然会存活。

如果你们的存档中他们已经死亡，此模组将恢复他们的生命状态，因此该模组适用于已有存档。

此模组还为第十二建筑师添加了额外的对话内容。（如果你下载 v1.1.1 或更高版本）
