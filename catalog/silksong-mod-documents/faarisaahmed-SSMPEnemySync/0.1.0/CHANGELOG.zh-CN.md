# Changelog

## 0.1.0

首次发布。

### 新增功能
- 敌人双方共享：一个敌人，一个生命值池，一旦死亡则双方都死亡。首领敌人也包含在内。
- 启用了 SSMP 的实体系统，该系统已完整实现，但在 `ClientManager` 中将启动它的三个调用注释掉。
- 注册了丝之歌的敌人，因为 SSMP 内置的实体注册表是空洞骑士 1 的，本游戏中无匹配项。
- 生命值同步功能，这是 SSMP 实体系统从未具备的功能。

### 注意事项
- 直接读取 SSMP 的内部结构，因此与 **SSMP 0.3.1.0** 紧密绑定。在不同版本中，它会在启动时自动禁用自身并记录原因，而非导致游戏崩溃。
- 场景主机具有权威性。客户端报告自己造成的伤害，并在主机端应用，因此无论哪位玩家造成击杀都有效计数。
- 死亡通过游戏自身的死亡流程处理，而非直接将生命值设为零，以确保正确效果触发，并由 SSMP 进行同步复制。
