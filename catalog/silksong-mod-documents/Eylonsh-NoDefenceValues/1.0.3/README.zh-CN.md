# 无防御值

禁用敌方伤害加成（https://hollowknight.wiki/w/Damage\_Values\_and\_Enemy\_Health\_(Silksong)#Health\_Values\_and\_Damage\_Modifiers), 使所有敌方 1。

游戏启动时，应出现提示行：“No-Defence-Values: 已成功移除伤害加成”。

若出现以 “No-Defence-Values buildtime error:” 开头的错误信息，则说明该模组未生效，请联系我（Eylonsh）在 Discord 上咨询。

## 手动安装

与其他大多数模组一样，解压文件后，将 NoDefenceValues.dll 文件复制到你的 空洞骑士 丝之歌\\BepInEx\\plugins 文件夹中。
