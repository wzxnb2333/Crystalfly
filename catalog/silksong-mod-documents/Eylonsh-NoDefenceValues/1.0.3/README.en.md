# No Defence Values

Disables enemy damage modifiers (https://hollowknight.wiki/w/Damage\_Values\_and\_Enemy\_Health\_(Silksong)#Health\_Values\_and\_Damage\_Modifiers), making all of them 1.

when starting the game, the line "No-Defence-Values: Damage scaling has been successfully removed" should appear.

If instead an error line starting with "No-Defence-Values buildtime error:" shows up, the mod did not work, please contact me (Eylonsh) on discord.





## Manual Install

Like with most other mods, unzip the file, and copy the NoDefenceValues.dll file into your Hollow Knight Silksong\\BepInEx\\plugins folder.
