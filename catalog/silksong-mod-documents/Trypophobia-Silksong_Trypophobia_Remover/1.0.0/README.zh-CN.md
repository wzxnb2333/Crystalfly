## 本模组内容：

* 移除部分关卡中引发恐怖感的元素，这些元素出现在 3 中的几只敌人身上。

### 使用模组管理器安装

这是将 Silksong_Trypophobia_Remover 安装到游戏中的推荐方式。

1. 下载并安装 [Thunderstore Mod Manager](https://www.overwolf.com/app/Thunderstore-Thunderstore_Mod_Manager) 或 [r2modman](https://Timberborn.thunderstore.io/package/ebkr/r2modman/)。
2. 点击 [BepInEx's](https://thunderstore.io/c/tcg-card-shop-simulator/p/BepInEx/BepInExPack/) 页面顶部的 **使用模组管理器安装** 按钮。
3. 通过模组管理器运行游戏。
