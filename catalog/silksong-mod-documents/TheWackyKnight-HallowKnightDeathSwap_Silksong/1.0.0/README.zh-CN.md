# 空洞骑士 死亡切换 - 1.0

角色死亡时，可立即在 **空洞骑士** 与 **丝之歌** 之间切换。请确保两个游戏均已运行，并将其他所有窗口最小化或置于游戏窗口之后。

## 要求  
- 安装并保持空洞骑士与丝之歌最新版本  
- 两个游戏同时运行

## 特性
- 死亡时在空洞骑士与丝之歌之间切换  
- 自动窗口管理（活跃的游戏窗口会置顶）  
- 兼容标准游戏控制方式

## 其他说明  
- 无需额外安装其他模组  
- 其他窗口必须最小化或位于游戏窗口之后  
- 轻量级，当两个游戏同时运行时会在后台持续运行  

> **注意**：该模组不会提供任何游戏优势。它仅通过切换游戏来改变操作方式——不会影响任何物品、能力或存档。

## 已知问题
- 其他窗口覆盖游戏时可能导致窗口焦点丢失  
- 使用 Alt+Tab 可能会干扰自动切换功能
