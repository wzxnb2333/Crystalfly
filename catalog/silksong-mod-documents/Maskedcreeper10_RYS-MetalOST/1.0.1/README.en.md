# MetalOST

This mod replaces all of the games music, from the opening cutscene all the way to the end credits, with metal covers.

This includes things like:
- Boss tracks
- Area tracks
- Needolin (All variants)
- Cutscenes
- Psalm Cylinders
- And **so much more**.
