# MetalOST

该模组会将游戏中的所有音乐，从开场场景一直到片尾字幕，全部替换为金属风格的翻唱版本。

这包括以下内容：
- 首领主题曲
- 区域背景音乐
- Needolin（所有变体）
- 场景剧情音乐
- 诗篇圆筒
- 以及**更多内容**。
