# ReturnClawmaidens

A tiny mod to have clawmaidens back, they can be turned on/off in the config.

The value will get updated upon sitting on a bench.
The clawmaidens will not return to how they were before if you remove the mod, you will need to set the "HaveClawmaidens" value in the config.



## Manual Install

Like with most other mods, unzip the file, and copy the Clawmaidens.dll file into your Hollow Knight Silksong\\BepInEx\\plugins folder.
