Hard_Item_Randomizer w/ SceneRandom

这是一个将 Hard_Item_Randomizer 与 BloodDestroier 的 Scene Randomizer 整合在一起的配置包，安装后即可同时体验物品/技能/纹章/商店/开局全随机 + 场景出口随机化的完整丝之歌随机挑战。现已获得Scene Randomizer 作者BloodDestroier允许

###### ! 注意！Reset  Scene Seed --> Menu --> Mod Menu --> Fill new seed --> Regenerate !

###### !                Do not Exit Directly!  Ingame Menu --> Use Return To Bench!

###### !                Make Sure The    Hard_Item_Randomizer w SceneRandom config IS INSTALLED！

本包包含

Hard_Item_Randomizer

· 商店物品随机  
· 拾取点物品随机  
· 纹章随机  
· 技能随机  
· 开局劈方向随机（上/左/右）  
· 开局物品/能力随机  

Scene Randomizer by BloodDestroier

· 场景门/出口随机化  
· 按 F5 随机传送  
· 按 F7 查看当前场景  

配置说明

· 场景随机模组配置已预设，开箱即用  
· 配置文件路径：BepInEx/config/SceneRandomizer.cfg  

依赖模组

· SilksongItemRandomizer  
· SkillTriggerMod  
· StartingAbilityPicker  
· SceneRandomizer
