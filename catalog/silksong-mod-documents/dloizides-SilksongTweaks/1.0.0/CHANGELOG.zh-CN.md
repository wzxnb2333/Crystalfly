# Changelog

## 1.0.0

首次发布。四个调整整合在一个面板中，可通过 `F8` 或控制器上的后退/查看按钮打开。

- **返回死亡地点** — 重生后可回到死亡位置，带有可取消的倒计时
- **保留念珠** — 死亡两次不再摧毁你的第一个茧
- **最大面罩** — 将最大生命值从 1 提升至 20
- **受到伤害** — 调整承受伤害，从无敌状态变为比原版更难应对

每个调整都会报告是否成功挂钩游戏以及最后一次执行的时间，因此在游戏更新后无声失效的调整会变得可见而非不可见。

你的存档文件永远不会被写入。最大生命值通过拦截游戏读取实现，卸载后将保留一个原版存档，无需回滚。
