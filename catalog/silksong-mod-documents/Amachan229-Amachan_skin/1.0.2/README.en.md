Cosmetic mod for Hollow Knight: Silksong. This mod replaces the Hornet with the Amachan (OC).

Ver. 1.0.2

Installation:
1. DownloadBepInEx 5 with Configuration Manager -> extract into root game folder -> run the game and exit (a BepInEx folder will appear).
2. Download Silksong Customizer -> put it into 
\Hollow Knight Silksong\BepInEx\plugins\Customizer
(create the Customizer folder if it doesn’t exist) → run the game once and exit (a Mods folder will appear).
Like so:
\Hollow Knight Silksong\BepInEx\plugins\Customizer\Customizer.dll
3. Download [CustomizerT2D.zip plugin](https://www.nexusmods.com/hollowknightsilksong/mods/203?tab=files) from this mod page (if skipped, some sprites won't change). Put into same \plugins\ folder like so:
\Hollow Knight Silksong\BepInEx\plugins\CustomizerT2D\CustomizerT2D.dll
4. Put the Amachan folder into 
\Hollow Knight Silksong_Data\Mods\Customizer
Like so:
\Hollow Knight Silksong\Hollow Knight Silksong_Data\Mods\Customizer\CuteHornet <or your different modpack folder name>\Ability Get Thread Cln.....etc. 
5.  Download [Text Modder](https://thunderstore.io/c/hollow-knight-silksong/p/dr1/Text_Modder/) (mod for replacing text)  put it into 
\Hollow Knight Silksong\BepInEx\plugins\TextModder
(create the TextModder folder if it doesn’t exist) → run the game once and exit 
Like so:
\Hollow Knight Silksong\BepInEx\plugins\TextModder\SilkSongTextModder.dll

Hollow Knight Silksong\
├─ BepInEx\
│  └─ plugins\
│     ├─ Customizer\
│     │  └─ Customizer.dll         (from Silksong Customizer)
│     └─ CustomizerT2D\
│     │    └─ CustomizerT2D.dll      (from this page)
│     ├─ TextModder\
│        └─ SilkSongTextModder.dll     ( from TextModder )   
│     
│        
└─ Hollow Knight Silksong_Data\
   └─ Mods\
   │  └─ TextModder\         
   │         └─ ...  text documents
   ├─  Customizer\
         └─ CuteHornet <or your different modpack folder name>\            (pack folder or include into existing one, its better if you have single modpack folder)
