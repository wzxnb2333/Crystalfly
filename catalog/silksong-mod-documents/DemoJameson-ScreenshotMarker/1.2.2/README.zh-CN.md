一个丝之歌的模组，用于截图并标记在地图上。

# 安装  
1. 下载并安装 [BepinEx](https://github.com/bepinex/bepinex/releases)。  
2. 下载本模组，将 dll 文件解压到 `BepInEx\plugins` 文件夹。

# 安装
1. 下载并安装 [BepinEx](https://github.com/bepinex/bepinex/releases)。
2. 下载本模组，并将 dll 文件提取到 `BepInEx\plugins` 文件夹中。

# 使用
1. 键盘按P键截图并标记在地图中（可编辑 `BepInEx\config\mod.silksong.screenshotmarker.cfg` 文件改键）。
2. 手柄先按弹琴再按快速地图截图并标记在地图中。
3. 打开地图蓝色的标记即截图标记。从制图师手中购买一个标记工具后启标记模式，可以像普通标记一样进行移除，选中后按截图键、快速地图键、切换标记键均可以进行查看。
4. 截图保存在 `BepInEx\config\ScreenshotMarker\Save_X` 文件夹中，X代表第几个存档。

# 使用方法  
1. 键盘用户：按下 P 键进行截图并标记在地图上（可通过编辑文件 `BepInEx\config\mod.silksong.screenshotmarker.cfg` 修改按键）。  
2. 控制器用户：先按需olin按钮，再按快速地图按钮进行截图并标记在地图上。  
3. 打开地图后，蓝色标记为截图标记，可像普通标记一样删除。选择后，按下截图键、快速地图按钮或更改标记按钮即可查看截图。（需要从 Shakra 处购买至少一个标记才能启用放置模式）  
4. 截图保存在 `BepInEx\config\ScreenshotMarker\Save_X` 文件夹中，其中 X 代表存档槽位编号。
