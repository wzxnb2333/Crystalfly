# SLAPSONG

**Slap the bugs of Pharloom**
- Yes, including Kratt.
- Keybinds and settings in config with F1.
- Showcase YouTube [Video1](https://youtu.be/YqAhpuMjDtc) and [Video2](https://youtu.be/i-cc48x6zDE).

**Mod Installation**
- The mod comes with a folder named "CloakLessSlap" which contains the sprites.
- This folder alongwith the .dll file should be inside the folder (...BepInEx\plugins\Slapsong) for the cloakless slap to work.
