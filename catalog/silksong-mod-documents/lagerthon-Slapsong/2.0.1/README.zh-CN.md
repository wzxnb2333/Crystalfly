**模组安装说明**
- 模组包含一个名为 "CloakLessSlap" 的文件夹，其中存放了精灵图。
- 该文件夹需与 .dll 文件一同放置在 (...BepInEx\plugins\Slapsong) 目录下，才能使无披风击打功能生效。
