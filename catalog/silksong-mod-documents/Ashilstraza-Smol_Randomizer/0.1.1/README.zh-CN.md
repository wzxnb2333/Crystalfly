# Smol Randomizer

一个用于丝之歌的小型随机化模组。这不是一个物品随机化模组。它会随机化如下列出的各类内容。

使用方法：下载并启用您所选择的模组管理器中的 Silksong（或如果您喜欢手动安装，则可直接手动安装），启动 Silksong，然后进入模组选项。在该界面中，您可以根据个人喜好开启、关闭以及配置各项选项。目前这些设置是全局生效的，适用于您所选择的任意存档文件，但未来将支持按存档独立设置。

## 敌人货币

此模组会随机化击杀敌人时掉落的念珠和贝壳碎片的数量。  
<details>  
<Summary> 该选项包括：</Summary>

* 货币一致性  
	* 无 - 相同类型的敌人在被击杀时，其掉落的贝壳碎片和/或念珠数量会不一致。  
	* 场景 - 在同一场景中，相同类型的敌人可能掉落不同数量的物品，但在该场景内每次掉落的数量将保持一致。  
	* 敌人类型 - 相同类型的敌人每次被击杀时，都将固定掉落相同数量的贝壳碎片和/或念珠。

* 念珠数量  
	* 禁用 - 敌人将按照正常情况掉落其原本的念珠数量。  
	* 百分比 - 敌人将随机掉落其正常数量的百分比念珠。50% 表示减半，200% 表示翻倍。  
	* 固定值 - 敌人将随机掉落一个介于设定范围内的念珠数量。

* 念珠掉落百分比范围  
	* 最小值和最大值 - 敌人的念珠掉落量将被乘以一个介于这两个值之间的随机数值。

* 念珠掉落固定值范围  
	* 最小值和最大值 - 敌人的念珠掉落量将在这两个值之间随机生成。

* 贝壳碎片数量  
	* 禁用 - 敌人将按照正常情况掉落其原本的贝壳碎片数量。  
	* 百分比 - 敌人将随机掉落其正常数量的百分比贝壳碎片。50% 表示减半，200% 表示翻倍。  
	* 固定值 - 敌人将随机掉落一个介于设定范围内的贝壳碎片数量。

* 贝壳碎片掉落百分比范围  
	* 最小值和最大值 - 敌人的贝壳碎片掉落量将被乘以一个介于这两个值之间的随机数值。

* 贝壳碎片掉落固定值范围  
	* 最小值和最大值 - 敌人的贝壳碎片掉落量将在这两个值之间随机生成。  
</Details>

## 敌人伤害

此设置会随机化敌人和首领对大黄蜂造成的伤害，包括接触伤害和攻击伤害。  
<details>  
<Summary> 该选项包括：</Summary>

* 敌人伤害调整类型  
	* 禁用 - 敌人的伤害将保持正常。  
	* 移动 - 敌人的伤害将在给定数量范围内上下浮动。数值为 2 时，伤害可能在 -2 到 +2 之间变化。负值将被游戏视为 0。  
	* 范围 - 敌人的伤害将在一个范围内随机生成。

* 伤害一致性  
	* 无 - 相同类型的敌人在攻击时伤害不一致。  
	* 场景 - 相同类型的敌人在同一场景内伤害一致，但在其他场景中可能不同。  
	* 类型 - 相同类型的敌人每次攻击的伤害都完全相同。

* 伤害偏移  
	* 数量 - 伤害将在指定数值范围内进行偏移。

* 伤害范围  
	* 最小值和最大值 - 敌人的伤害将在这两个值之间随机生成。

* 敌人伤害最小值  
	* 开启或关闭 - 当开启时，敌人对大黄蜂造成的最低伤害将设为 1。

* 攻击伤害一致性  
	* 开启或关闭 - 此设置会使攻击的每个部分造成相同的伤害。若关闭，则攻击的各个部分可能造成不同的伤害。

</details>

## 敌人生命值

此功能会随机调整敌人和首领的生命值。需要注意的是，某些首领的阶段可能不会被正确影响，因为这只是一个简单地修改其生命值的操作。
<details>
<Summary> 此选项包括：</summary>

* 随机化生命值  
	* 无 - 所有敌人的生命值保持正常。  
	* 敌人 - 敌人的生命值被随机调整，首领的生命值保持正常。  
	* 首领 - 首领的生命值被随机调整，普通敌人生命值保持正常。  
	* 全部 - 敌人和首领的生命值均被随机调整。

* 生命值一致性  
	* 无 - 相同类型的敌人将拥有不一致的生命值。  
	* 场景 - 同一类型敌人在同一场景内生命值一致，但在不同场景中可能不同。  
	* 敌人类型 - 相同类型的敌人始终拥有相同的生命值。

* 敌人生命值范围  
	* 最小值与最大值 - 敌人的生命值将乘以一个介于这两个值之间的随机数值。

* 首领生命值范围  
	* 最小值与最大值 - 首领的生命值将乘以一个介于这两个值之间的随机数值。  
</details>

## 敌人大小

此设置会随机调整敌人的大小和首领的大小。  
<details>  
<summary> 该选项包括：</summary>

* 随机化大小  
	* 无 - 所有敌人和首领保持正常大小。  
	* 敌人 - 敌人的大小会随机调整，首领保持正常大小。  
	* 首领 - 首领的大小会随机调整，普通敌人保持正常大小。  
	* 两者 - 敌人和首领的大小都会被随机化。

* 大小一致性  
	* 无 - 相同类型的敌人可能具有不同的大小。  
	* 场景内一致 - 同一类型敌人在同一场景中大小一致，但在其他场景中可能不同。  
	* 类型一致 - 相同类型的敌人始终拥有相同的大小。

* 敌人生命值范围  
	* 最小值与最大值 - 敌人的大小将乘以介于这两个值之间的随机数值。

* 首领大小范围  
	* 最小值与最大值 - 首领的大小将乘以介于这两个值之间的随机数值。若数值过小或过大，可能导致首领战斗异常。建议最小值为 85%，最大值为 125%。  
</details>

## 大黄蜂的伤害

此功能（目前）会随机化大黄蜂的针刺伤害。  
<details>  
<summary> 该选项包括：</summary>

* 随机化大黄蜂伤害  
	* 开启或关闭 - 若应随机化大黄蜂针刺的伤害。

* 伤害一致性  
	* 无 - 每次攻击将具有不同的伤害值。  
	* 针头升级等级 - 每个针头等级将拥有不同的伤害值。  
	* 每次存档 - 每个针头等级将被相同量的数值改变。

* 伤害偏移  
	* 数量 - 伤害值将在 ± 此数值范围内随机偏移。例如，若该值为 3，则伤害值将在 -3 到 +3 之间。

* 大黄蜂伤害最小值  
	* 开启或关闭 - 若大黄蜂针刺的伤害应始终不低于 1。  
</details>

## 世界货币

此功能（目前）会随机调整特定墙壁掉落贝壳碎片的概率。这些是金属银色的墙壁，当被击中时可能掉落贝壳碎片。

建筑师纹章拥有与这些墙壁的特殊互动，本模组已对此进行考虑。
<details>
<Summary> 该功能的选项如下：</Summary>

* 掉落概率一致性  
	* 无 - 每次进入相同场景时，概率都会不同。  
	* 场景 - 在同一场景内，墙壁的掉落概率始终一致。  
	* 每个存档 - 整个存档中的概率保持一致。

* 墙壁贝壳碎片掉落概率  
	* 开启或关闭 - 若非建筑师纹章击中时的贝壳碎片掉落概率将被修改。

* 掉落概率倍率  
	* 最小值和最大值 - 荒野碎片的掉落概率将乘以介于这两个数值之间的随机值。

* 建筑师纹章贝壳碎片掉落概率  
	* 开启或关闭 - 若建筑师纹章击中时的贝壳碎片掉落概率将被修改。

* 建筑师纹铭掉落概率倍率  
	* 最小值和最大值 - 建筑师纹章击中的贝壳碎片掉落概率将乘以介于这两个数值之间的随机值。  
</details>

### 小细节

更改设置后，大多数效果需等到场景切换才会生效。

你可以通过进入模组选项 → 当前存档信息 → 重新生成或手动设定种子来修改当前存档的种子。

随机化设置可以被配置为让敌人始终拥有特定数值。例如：  
* 所有敌人都非常小。（虫子永远都是“小号”！）  
* 敌人死亡时掉落大量念珠和贝壳碎片。（不再需要反复刷怪！）  
* 敌人不造成任何伤害。（丝之歌现在变成了行走与奔跑模拟器！）  
* 首领拥有远超常人的生命值。（我无法对因频繁攻击卡玛莉塔而导致的腕部损伤负责！）
