# ReloadRosaryCannon

This mod allows players to reload the Rosary Cannon using the Architect Crest in Hollow Knight: Silksong.

## Features
- Enables Rosary Cannon reload via Architect Crest
- Lightweight and compatible with other mods

## Installation
1. Install BepInEx via Thunderstore Mod Manager
2. Drop `ReloadRosaryCannon.dll` into `BepInEx/plugins`
3. Launch the game
