快速重新着色为骑士斗篷颜色的空洞骑士：丝之歌HUD

:: 必需 ::

* BepInEx 5
* 补丁工作坊

:: 手动安装 ::

1. 下载 BepInEx 5，打开游戏文件夹并将 BepInEx 放置在其根目录下，运行游戏一次以创建必要的文件夹。

2. 下载 Ashiepaws 的 Patchwork，将包含 Patchwork.dll 的 Patchwork 文件夹放入 BepInEx/plugins 中，再运行游戏一次，让其创建相应的文件夹。

3. 将 KnightBlueHUD 文件夹放入 HollowKnightSilksong/BepInEx/plugins/Patchwork/Spritesheets

4\. 享受吧！
