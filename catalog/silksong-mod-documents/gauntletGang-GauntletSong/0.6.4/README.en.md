## Gauntlet Song

A map created through Architect that adds a ludicrous amount of gauntlets across the game. Features new enemies, bosses, quests, NPCs, altered progression, and a slightly different story. This map is a work in progress, and likely won't be fully completed for a long time. Information regarding development, updates, and a progression guide can be found in both the main Silksong mod Discord as well as in the Architect specific Discord.
