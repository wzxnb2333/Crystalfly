# 丝线缝合

**缚丝治疗，重新计时。** 当开始使用治疗缚丝的瞬间，你立即获得 **1 面具** —— 剩余治疗效果在缚丝完成时生效。总治疗量始终与原版一致：丝线缝合改变的是治疗的时机，而非治疗总量。

## 为什么？

在原版游戏中，中断一次缚丝会消耗你所有的丝线，并无法获得任何回报。使用丝之歌的缝合功能后，你提前获得的护目镜可能能帮你避免陷入绝境。

## 所有情况均被妥善处理

不仅限于基础的缚丝——每个纹章、工具和状态都具有正确且一致的行为（您可通过配置选择启用或禁用每种行为）：

| 情况 | 原版行为 | 丝之歌行为 |
|---|---|---|
| 正常缚丝 | 3 在完成时生效 | **1 立即生效 + 2 在完成时生效** |
| 多重缚丝 | 2 + 2 | 1 立即生效，随后为 1 + 2（或 2 + 1，可配置） |
| 预言者纹章 | 3 | 1 立即生效 + 2（包括空中持握的缚丝） |
| 架构师纹章（治疗缚丝） | 3 | 1 立即生效 + 2 |
| 架构师纹章（制作） | 无治疗效果 | 保持不变 |
| 魔女纹章 | 生命值吸血至 3/4 | 1 立即生效 + 生命值吸血至 2/3 |
| 动物纹章 | 愤怒状态治疗至 3/4 | 1 立即生效 + 愤怒状态治疗至 2/3 |
| 虫化状态 | 仅净化，治疗 0 | 1 立即生效 + 净化（可选择关闭的额外奖励） |
| 虫化状态 + 多重缚丝 | 净化后，再提供 2 | 1 + 净化 + 1（总效果不变） |
| 生命之血状态 | 治疗 1 | 保持不变（生命之血遮罩是独立系统） |
| 被诅咒的缚丝 | 无治疗效果 | 保持不变 |
| 中断的缚丝 | 所有丝线丢失，无治疗 | 所有丝线丢失，**保留即时遮罩** |

详细信息请参见捆绑的 `HEALING.md`。

## 可根据个人喜好配置

每个特殊情形都有其对应的开关，而每个开关的关闭状态均为原版行为：`WitchAdvance`，`BeastAdvance`，`ShamanAdvance`，`MaggotAdvance`，`MaggotMultibindAdvance`，`LifebloodAdvance`，以及多绑定分离模式。配置文件：`BepInEx/config/com.fabulator_k.silksuture.cfg`（首次启动时生成）。

## 安装

使用模组管理器，或手动操作：将 `plugins/` 的内容复制到 `BepInEx/plugins/SilkSuture/` 中。

## 欢迎反馈

这是一个 0.5.x 版本：机制已完整实现，所有边缘情况均已处理，但少数罕见组合的实地测试仍有限。如果发现任何治疗效果与表格中说明的数值有偏差——尤其是 **发霉 + 多缚丝** 或 **女巫纹章的发光“潜在治疗”面具**——请使用你的 `BepInEx/LogOutput.log` 提交反馈（它每次启动都会重置，因此请在启动后立即获取）。
