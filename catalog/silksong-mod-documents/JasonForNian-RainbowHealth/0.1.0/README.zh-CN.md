# 🌈 彩虹血条

**一个为《空洞骑士：丝之歌》打造的模组，将你的血条变为循环流动的彩虹色。**

## ✨ 特色功能

- 将默认的白色生命值遮罩替换为鲜艳的彩虹色。
- 将默认的白色生命面具替换为鲜艳的彩虹跑马灯。
- 与所有面罩数量动态配合工作——无论你拥有 5 个面罩还是完整的 10，彩虹图案都会流畅延伸。
- 动态适配所有面具数量——无论你是只有5个面具还是满配10个上，彩虹色都会跑马显示。
- 彩虹色可以像流动的旗帜一样平滑地在你的面具上滚动。
- 彩虹色彩可如流动横幅般在面具间平滑滚动。
- 通过简单的 BepInEx 配置控制颜色循环的速度。
- 通过简单的 BepInEx 配置控制色彩循环的速度。
- 完全为外观效果；不会影响游戏平衡或成就。
- 纯外观向模组，不影响游戏平衡或成就获取。

## ⚙️ 配置 | 配置（实时修改）

**你可以在游戏内直接调整彩虹行为，无需编辑任何文件！**  
**You can tweak the rainbow behaviour in-game without editing any files!**

需要安装 **BepInEx** （在游戏内按 `F1` 打开菜单）。  
Requires **BepInEx** (press `F1` in-game to open).

| 设置 设置 | 描述 描述 | 默认值 默认值 |
|----------|-----------|---------------|
| **EnableRainbow**<br> 启用彩虹跑马灯 | 开启/关闭彩虹跑马灯动画。<br> Toggle the scrolling rainbow animation ON/OFF. | `Enable` |
| **Speed**<br> 跑马灯速度 | 调整彩虹滚动的速度。<br> Adjust the scrolling speed of the rainbow. | `5.0` |

- Speed `5.0` 为默认平滑速率；数值越高流动越快。  
  速度 `5.0` 是默认平滑速率；更高值 = 更快的流动。

所有更改都会**立即生效**，无需重启游戏。  
All changes take effect **instantly** – no restart needed.
