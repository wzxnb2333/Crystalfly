# 🌈 Rainbow Health - 彩虹血条

**A mod for *Hollow Knight: Silksong* that transforms your health masks into a cycling rainbow spectrum.**

**一个为《空洞骑士：丝之歌》打造的模组，将你的血条变为循环流动的彩虹色。**

---

## ✨ Features | 功能特色

- Replaces the default white health masks with a vibrant rainbow.
- 将默认的白色生命面具替换为鲜艳的彩虹跑马灯。
- Works dynamically with all mask counts – the rainbow pattern stretches gracefully whether you have 5 masks or a full 10.
- 动态适配所有面具数量——无论你是只有5个面具还是满配10个上，彩虹色都会跑马显示。
- the rainbow colors can smoothly scroll across your masks like a flowing banner.
- 彩虹色彩可如流动横幅般在面具间平滑滚动。
- control how fast the colors cycle via a simple BepInEx config .
- 通过简单的BepInEx配置控制色彩循环的快慢。
- Completely cosmetic; does not affect gameplay balance or achievements.
- 纯外观向模组，不影响游戏平衡或成就获取。

---

## 📥 Installation | 安装方法

1. Make sure you have the latest version of the **BepInEx** installed.  
   确保你已安装最新版本的 **BepInEx**。
3. Extract the contents into your `BepInEx/plugins` folder.  
   将压缩包内容解压至 `BepInEx/plugins` 文件夹。

## ⚙️ Configuration | 配置（实时修改）

**You can tweak the rainbow behaviour in-game without editing any files!**  
**你可以在游戏内直接调整彩虹行为，无需编辑任何文件！**

Requires **BepInEx** (press `F1` in-game to open).  
需要安装 **BepInEx** （在游戏内按 `F1` 打开菜单）。

| Setting 设置 | Description 描述 | Default 默认值 |
|-------------|-----------------|----------------|
| **EnableRainbow**<br>启用彩虹跑马灯 | Toggle the scrolling rainbow animation ON/OFF.<br>打开/关闭彩虹跑马灯动画。 | `Enable` |
| **Speed**<br>跑马灯速度 | Adjust the scrolling speed of the rainbow.<br>调整彩虹滚动的速度。 | `5.0` |

- Speed `5.0` is the default smooth rate; higher values = faster flow.  
  速度 `5.0` 为默认平滑速率；数值越高流动越快。

All changes take effect **instantly** – no restart needed.  
所有更改都会**立即生效**，无需重启游戏。
