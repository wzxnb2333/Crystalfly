# 双倍敌人

**使每一个敌人、战场和首领战都变为两倍！**  
通过同步敌人和可配置的难度选项，迎接加倍的挑战。

目前同类模组中最为稳定且功能最丰富的模组。

## 它的功能

该模组会克隆所有使用 `HealthManager` 组件的游戏内实体——实际上会将所有敌人和首领数量翻倍（或倍增）。

它包含以下选项：
- **调整倍数**，以控制每个敌人被生成的副本数量。
- **按类型过滤**（普通敌人、竞技场敌人、首领）。
- **启用克隆首领之间的共享生命值**，以实现同步战斗。
- **启用危险模式**，使竞技场也受到共享生命值的影响。

## 共享生命值

共享生命值是一个可选功能，它将克隆首领的生命值连接起来，使战斗更加动态和一致。  
启用后，所有首领的副本将共享相同的有效生命值——攻击其中一个，也会对其他副本造成影响。

该功能**默认开启**，如需关闭，可在配置文件中进行设置。  
部分特殊首领会自动被排除，以确保游戏稳定性。

## 配置

在首次启动游戏并加载了模组后，可以编辑配置文件，位置在  
`BepInEx/config/com.adwamogus.skdoubleenemiesmod.cfg`

主要选项：
- **倍率：** 修改生成的克隆体数量。
- **敌人过滤器：** 开启或关闭竞技场、首领或普通敌人。
- **共享生命值：** 开启或关闭首领生命值同步功能。

## 兼容性

- 与大多数其他敌人或生成模组兼容。  
- 与基于 BepInEx 的设置完全兼容。

## 安装

1. 安装 **BepInEx**（参见指南 [BepInEx](https://docs.bepinex.dev/articles/user_guide/installation/index.html)）。  
2. 下载本模组并将其 `.dll` 文件提取到你的  
   `BepInEx/plugins` 文件夹中。  
3. 启动游戏并享受混乱吧！

## 难度说明

本模组**显著提升游戏难度**，可能导致极为艰难的挑战。  
如需使用，建议搭配品质生活或平衡类模组（e.g. 无限碎片）。
