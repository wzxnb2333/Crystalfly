# 所有工具均可解锁

允许在正常游戏玩法中解锁所有工具。当满足特定条件时，玩家将获得相应工具，或者当大黄蜂靠近长椅足够近时，会弹出提示（包括加载一个大黄蜂坐在长椅上的存档）。每个工具的解锁都可以在插件配置文件中单独启用；默认情况下所有解锁功能均被禁用。已被重新解锁的工具降级版本不会覆盖其升级版本。

## 

### 当所有配置选项均开启时...

- 当获得一枚丝线射击时，其他丝线射击将被解锁。
- 当获得死虫的钱包或贝壳背包时，另一个将被解锁。
- 当获得曲爪（降级版）时，曲镰刀将被重新解锁。
- 当获得德鲁伊之眼（降级版）时，德鲁伊之眼将被重新解锁。
- 当获得爪镜（降级版）时，爪镜将被重新解锁。
- 进入第 3 关卡时，陷阱设置者将被重新解锁。
- 当获得等离子腺体时，针剂瓶将被重新解锁。
