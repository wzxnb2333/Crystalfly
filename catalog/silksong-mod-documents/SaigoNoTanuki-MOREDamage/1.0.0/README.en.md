A Hollow Knight: Silksong mod that allows user to set incoming damage multiplier.

Dependencies:
BepInEx 5.

How to use:
-Install zip file.
-Extract zip.
-Paste unzipped folder with the .dll in BepInEx/plugins. (Usually in the game's root directory)
-Launch the game.
 OR,
-Use a Mod Loader like R2ModMan.
