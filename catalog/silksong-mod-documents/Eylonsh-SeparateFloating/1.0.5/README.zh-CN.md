# SeparatedFloat

一个模组将浮空动作从跳跃按钮分离出来，改为使打开物品栏的祈愿按钮执行浮空操作。

开放库存愿望功能已禁用！要打开库存愿望面板，请从其他面板向侧面滚动。

这意味着你需要重新绑定“任务”按钮才能重新绑定浮空功能。

## 特性：

现在可以持续按住漂浮按键，系统会在可能的情况下自动激活漂浮！如果在继续按住按钮的同时因其他动作（如冲刺、攻击、缚丝等）而取消了漂浮，那么在 0.25 秒之后且该动作的动画结束时，漂浮将重新开始。

目前在漂浮状态下无法进行二次跳跃，未来可能会添加此功能。你可以在松开漂浮按键后进行二次跳跃。

## 问题：

- 如果你在漂浮状态下使用建筑师的“缚丝”能力，并持续按住漂浮按钮，漂浮状态将不会重新激活，且大黄蜂的角色图像会卡住。当释放漂浮按钮或触发其他动画时，该问题会自行解决。

- 这可能是唯一会导致此行为的操作，但有可能我遗漏了另一个操作。错误信息应为：“\[Error : Unity Log] 无法解析动画剪辑：Float”。
- 本模组的“故意”错误提示均以“Separate-Float runtime/buildtime error:”开头。这些提示不应出现，如果出现了，请通过 Discord 联系我。

\## 与其他模组的兼容性

本模组仅修改与角色控制相关的内容。因此，大多数模组应能正常工作。
更改了角色控制（非跳跃操作）的模组可能仍可正常使用，但可能会出现类似上述的精灵加载错误，这些错误不应造成严重问题。
更改了跳跃或漂浮控制的模组则显然无法与本模组兼容。

## 手动安装

与其他大多数模组一样，解压文件后，将 SeparateFloating.dll 文件复制到你的 空洞骑士 丝之歌\\BepInEx\\plugins 文件夹中。
