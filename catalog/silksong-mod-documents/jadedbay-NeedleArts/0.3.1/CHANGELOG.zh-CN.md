# Changelog

## v0.3.1
- 修复与其他 Needleforge 模组在添加自定义工具时的兼容性问题

## v0.3.0
- 为 Vesticrest 添加了方向性 NeedleArt 插槽（最多可装备 3 针艺）
- 移除了之前的解锁逻辑（现使用 SimpleUnlock 逻辑）

> <strong>开发者评论：</strong>
>
> 我最初为这个模组的设想是将其作为游戏正常进度的一部分，例如随着时间推移逐步解锁技艺，并最终打造一个以 NeedleArts 为核心的自定义纹章。
> 我决定移除解锁系统，因为它迫使我实现了一些奇怪的自动装备功能，使用起来并不直观。
> 要制作一个完全自定义的纹章需要相当多的工作量，我意识到自己永远无法在短期内将其打磨到满意的状态。因此，目前我将允许任何纹章使用所有 3 NeedleArt 插槽。
