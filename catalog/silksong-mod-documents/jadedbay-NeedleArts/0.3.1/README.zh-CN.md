# NeedleArts

一个空洞骑士：丝之歌模组，新增了从任意纹章装备多个针刺攻击的能力。

*Thunderstore*：https://thunderstore.io/c/hollow-knight-silksong/p/jadedbay/NeedleArts/

*GitHub*：https://github.com/jadedbay/NeedleArts

## 特性  
- 增加一种新的工具类型 NeedleArt（橙色），并在 Vesticrest 中添加 3 槽位。  
- 为每个纹章增加一个 NeedleArt 工具，装备与纹章关联的工具时，当方向输入匹配将使用该纹章的 Needle Strike。

### 配置  
- UnlockNeedleArts：立即解锁 Needle Strike 及所有 Needle Arts。

## 安装

通过 Thunderstore 模组管理器安装，或手动安装如下：
1. 安装最新版本的 [BepInEx](https://github.com/BepInEx/BepInEx/releases)
2. 下载所有依赖项并按照其安装说明进行操作。
3. 从 [Thunderstore](https://thunderstore.io/c/hollow-knight-silksong/p/jadedbay/NeedleArts/) 或 [GitHub](https://github.com/jadedbay/NeedleArts/releases) 下载 `.zip` 文件。
4. 将 `.zip` 文件解压到你的 `BepInEx/plugins` 文件夹中。
