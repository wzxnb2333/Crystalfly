Take up your duster and start cleaning out Pharloom!

## REQUIRED: 

- BepInEx 5
- Patchwork

## MANUAL DOWNLOAD: 

1) Download BepInEx 5 and place it at the root of the gamefolder. After running it once you should have all the other folders needed. 
2) Download Patchworker (by Ashiepaws) and place the Patchwork.dll it into BepInEx/plugins, and the run the game again so that it creates it's folders. 
3) In case the mod doesn't pick up automatically you can manually add it: HollowKnightSilksong/BepInEx/plugins/Patchwork/Spritesheets
