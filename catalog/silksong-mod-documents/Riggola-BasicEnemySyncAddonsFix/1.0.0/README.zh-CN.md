# BasicEnemySyncAddonsFix

空洞骑士的非官方补丁工具[BasicEnemySync](https://thunderstore.io/c/hollow-knight-silksong/p/Brothergaming52/BasicEnemySync/). 这是一个独立的BepInEx插件并需要原模组。它不会替代`EnemySyncing.dll`.

它使本地茧状态立即显现，为其他玩家及延迟加入的玩家重复茧状态，并保留复活保护机制，在茧状态下抵御普通伤害。此外，它还会抑制已记录死亡敌人的重新出现以及落地岩石接触造成的伤害。

所有玩家都应安装相同的插件版本。在使用本插件时，请禁用较旧的 `BasicEnemySyncCocoonsReviveFix` 包。

这些同步修复需要在场景切换时进行多人游戏测试。详见 [CHANGELOG.md](CHANGELOG.md) 中的详细变更。
