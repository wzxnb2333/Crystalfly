# 使用方法

安装模组后，在任意游戏模式下创建一个新文件。如果安装成功，你会知道 :)

# 动机

当我玩《空洞骑士》时，我几乎只使用针进行攻击。它造成的每秒伤害（DPS）更高，而这也是我最熟悉、最舒适的玩法。因此，当我开始玩《丝之歌》时，我也做了完全相同的选择：我从未真正使用过丝线技能或红色工具，仅在测试它们效果时例外。我总是用针不断攻击一切敌人，直到它们死亡。这种方法非常有效，我几乎没有任何困难地通关了游戏。我认为没有任何一次战斗让我死得更惨，最多只有 15 次，且仅有少数几次超过 10。我从未使用过丝食者，也从未需要采集念珠来购买长椅或快速传送站。总体而言，我发现游戏的挑战性明显不足。

如今我已经在《丝之歌》中投入了数百小时的游戏时间，问题变得更加严重。我绝不会考虑在战斗中使用工具，因为我清楚地知道，仅凭针就能一次性击败所有敌人。为什么要尝试其他方式呢？甚至我不再购买大多数长椅，因为我知道自己短期内不会死亡。一旦你玩得足够多，游戏中的许多系统就会变得对你毫无意义。你很少会感受到对游戏挑战的尊重，也很难获得原本设计的体验。因此，回放的乐趣和记忆性远不如随意游玩时那样令人难忘。

这个模组改变了这一切。它让我感觉仿佛又是在第一次接触游戏；同时，我感觉自己如今拥有了婴儿般的精细操作能力。这种感觉非常有趣。如果你也曾有过类似的感受，那么这个模组绝对适合你。

# 更新内容

- 你的最大生命值初始为 2（此前为 5）。
- 使用针攻击的伤害上限为 1（此前为 5）。此限制在所有其他加成之后生效，因此不受针类升级、元素增益、带刺手镯等影响。其他所有攻击（包括针刺攻击）均保持不变。
	- 如果玩家在最近 6 秒内曾挑衅，则该伤害上限提升至 2。
- 掩具碎片和卷轴碎片不再增加你的最大生命值和丝线。现在，获得额外的掩具或卷轴将分别获得 1000 和 500 念珠。
- 死亡时，你将恢复自上次存档以来所使用的所有工具。

# 为何做出这些改动？

这可能听起来像是奇怪的改动，因此让我解释一下我为何设计模组如此。

*最大生命值降低*：显而易见的是，当你仅有 2 点生命值时，会轻易被大量攻击一击必杀。这一改动受到《黑暗之魂》系列游戏的启发，在这些游戏中，许多首领的攻击都超过你一半的生命值，甚至能一击致死，这使得战斗更具紧张感和刺激性。Team Cherry 在丝之歌中广泛使用双倍伤害时，很可能也是出于类似思路，但我将这一理念推向了更极端的程度。在大师模式下，*任何* 攻击都可能让你死亡。

为什么不直接降到 1 点生命值呢？我认为那样对游戏体验来说会过于严苛。它会抹平单倍伤害与双倍伤害攻击之间的差异，而由于双倍伤害攻击通常速度较慢且更容易预判，因此它们的危险性反而会低于同类攻击。我们不希望出现这种情况。此外，在 2 点生命值时受到一次单倍伤害攻击，会带来一个有趣的抉择：你是否冒险使用丝线来应对额外伤害以击败威胁？还是选择稳妥地慢慢收集足够丝线，恢复到满血状态？当生命值仅为 1 时，这种复杂性便消失殆尽，你只能被迫永远不被击中。

当然，生命值越低意味着死亡的次数会更多。这是一件好事。它让你能以更慢的节奏游玩，也意味着你会频繁失去念珠。这意味着你需要探索得更多，才能积累足够财富来购买物品。说白了，就像你在休闲通关时那样。我认为沉浸于这个精心打造的世界细节中，比一味地快速推进更有乐趣。（当然，快速通关也很有趣，我并不否认。如果我真的能完成速通，我的看法或许会不同。）

*弱针攻击*：这一改动的初衷很简单——我希望你大部分伤害都来自丝线技能和红色工具。在原版游戏中，即使你把所有丝线都投入丝线技能中，它们也仅占你总伤害的一半以下。相比之下，在《空洞骑士》中，法术构筑的伤害主要来源于法术本身。现在，使用丝线长矛时，丝线技能的伤害占比已超过 75%。在大师模式下，针的唯一真正用途是收集丝线，而丝线技能才是你真正的输出来源。

这一改动还带来另一个好处：它迫使你使用高投入型攻击。这是《黑暗之魂》系列战斗的核心理念之一，要求你认真研究敌人的动作模式，并找到突破口。你在平时休闲游玩丝之歌时可能从未这样做过，因此这将大大增加你的游戏深度。但谁说首领才是最大的威胁呢？在丝之歌中，敌方战场占据着重要地位，在大师模式下，这种存在感将变得更为显著。掌握多个敌人行为模式的难度远高于理解首领，而敌方战场正是本模组的 true 技能考验。

*挑衅增益*：请回忆，在游戏初期针是你的唯一伤害来源。苔藓母亲拥有 120 点生命值，仅靠针击败她需要耗费大量时间。这一改动旨在让这场战斗更轻松一些，尽管在其他地方可能并无太大作用。

*工具补给机制*：丝之歌战斗中常被提及的一个问题是，壳碎片数量有限，会削弱你使用红色工具对抗强敌的意愿。如果你频繁死亡，就会耗尽碎片，导致敌人变得异常困难。通过这一改动，这种情况将不再发生。红色工具作为不依赖丝线（通常）且具备更远攻击距离的补充手段，能很好地与丝线技能配合。丝线技能仍将是你的核心构筑，但这些工具将成为你装备中不可或缺的一部分。

# 其他建议

- 选择游戏中的风景路线：尽早完成爬行竞技场，击败分裂姐妹，乘坐电梯进入地下工坊等。你可能错过了比想象中更多的内容。
- 作为额外挑战，你可以跳过获取破碎面罩或等离子药瓶。也许也可以推迟获得针状升级。
- 在通关前先击败第一位罪人。这会让你看到更多区域，并能使用最炫酷的丝线技能对抗最终首领。
- 考虑搭配使用 [Moorlap](https://github.com/flibber-hk/Silksong.Moorlap)（镜像法洛姆）模组。这会迫使你重新建立肌肉记忆并重新思考导航方式。其效果远超你的预期。
