# Changelog

## 1.1.1

目标版本：`1.1.1`。

### 新增功能

- 增加了独立的 `CrestComponentLab` 针forge 测试模组，具备真正无害的攻击默认设置，并拥有独立的核心动作集、冲刺斩、蓄力斩、普通缚丝和上段缚丝提供配置。
- 增加了干净配置安装、静态反依赖验证以及聚焦组件隔离的游戏玩法矩阵。

- 增加了一个实验性的纹章组合基础，包含功能描述、配方、依赖/冲突验证、结构化诊断以及逆序回滚事务。
- 增加了一个基于实证的原版功能目录，涵盖标准攻击槽位、动画/音效配置，以及目前所理解的猎手、流浪者、收割者、野兽、祭司和女巫的行为模式。
- 增加了一个可复用的 Mono.Cecil 检查工具，并生成了用于纹章状态、配置字段及依赖纹章的调用点的托管 IL 库。
- 增加了运行时配置组快照，能够区分物理纹章、当前提供者、移植宿主组以及当前组的对象身份。
- 增加了逆向工程和框架架构文档，以及仅针对框架的测试。

### 修复内容

- 将虚空的基底纹章切换器修改为显示建筑师、祭司、野兽和女巫，同时保留虚空纹章 IDs 所需的提供者 0.4.4。诅咒不再可选或被视为女巫身份；它仅作为原模组私有的女巫家族启动前的基底，待真正的女巫/鞭子运行时提供者应用后才生效。
- 将抽象的 `ToolBase.IsEquipped` Harmony 目标替换为其具体的 `ToolCrest` 实现，使实验室能够正常加载而无需 `BadImageFormatException`。
- 阻止了 `None` 核心直接进入猎手下斩或遗漏 null 斩击/伤害组件，从而避免触发 `HeroController.Attack` 异常。
- 增加了实时配置检测功能，并通过原子操作、长椅入口/出口门控实现配方激活。
- 预安装了特殊缚丝 FSM 路径，使其提供者可在同一门控下动态变更。
- 移除了一个被遗忘的规划说明。

## 1.1.0

### 新增功能

- 增加了独立的 `CrestComponentLab` Needleforge 测试模组，具备真正无害的攻击默认设置，并拥有独立的核心动作集、冲刺斩、蓄力斩、普通缚丝和上段缚丝提供配置。
- 增加了干净配置的安装方式、静态反依赖验证以及聚焦组件隔离的游戏玩法矩阵。

- 增加了一个实验性的纹章组合基础，包含功能描述、配方、依赖/冲突验证、结构化诊断以及逆序回滚事务。
- 增加了一个基于实证的原版功能目录，涵盖标准攻击槽位、动画/音效配置，以及目前所理解的猎手、游荡者、收割者、野兽、祭司和女巫的行为模式。
- 增加了一个可复用的 Mono.Cecil 检查工具，并生成了用于纹章状态、配置字段及依赖纹章调用点的托管 IL 库。
- 增加了运行时配置组快照，能够根据对象身份区分物理纹章、当前提供者、移植宿主组和当前组。
- 增加了逆向工程与框架架构文档，以及仅针对框架的测试。

### 修复内容

- 将虚空的基底纹章切换器修改为显示建筑师、祭司、野兽和女巫，同时保留虚空纹章 IDs 所需的提供者 0.4.4。诅咒不再可选或被视为女巫身份；它仅作为原模组私有女巫家族启动前的基底，待真正的女巫/鞭子运行时提供者加载后才生效。
- 将抽象的 `ToolBase.IsEquipped` Harmony 目标替换为其具体的 `ToolCrest` 实现，使实验室能够正常加载而不再出现 `BadImageFormatException`。
- 阻止了 `None` 核心直接进入猎手下斩或导致 null 斩击/伤害组件频繁抛出 `HeroController.Attack` 异常。
- 增加了实时配置检测功能，支持原子操作及长椅进入/退出触发的配方激活。
- 预安装了特殊缚丝 FSM 路径，使其提供者可在同一门限下动态变更。

## 1.0.0

- 增加了完整的基础纹章攻击集移植，并支持安全的长椅门控切换。
- 恢复了在装备虚空纹章时，猎手专注度缩放、流浪者暴击几率、收割者收获转换、战士怒气以及祭司法术/缚丝行为。
- 恢复了兼容的蓄力斩、挑战、语音、咆哮、攻击和缚丝音频路径。
- 修复了影之冲刺动画回退问题，移植了攻击碰撞框，修正了蓄力斩着色、纹章持久性以及虚空缚丝无敌/治疗冲突。
- 增加了 ModMenu 控制设置、游戏玩法调试选项和诊断日志功能。
- 增加了埃里曼蒂斯重新设计的虚空纹章艺术图及六槽布局。
- 修复了红色工具与丝线技能需要特定插入顺序的问题；现在最多三个可使用任意虚空槽位，施法优先级遵循上、中立和下中心脊的位置。
- 修复了虚空纹章的橙色大黄蜂模型着色器仅在存档加载时可靠生效，在游戏过程中无法关闭的问题；现在实时更改会保留独立配置的橙色光环。
