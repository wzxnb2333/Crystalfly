# 丝之歌-蜜液过敏模组  
一个有趣且无用的丝之歌模组。它新增了一个功能：如果大黄蜂在半路之家从纹章处购买蜜液，她会昏倒。  
这或许在某些 YouTube 视频的场景中会是个不错的实用功能，姑且这么说。  
该模组可以进行大量配置。

# 手动安装
将 `NectarAllergic.dll` 从 `NectarAllergic.zip` 中取出，放入 `BepInEx\plugins`。

将文件夹 `Plugins` 从 `silksong_modding-AssetHelper-1.3.0.zip` 中取出，放入 `BepInEx\plugins`。

下载 AssetHelper 的所有依赖项。

将 `Silksong.I18N.dll` 从 `silksong_modding-I18N-1.0.2.zip` 中取出，放入 `BepInEx\plugins`。

将文件夹 `patchers` 从 `MonoDetour-MonoDetour_BepInEx_5-0.7.12.zip` 中取出，放入 `BepInEx\patchers`。

将文件夹 `core` 从 `MonoDetour-MonoDetour-0.7.13.zip` 中取出，放入 `BepInEx\core`。

完成。

# 配置
它被称为 `com.sealofapproval.nectarallergic.cfg`，包含 3 个设置。

其中一个用于切换大黄蜂在饮用蜜露后是否受到伤害（她将剩下 1 点生命值），  

其中一个用于切换大黄蜂是否直接死亡，  

还有一个用于调整音效的音量（因为我已根据个人习惯进行了调整）。

要更改某个设置，只需将每个“段落”最后一行的值替换为另一个值即可。

设置示例： https://youtu.be/jEpwU75WspA
