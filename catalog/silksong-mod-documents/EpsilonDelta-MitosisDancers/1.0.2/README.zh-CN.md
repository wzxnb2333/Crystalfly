## 安装说明

### 手动下载
1.  [Download and install BepInEx.](https://docs.bepinex.dev/articles/user_guide/installation/index.html)
2. 确保游戏已运行至少一次，以便在 `BepInEx` 文件夹中生成一个 `plugins` 文件夹，该文件夹位于游戏可执行文件旁边。
3. 从上述列出的任一来源下载 .zip 文件。
4. 将 .zip 文件解压到生成的 `plugins` 文件夹中。
5. 启动游戏并享受吧！
