# 无限工具与念珠模组

在丝之歌中获得无限的丝线碎片、念珠和液体补给，完全可配置以启用或禁用每种资源。

---

## 它的功能

**无限工具与念珠模组** 为《丝之歌》提供了无限资源：

- **贝壳碎片** – 无限的灵魂碎片  
- **念珠** – 无限的念珠  
- **液体补给** – 无限的跳蚤酿造液和等离子补给液  

---

## 配置

安装模组后首次启动游戏，即可编辑位于  
`BepInEx/config/com.adwamogus.infintetoolsandrosaries.cfg`

上述所有功能均可以在配置文件中关闭

## 安装

1. 安装 **BepInEx**（参见指南 [BepInEx](https://docs.bepinex.dev/articles/user_guide/installation/index.html)）。  
2. 下载本模组并将其 `.dll` 文件提取到你的  
   `BepInEx/plugins` 文件夹中。  
3. 启动游戏并享受吧！
