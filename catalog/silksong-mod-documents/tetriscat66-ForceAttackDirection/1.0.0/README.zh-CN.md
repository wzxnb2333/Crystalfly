# 强制攻击方向

允许你强制将攻击方向设置为向上、向下或水平。同时包含一个选项，可禁用地面冲刺时的攻击。

此模组的一些使用场景包括挑战模式运行、不需要一直按住跳跃键进行跳跃的平台区域，以及跳弹效果。

## 配置设置  
#### “攻击方向”  
- 可设置为“NotForced”、“水平”、“向上”或“向下”，以改变强制的攻击方向。  
- 如果使用 BepInExConfigurationManager，此设置可随时更改，并会立即在游戏中更新其效果。  
#### “冲刺攻击”  
- 可设置为“NoAttack”或“SprintAttack”，以选择性地阻止冲刺攻击。  
- 如果使用 BepInExConfigurationManager，此设置可随时更改，但仅在靠近长椅时才会更新其效果（无需实际坐在长椅上）。这是因为该行为涉及修改冲刺 FSM，出于性能考虑，可能不应频繁执行。
