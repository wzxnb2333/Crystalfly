# FreeCamera 禁用后出现黑屏问题  
使用 FreeCamera 克隆功能  

禁用屏幕后会出现黑屏现象  

禁用组件/GameObjects 输入  

```~/_GameCameras/CameraParent/tk2dCamera/Masker Blackout```  

![](https://github.com/asd9176506911298/CinematicUnityExplorer/blob/Silksong/img/componentDisable.png?raw=true)  

类似情况在禁用 FreeCam 克隆后可解决
