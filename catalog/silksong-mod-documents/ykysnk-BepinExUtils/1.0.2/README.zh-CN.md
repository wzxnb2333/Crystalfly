# BepInEx 工具库

为 BepinEx 提供的工具库

![icon.png](https://raw.githubusercontent.com/T2PeNBiX99wcoxKv3A4g/BepinEx-Utils/master/icon.png)

### **这只是一个我模组用的库，仅下载此文件不会产生任何效果。**

## 安装

1. 下载 [BepInEx](https://github.com/BepInEx/BepInEx) 和 [install](https://docs.bepinex.dev/articles/user_guide/installation/index.html)。
2. 将 .dll 文件提取到 `game folder/BepInEx/plugins`。
3. 启动游戏。

## 对开发者

如同其他库一样，从发布页面导入 .dll 文件。  
您也可以下载 [BepinEx-Utils.Generator](https://github.com/T2PeNBiX99wcoxKv3A4g/BepinEx-Utils.Generator)，如果您希望使用 BepInEx 工具生成代码。
