# StubbornHornet - Silksong Mod

## 🎮 游戏玩法

### 核心机制

StubbornHornet 是一个 **顽固大黄蜂模组**。大黄蜂的思维始终专注于某个单一方向，她只能朝自己想要的方向进行攻击。

### 箭头系统

- 玩家头顶会显示 **4 个垂直排列的箭头**（上/下/左/右）
- **最下方的箭头** 表示大黄蜂当前思维所指向的方向
- 成功执行动作后，箭头队列向下滚动，生成新的方向

### 动作规则

| 动作类型           | 输入               | 所需方向                                                                 |
| ------------------ | ------------------ | ------------------------------------------------------------------------ |
| **基础攻击**       | 攻击按钮           | 上/下/左/右（根据攻击方向）                                             |
| **蓄力攻击**       | 攻击 + 持续按下     | 左/右（根据角色朝向）                                                   |
| **冲刺攻击**       | 冲刺 + 攻击        | 左/右（根据角色朝向）                                                   |
| 钩索攻击           | 钩索按钮           | 左/右（根据角色朝向）                                                   |
| **法术/工具使用**  | 法术按钮           | 左/右（根据角色朝向），上/下（根据工具/法术位置）                        |

### 失败惩罚

- 当动作方向 **与思维方向不一致** 时，该动作将被 **阻止**（无攻击判定 / 无法力或工具消耗）
- 箭头队列不会滚动，你需要调整方向并重新尝试

### 成功

- 当方向匹配时，动作正常执行
- 箭头队列向下滚动，进入下一个方向

## ⚙️ 设置

- 您可以在模组选项中 **开启/关闭** 此模组  
- 当禁用时，所有操作均不受限制，恢复游戏原始行为

### 配置选项

| 选项           | 默认值   | 描述             |
| -------------- | -------- | ---------------- |
| 箭头数量       | 4       | 箭头数量         |
| 箭头透明度     | 1.0     | 箭头透明度       |
| 音效音量       | 5       | 音效音量         |
