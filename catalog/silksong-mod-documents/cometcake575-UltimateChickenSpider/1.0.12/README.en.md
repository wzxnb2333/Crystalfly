## Ultimate Chicken Spider

Ultimate Chicken Spider is a Silksong mod inspired by the game Ultimate Chicken Horse, where you slowly build a level and try to reach the end.

### Setting Up

To set up a match, you first need to place Starting Point and End Point objects, which can be found in the UCS Arena category in the Architect editor.

These can go anywhere, including in custom scenes, and you can use Architect to edit rooms however you want before starting the game.

You can also place down Safe Zone objects wherever you want to make placing things impossible.

### Starting the Game

To play Ultimate Chicken Spider, first enter an SSMP server with the other players.

You can play with up to 8 people total, but between 2 and 4 players is recommended.

To start the match, make sure everyone has the room file (you can click the "Share Room (SSMP)" button in the Architect editor to do this) and is in the same room, then type the SSMP command /ucs start.

To teleport others to your room, run the command `/ucs tph <player>`

To teleport to another player's room run the command `/ucs tp <player>`

### Playing

Each round, players get to pick an object from a list of 9 randomly generated things, and can place it in the room.

Once everyone has picked and placed their objects, the round will begin, and everyone tries to reach the finish line to get a point.

If you take damage in any way, you lose the round, and can spectate other players until the round is over, with all players having either lost or reached the end.
- You can configure a loss to instead mean hazard damage or death in the mod's config.
