# 修复跳蚤酿造的冷却时间

当激活跳蚤酿造时，攻击冷却时间应使用跳蚤酿造减少的攻击持续时间作为下限，而非原始持续时间。

## 说明

以“野兽纹章”激活怒气为例，其攻击持续时间为 0.3s，冷却时间为 0.32s。

理论上，跳蚤酿造应将持续时间缩短至 0.2s，冷却时间缩短至 0.16s。

然而，冷却时间被原始攻击持续时间下限限制在 0.3s，导致最终的加速效果仅为 6.25%。

本模组对此进行了修改，使其冷却时间被缩短后的持续时间所限制，所有纹章因此获得更显著的增益。

# 跳蚤秘酿冷却修复

跳蚤秘酿生效时，使攻击冷却以跳蚤蜜酿减少后的攻击间隔而非原始攻击间隔作为下限。

## 解释

以野兽纹章狂暴状态为例，其攻击持续时间为 0.3 秒，冷却时间为 0.32 秒。

跳蚤秘酿理论上应当将持续时间缩短为 0.2 秒，冷却时间缩短至 0.16 秒。

然而，冷却时间以*原始的*攻击间隔作为下限，实际变为 0.3 秒，导致跳蚤秘酿最终的加速仅有 6.25%。

本 mod 使得冷却时间改为以跳蚤秘酿*减少后的*攻击间隔作为下限，各纹章都有不等的收益。
