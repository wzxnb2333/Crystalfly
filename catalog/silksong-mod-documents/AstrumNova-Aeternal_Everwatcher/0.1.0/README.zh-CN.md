# 永恒守望者  
永恒守望者是对“边缘守望者”模组的重制版本，使其成为以格挡为核心的首领战斗。

# 版权声明  
如果你正在使用 pantheon of pharloom 模组，该模组会破坏绝望阶段（因为该模组开发者改动过多），建议使用其非常旧的版本（我有一个，需要的话可以私信我或联系我获取），或者干脆不要使用它。  

阶段 1:  
- 修改了他所有的攻击（实际上 3）使其更快，他会直接冲刺到你面前并穿过你，你需要进行格挡，存在一些方法可以加快该阶段的节奏，如果你懂得其中技巧的话  

阶段 2:  
- 增加了 2 攻击，包括九日终焉首领的四风斩击，以及咆哮地面波，阶段 2 中的咆哮地面波之后会接上“挖出上勾拳”，并提供充足的格挡窗口，作为阶段 3 地面波连招的入门教程  
- 他的上勾拳和三连斩地面砸击会产生沙尘冲击波，迫使你采取特定站位  
- 他的远距离斩击和近距离三连斩会在其身后生成风斩  

阶段 3:  
- 他的地面波之后会接上九日终焉首领的三段空中斩击，模式上基本相同，只是结尾会以地面砸击结束，你可以忽略，或者下蹲冲刺接住并格挡  
- 他的上勾拳现在会接上 3 地面砸击，随后再接一个上勾拳，该攻击会生成巨大的地面波（类似《艾尔登法环》最终BOSS的攻击，笑死）  
- 他的三连斩攻击现在有一个变体：他会先斩击一次，冲刺斩击，瞬移靠近你，再斩击一次，冲刺斩击，瞬移至你身后，随后快速收尾（请尽早格挡，虽然击中范围有趣，但一旦掌握就会非常稳定）  

阶段转换：  
- 他会每侧生成 2 珊瑚尖刺，鼓励你靠近，大概率是这样，且在阶段 2 和阶段 3 的首次攻击中，他都会先咆哮  

绝望阶段：  
- 他会生成 100 珊瑚尖刺，每 0.15 秒随机生成一次，位置和方向均靠近你

# 设置  
- 护盾反制时间冻结，你可以将其设置为短于原版的冻结时间，或直接设置为 0 以禁用（但某些攻击是利用冻结时间让你有反应时间来判断敌人使用的变体，你已警告）  
- 受伤冻结，本质上是护盾反制冻结，但当你受到伤害时，有助于维持节奏  
- 阶段持续时间，用于帮助你练习阶段（我猜）  
- 视觉效果，用于调节沙地亮度，确保玩家和首领始终在沙地之上显示，以及在风效过于烦扰时关闭风效果
