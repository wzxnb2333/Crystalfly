# ⚔️ Abilities Unlocked
*This mod should give you all abilities right from start. Can be configured by going into BepInEx config and changing the settings from true to false,*
*so that you can adjust what abilities you want right away and which you don't want to have instantly.*

---

## 🔧 Install
1. Download BepInEx
2. Drop the Files from the BepInExPack folder inside your exe, should be at steamapp/common/hollow knight silksong/
3. Download this mod
4. Drop the DLL called (AbilitiesUnlocked.dll) inside the plugins folder inside the BepInEx Folder inside your exe folder. So inside steamapps\common\Hollow Knight Silksong\BepInEx\plugins
4.1 If there is no plugin Folder just fucking download the BepInEx from the link i put into requirements if you come from nexus. Or just start the game once with your current BepInEx installation.
5. Done

---

## 📒 Note

- I started a new game and could use all abilities, so i guess it should work. I do test runs with it at a later time.
- Theoretically it just sets the bools hasXYZ to true at the start of HeroController. They should not be set false again and should not crash the game when gaining the ability the normal way.
However since you could have access to everywhere, i do not know if there is anything you COULD break. So use at own risk i guess.
