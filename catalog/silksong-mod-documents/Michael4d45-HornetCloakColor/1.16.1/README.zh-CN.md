# 大黄蜂纹章颜色

在《空洞骑士：丝之歌》中通过预设或自定义十六进制/RGB值重新着色**大黄蜂的纹章**。如果你希望拥有不同的外观但不修改游戏机制，此功能非常合适。

**多人模式：** 可选。使用 **[SSMP](https://thunderstore.io/c/hollow-knight-silksong/p/SSMP/SSMP/)** 时，其他也安装了该模组的玩家可以看到彼此的纹章颜色。单人模式下无需 SSMP。你也可以单独为你的**浮动用户名**着色（当显示名字时）；请参阅同一模组的“多人用户名”部分在 Mod Menu 中的内容。

**要求：** 丝之歌、BepInEx、Mod Menu。请保持 **`HornetCloakColor.dll`**、**`HornetCloakColor.SSMP.dll`** 和 **`cloak_palette.json`** 一同存在（e.g. Thunderstore 压缩包结构）。未安装该模组的玩家仍会看到正常的纹章。
