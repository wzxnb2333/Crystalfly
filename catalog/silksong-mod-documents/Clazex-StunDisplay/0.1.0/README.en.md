# Stun Display

A Hollow Knight: Silksong mod that displays the stun state of bosses.

By default, it is shown at the lower center of the scrren as `Stun: X/Y Combo: Z U/V`, where:
- `X` is the current stun accumulation value;
- `Y` is the value required for boss to be stunned;
- `Z` is the value required if in combo;
- `U` is the current combo time left;
- `V` is the total length of the combo timer.

An additional indicator is shown when the boss is stunned, or when its stunning is disabled.

# 硬直显示

一个《空洞骑士：丝之歌》模组，可以显示 Boss 的硬直状态。

默认在屏幕正下方显示为 `硬直：X/Y 连击：Z U/V`，其中：
- `X` 为当前的硬直累计值；
- `Y` 为使得 Boss 硬直所需的累计值；
- `Z` 为连击时所需的累计值；
- `U` 为当前剩下的连击计时；
- `V` 为连击计时的总时长。

当 Boss 硬直时，或其硬直被禁用时，将相应地显示。
