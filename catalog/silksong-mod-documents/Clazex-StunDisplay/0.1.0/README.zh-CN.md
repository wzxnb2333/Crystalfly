# 震晕显示

一个《空洞骑士：丝之歌》模组，用于显示首领的震晕状态。

默认情况下，震晕状态显示在屏幕下半部分中央，显示为 `Stun: X/Y Combo: Z U/V`，其中：
- `X` 是当前震晕累积值；
- `Y` 是首领被震晕所需的值；
- `Z` 是处于连击状态下的所需值；
- `U` 是当前连击时间剩余值；
- `V` 是连击计时器的总时长。

当首领处于震晕状态，或其震晕功能被禁用时，会额外显示一个指示器。

# 硬直显示

一个《空洞骑士：丝之歌》模组，可以显示首领的硬直状态。

默认在屏幕正下方显示为 `硬直：X/Y 连击：Z U/V`，其中：
- `X` 为当前的硬直累计值；
- `Y` 为使得首领硬直所需的累计值；
- `Z` 为连击时所需的累计值；
- `U` 为当前剩下的连击计时；
- `V` 为连击计时的总时长。

当首领硬直时，或其硬直被禁用时，将相应地显示。
