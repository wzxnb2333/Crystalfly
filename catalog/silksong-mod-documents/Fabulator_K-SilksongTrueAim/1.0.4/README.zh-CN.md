# 真实瞄准

Hollow Knight：丝之歌中输入方向的视觉反馈叠加层。

## 特性

按 **F8**（键盘）或 **L3/左摇杆点击**（手柄）可切换显示攻击方向的辅助界面。

## 安装

通过 r2modman 或 Thunderstore 模组管理器进行安装。BepInEx 将作为依赖项自动安装。

手动安装：解压到游戏文件夹，并与现有的 BepInEx 安装合并。

## 配置

在游戏中按 F8/L3 可切换叠加层。其他设置请参见 BepInEx 配置文件。

## 依赖项

需搭配配置管理器的 BepInEx（用于自定义/本地化功能）。

# 真准 - 中文简介

输入方向可视化反馈模组。

按下 **F8**（键盘）或 **L3**（左摇杆按键）切换显示攻击方向的覆盖层。

通过 r2modman 或者 Thunderstore 安装会自动安装需要的前置mod。

手动安装可以直接把压缩文件中的BepInEx文件夹放到游戏根目录与原有的BepInEx文件夹合并。

需要通过 BepInEx 的配置管理器调整设置选项。
