# 三段弹道

**复制游戏中的大多数弹道，并将其分散成可配置的弧线。**  
通过可调节的弹道数量，让每一次战斗都充满混乱。

设计上灵活、安全且高度可配置。

## 它的功能

该模组会介入丝之歌的弹幕生成机制，并**克隆大多数敌方弹幕**。

它包含以下选项：
- **设置弹幕倍率**（e.g. 3x, 5x 等）
- **控制克隆弹幕的扩散角度**
- **启用或禁用玩家弹幕**
- **仅限制物理基础弹幕的克隆**

使用了详尽的黑名单，以避免粒子效果、UI元素、特效和物体对战斗造成干扰。

## 配置

游戏启动一次后，编辑以下配置文件：  
`BepInEx/config/com.adwamogus.tripleprojectiles.cfg`

主要选项：
- **倍率**：每个原始弹幕生成的弹幕数量
- **MaxSpread**：总扩散角度（度）
- **EnablePlayerProjectiles**：包含玩家工具/弹幕
- **OnlyClonePhysicsProjectiles**：忽略静态/脚本对象

## 兼容性

- BepInEx 5.x  
- 与双敌模组兼容

## 难度提示

本模组可能**显著提升游戏难度和视觉强度**。  
高倍率可能会对性能或战斗可读性造成影响。
