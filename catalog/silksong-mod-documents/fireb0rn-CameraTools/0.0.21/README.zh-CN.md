# 相机工具

一个用于创建电影镜头的模组。这些镜头适用于丝之歌内容中的B-roll类画面。该模组会对游戏画面应用滤镜，以增强视觉效果，并减少背景物体的模糊现象。每个相机特效默认持续 25 秒，可选择延长其时长。

使用此模组时，建议开启OBS的“回放缓冲”功能。在设置 > 输出 > 回放缓冲中，勾选“启用回放缓冲”，并将最大回放时间设为25秒。在快捷键设置中，为“保存回放”分配一个快捷键。配置好场景后，启动回放缓冲。在游戏中，按下你的快捷键时，将截取之前 25 秒的画面。

建议在调试模式下移除HUD、隐藏主角（如需），并在页面 5 的绑定设置中移除主角光效。请注意，你也可以在页面 1 中调整时间缩放比例，但此时可能还需要相应地调整最大回放时间。

## 控制方式

- 1: 向右平移  
- 2: 向左平移  
- 3: 放大  
- 4: 缩小  
- 5: 向右平移（大范围）  
- 6: 向左平移（大范围）  
- 8: 为下一次摄像机移动添加 5 秒的延迟。  
- 9: 切换模糊效果（在屏幕外添加模糊效果）  
- 0: 切换暗角效果  
- U: 向上平移  
- I: 向左平移（同时保持角色在左侧）  
- O: 对角向上右平移  
- P: 对角向上左平移  
- B: 加载周边场景到当前场景。这是一个实验性功能（非常不稳定）。

## 已知问题

本模组以当前状态提供，且不提供任何支持，因为它只是为一段视频快速制作的一个模组。如果在使用过程中遇到令人困扰的问题，敬请谅解，但希望它能对你有所帮助！

- 加载文件后保存并退出，再进入另一个存档时，模组功能会失效，直到重新启动游戏。
- 在某些镜头特效期间，场景前景中会出现黑色方块。可通过完全重启游戏解决。该问题影响特定场景，因此你也可以直接切换到其他场景。
- 某些光照效果会产生红色光晕，包括在地形上跳跃或击打时产生的粒子效果。如果是由可破坏物体（如台灯）引发的，可以尝试破坏该物体以避免出现光晕。
