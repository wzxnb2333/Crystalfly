# GlassMode

本模组为无伤害模式添加了两种游戏模式：
- 脆弱之魂：无伤害，但仍可重生。
- 玻璃之魂：无伤害，包含钢魂内容。死亡为永久。

在这些模式下，破碎面罩功能将无法使用。

现有存档不受影响。只有新创建并启用这些模式的存档会受到影响。
