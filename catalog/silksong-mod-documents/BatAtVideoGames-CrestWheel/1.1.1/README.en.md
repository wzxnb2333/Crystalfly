# Crest Wheel

Made with the Silksong AP Randomizer in mind but can be used outside of it.
Hold L3 or Ctrl, aim with the right stick or W/A/S/D, then release the opening input to equip a crest. Releasing before the 0.25-second opening animation finishes cancels without switching.

The wheel keeps all seven vanilla crests in fixed positions and greys out unowned crests. Controller buttons, keyboard keys, hold duration, deadzone, size and background dimming are configurable.
