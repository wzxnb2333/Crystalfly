# 丝线翱翔模组

一种丝线翱翔变体，让你能够像水晶冲刺一样进行水平飞行。

## 描述

你喜欢《丝之歌》吗？是否怀念《水晶冲刺》呢？那么这个模组正是为你准备的！  
本模组为《丝之歌》提供了第二种使用方式：将针水平抛出，从而实现冲刺飞跃房间！

可以说，这其实也可以直接命名为“超级爪线”。

安装说明  
最简单的方式是通过 Thunderstore 使用像 r2modman 或 Gale 这样的模组管理器进行安装。

若选择手动安装，则需要先安装 BepInEx 模组加载器。请参考 [installation instructions on the official website](https://docs.bepinex.dev/articles/user_guide/installation/index.html)。  
安装完成后，下载本模组并将压缩包解压至 

```
\steamapps\common\Hollow Knight Silksong
```
。

## 主要功能

- 站立在地面时使用 SSD
- 爬墙时使用 SSD（需开启 Cling Grip）
- 将针投掷到路径中的下一面墙上并冲刺前往
- 若拥有 Cling Grip，可附着于墙面
- 冲刺穿越门的过渡区域
- 默认组合：鱼叉（LT）+ 上方向键（与 Silk Soar 相反）
- 通过按 F1 进行游戏内配置（BepInEx 配置）
- 切换按键组合：Silk Soar 变为鱼叉 + 上方向键，Silk Soar Dash 变为鱼叉 + 下方向键
- 在以下情况下可进行配置：使用 Silk Soar 时、使用 Clawline 时、始终可用
- 配置丝线消耗值：1（默认），或其他数值或无消耗
- Silk Soar 功能本身仍然可用

## 要求

无需其他模组。

## 已知限制

**房间切换**
目前游戏无法判断在接下来的几间横向房间中，针是否能落在有效墙壁上。因此，当前版本中针会直接移动，而墙壁检测会在进入房间时才进行。大黄蜂随后将继续向右冲刺，直到碰到障碍物为止。  
在未来版本中，我们或许可以在加载游戏时提前完成一些工作，从而正确地进行判断，并在开始冲刺前就停止冲刺，就像丝之歌所做的那样。  
不过说实话：我很难找到一个真正需要这种功能的房间。

**动画效果**
在某些情况下，动画表现异常。这是因为我在丝之歌和爪线模组中复用了现有的动画资源。除非有开发者愿意并希望为本模组制作完整的图形内容，否则这一问题无法得到解决。

**平衡性/游戏玩法**
当然，从游戏平衡性的角度来看，这种设计并不合理，很可能会导致一些有趣的互动、流程中断，或者直接让部分游戏内容变得更容易完成。如果你希望调整平衡性，配置选项可以提供一定的调节空间。
