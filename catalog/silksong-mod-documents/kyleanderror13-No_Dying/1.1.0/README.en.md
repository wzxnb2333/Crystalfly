# No Dying

A Hollow Knight: Silksong mod that stops Hornet from dying.

The mod sets the `PreventDeath` flag already supported by the game. This causes any damage that would normally result in the player dying to set the player's health to 1 instead.

No Dying is a mod that is often used by hitless runners particularly when working their PB down and death is more likely. It is particularly useful when running in Steel Soul mode so that the save is not deleted mid-run.
