# 针锋  
一个用于为游戏添加纹章和工具的工具（不包含纹章与工具机制）

## 特性  
- 添加纹章  
  - 创建 CrestData  
  - 向缚丝FSM注入代码的钩子  
  - 自定义生命值背景  
  - 自定义动作集  
    - 普通斩击  
    - 充能斩击  
    - 跳跃攻击  
    - 下坠攻击  
- 添加工具  
  - 黄色和蓝色工具完全支持  
    - 红色工具处于开发中  
      - 液体工具已可用（等离子药瓶/跳蚤酿造液）  
      - 射击类工具尚未实现  
- 添加自定义工具/槽位颜色  
  - 预设包含粉红（红色/白色）、绿色（蓝色/黄色）和黑色（所有颜色）

## 已知问题
- 自定义颜色的工具将无论何种情况自动装备

技术标识：`BindFSM`
