# 敌人傀儡师

> **实验性。** 这是一个测试工具，而非游戏内容模组。可能具有不完善之处。

在《空洞骑士：丝之歌》中，你可以手动操控任意敌人——点击一个敌人，将其移动，并亲自发动其真实攻击。

## 要求

- **[BepInEx for Silksong](https://thunderstore.io/c/hollow-knight-silksong/p/BepInEx/BepInExPack_Silksong/)**
- **[Enemy Behavior API](https://github.com/faarisaahmed/enemy-behavior-api/releases)** — 一个硬性要求，而非可选附加项

**如果没有 API，此模组将完全无法加载。** 它是一个编译时的程序集引用，因此 BepInEx 无法构造插件并记录错误；你不会看到窗口，按 F8 也无任何反应。如果出现这种情况，请检查 `BepInEx/LogOutput.log`。

API 目前尚未发布到 Thunderstore，因此必须手动安装：从其发布页面下载 `EnemyBehaviorApi.dll`，并放入 `BepInEx/plugins/EnemyBehaviorApi/`。
BepInEx 会递归扫描 `plugins/`，因此任意子文件夹均可。

## 安装

首先安装 BepInEx 和敌对行为 API，然后安装本模组。游戏内按 **F8** 键。

## 使用方法

| | |
|---|---|
| **右键点击** 敌人 | 选择该敌人 |
| **接管控制** | 占有该敌人 |
| **左键点击** | 移动标记 —— 敌人会走向该位置 |
| **攻击按钮** | 发射该敌人的实际攻击 |
| **F8** | 打开/关闭窗口，同时也会释放控制 |

每次关闭窗口都会将敌人归还，因此不会出现敌人被遗留在原地的情况。

## 操控模式

接管后，大黄蜂会变成一个**不可见标记**。她无法受到伤害，也无法行动，屏幕上会显示一个十字准星标示她的位置。敌人会走向她，其余的一切都由你来决定。

### 它是行走而非滑行

操控设定敌人的**朝向**，并触发其自身的巡逻行走——即在察觉到你之前缓慢来回移动的行为。只有朝向和行走是否为奔跑会被改变；速度、动画以及地面控制仍保持原样，因此敌人会以原本的方式移动。

判断“朝右”的标志由每个敌人的艺术设定决定，因此如果某个敌人出现月步动作，则需要一个**朝向切换**选项。

### 仅你所操控的敌人会产生反应

该标记是一个真实的、可被攻击的大黄蜂，因此默认情况下房间内的所有敌人都会朝它移动。  
**旁观者：保持静止**（默认设置）会阻止其他敌人对它采取行动。它们并不会被“致盲”，而是被禁止选择追击或攻击——这一点可以被完全保证。

仅是其决策被抑制，因此即使有游离的敌人仍可能被击杀，并且依然会表现出惊吓反应。

## 游戏从未展示的攻击

大多数敌人拥有你在正常游玩中永远不会看到的状态。该功能读取的是FSM状态图，而非游戏运行历史，因此会列出所有开发者编写的可触发状态。

这些状态大多属于“可达但有条件限制”——即被封印的变体，其触发事件仅由封印机制广播、特定竞技场配置或距离/阶段守卫所控制。执行其中一个状态将绕过该限制，这就是为何某些脱离上下文的攻击看起来异常：它们是被设计为在其他条件满足后才可触发的。

## 已知的粗糙边缘

- 静止敌人没有行走状态；界面会显示这一点，而不是忽略你的点击
- 攻击可能在没有任何可见动作的情况下发动，如果分类器错误地将某种状态识别为攻击
- 明显的攻击可能缺失于菜单中，原因正好相反
- 如果处于控制之下的敌人无法死亡，那就是这个问题最严重的后果——请务必报告
