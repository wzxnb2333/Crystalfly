# Changelog

## 0.1.1

仅用于打包 — **模组本身未作更改。** `EnemyPuppeteer.dll` 与 0.1.0 完全一致，因此如果当前版本已正常运行，则无需更新。

### 修改内容
- 新增图标。
- 说明文件明确指出，敌对行为 API 是一项 **硬性要求**。若缺少该 API，模组不会仅仅处于空闲状态 —— 它将完全无法加载，因为该 API 是编译时的引用组件，BepInEx 无法构建插件。此前的描述暗示模组会正常加载但无任何功能，这可能导致用户在错误的地方进行查找。

## 0.1.0

首次发布。这是一个实验性测试框架，不是游戏玩法模组。

### 新增功能
- 点击敌人的攻击区域可选择敌人，或从场景中所有物体的列表中选择
- 可操控该敌人，发动其已发现的所有攻击，并通过点击移动它
- 提供傀儡模式：大黄蜂变为一个不可见、无敌的标记体，无法执行任何操作
- 借助旁观者抑制功能，只有你所控制的敌人才会对你做出反应
- 提供跳跃、冲刺和传送状态的按钮，用于攀爬和跨越空隙
- 实时显示敌人在 PlayMaker 中的状态以及每次指令是否成功命中
- 重新扫描功能，适用于在 API 加载前已经苏醒的敌人

### 注意事项
- 敌人移动采用其自身的 **巡逻行走** 行为——即在察觉到你之前缓慢来回移动。仅控制敌人的朝向和行走状态（是否奔跑）；速度、动画及地面处理方式仍由敌人自身决定，因此其移动行为与原版一致，并不会出现滑动现象。
- 所有攻击均为手动操作。在你操控期间，敌人的自主决策机制被完全抑制。
- 许多敌人拥有你在正常游戏过程中无法看到的状态。这些状态虽然可访问，但存在条件限制，触发攻击会绕过该限制——因此在脱离上下文的情况下发动攻击可能会显得异常或“出错”。
