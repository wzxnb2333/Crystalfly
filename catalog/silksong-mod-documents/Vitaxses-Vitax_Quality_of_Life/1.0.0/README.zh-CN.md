# 生活品质  
空洞骑士：丝之歌的生存品质模组

## 特性

- 跳过场景（空洞骑士：丝之歌中部分场景无法跳过，否则会导致软锁定）
- 加速拾取特殊物品（例如丝线之心和能力）
- 无弱点（黑屏）
- 无首领对话/加速首领加载
- 显示百分比
- 加速杠杆操作
- 加速对话
- 提供跳转平台
- 已被修复的跳过功能（旧补丁）
- 跳跃时撞墙不再有头部碰撞
- 无硬着陆

以上功能可在配置文件中开启或关闭（Hollow Knight Silksong\BepInEx\config\vitaxses.qol.cfg）
