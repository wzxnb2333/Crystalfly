## ULTRA STEEL SOUL:

A BlueSR mess of a mod.

This mod is not really fully finished, but it is in a playable state and should therefore provide a fun challenge.
WARNING: i suck at developing or programming or modding using architect (or otherwise) so this project was very much thrown together. I made it for a fun video, but since there has been a lot of interest, i'm uploading it for all of you to try out!

IMPORTANT NOTES:

* the needle damage and Mask amounts have to be configured separately in the Debug Mod. Do note that there is a known issue with needle scaling. I'd also recommend the Debug Mod in case you get softlocked or something along those lines.
* The Awakened Grand Mother Silk Mod used in the video is NOT included in this modpack, and needs to be downloaded separately, as it is not compatible with AssetHelper (one of the dependencies for architect). Therefore, before you fight grand mother silk, you must exit the game, turn off AssetHelper and enable Awakened GMS.
* Known Softlock after defeating Tormented Trobbio. Uh, i couldnt really fix it because im stupid. Uh. Good Luck. just boot up the game and noclip past or something idk.
* The mist route exists but isn't really developed. Phantom has nothing cool going for them (aside from that sick organ ofc)
have fun and good luck!
