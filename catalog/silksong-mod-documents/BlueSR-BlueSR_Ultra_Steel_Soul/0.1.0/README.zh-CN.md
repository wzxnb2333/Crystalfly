## 超级钢铁之魂：

一个 BlueSR 的混乱模组。

这个模组尚未完全完成，但已经可以游玩，因此应该能提供一个有趣的挑战。
警告：我对开发或编程，或使用架构工具（或其他方式）进行模组制作非常不擅长，因此这个项目几乎是随手拼凑而成。我最初是为一个有趣的视频制作的，但由于受到了大量关注，现在我将其上传给大家尝试！

重要说明：

* 针状伤害和面罩数值必须在调试模组中单独配置。请注意，针状伤害的缩放存在已知问题。如果遇到卡死等情况，建议使用调试模组。
* 视频中使用的“觉醒的祖母丝”模组并未包含在本模组包中，需要单独下载，因为它与 AssetHelper（架构工具的一个依赖项）不兼容。因此，在挑战祖母丝之前，必须退出游戏，关闭 AssetHelper，并启用“觉醒的祖母丝”模组。
* 克服“受苦的特罗比奥”后存在已知的卡死问题。嗯，我确实无法修复，因为我太笨了。嗯。祝你好运。可以尝试直接启动游戏并使用无碰撞功能跳过，或者类似的方法，我也不太清楚。
* 雾之路线存在，但尚未充分开发。幽灵角色并没有什么特别之处（除了那套酷炫的器官外）。

祝大家玩得愉快，好运！
