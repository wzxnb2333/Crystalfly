# Phantom Of The Organ
***
- Slight rework of the Phantom boss fight that aims to make the fight more fluid and less of a pushover for midgame builds
- The boss has been made faster, tankier and now has some extra combo routes
- Balanced for end of act 1 to mid act 2
- NOTE: This mod requires FsmUtil or it will not load properly!

## Manual Installation
***
1. Download BepInEx, extract the zip and place the folder in the game root directory.
2. Run the game once so that BepInex can generate the necessary files.
3. Download this mod and FsmUtil, extract and place both dll files inside Hollow Knight Silksong\BepInEx\plugins.

## Act 1 save file
***
- In the mod folder is an act 1 save with all the possible things you can get before fighting phantom.
- The save is user 3 by default but can be changed by renaming the file.
