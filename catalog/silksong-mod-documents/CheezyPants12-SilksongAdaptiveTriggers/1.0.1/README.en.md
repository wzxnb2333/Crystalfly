# Silksong Adaptive Triggers

A Mod For Silksong That Enables DualSense Adaptive Triggers Through An External Application.


## Usage

Requires an application that can recieve UDP requests to interface with the DualSense Adaptive Triggers and control them.

Applications that have been tested and work with this mod:  
DSX: https://steamcommunity.com/app/1812620  
DualSenseY: https://github.com/WujekFoliarz/DualSenseY-v2

For both applications, the IP must be set to 127.0.0.1 and the port to 6969 (Usually set to this automatically).
