Mod Description:
- This simple mod regenerates shell shards, allowing you to spend your time exploring when shards are running low, instead of grinding rosaries for shard bundles.

Features:
- The number of shell shards gained per time increment can be configured, as well as the time increment itself.

- By default the player gains 5 shell shards every 30 seconds, but this can be easily configured for your needs.

- There is also an option to only activate this effect when the player is wearing the shard pendant, buffing the tool and making the experience even more fair.

Installation:
- Download BepInEx, extract and place in game root directory.

- Download the mod folder, extract and place the dll file in the BepInEx plugins folder.

Configuration:
- Press F1 in-game if using configuration manager.

- Otherwise a config file will generate in BepInEx config folder where manual edits can be made.
