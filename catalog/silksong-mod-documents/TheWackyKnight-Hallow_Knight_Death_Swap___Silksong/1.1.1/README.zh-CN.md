# 空洞骑士 死亡切换 - 1.1.1

角色死亡时，可瞬间在 **空洞骑士** 与 **丝之歌** 之间切换。请确保两个游戏均已加载各自的模组，并且其他所有窗口均最小化或位于游戏窗口之后。

## 更新日志
### v1.1.1
- 修复了丝之歌窗口无法获得焦点的bug
- 小幅提升性能
- 更新了README的格式化内容

## 要求  
- 已安装并保持最新版本的《空洞骑士》和《丝之歌》  
- 两个游戏必须同时运行，并加载各自的模组  
- 为使切换功能生效，你必须在两个游戏中都已载入存档文件

## 特性
- 死亡时在空洞骑士与丝之歌之间切换  
- 自动窗口管理（活跃的游戏窗口会置顶）  
- 兼容标准游戏控制方式

## 其他说明  
- 无需额外安装其他模组  
- 其他窗口必须最小化或位于游戏窗口之后  
- 轻量级，可在两个游戏同时运行时后台持续运行  

> **注意**：该模组不会提供任何游戏优势。它仅通过切换游戏来改变操作方式——不会影响物品、能力或存档。

## 已知问题
- 其他窗口覆盖游戏时可能导致窗口焦点丢失  
- 使用 Alt+Tab 可能会干扰自动切换功能
