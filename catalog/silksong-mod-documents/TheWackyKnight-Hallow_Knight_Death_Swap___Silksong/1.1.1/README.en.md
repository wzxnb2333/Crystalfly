# Hollow Knight Death Swap - 1.1.1

Switch between **Hollow Knight** and **Silksong** instantly when your character dies. Make sure both games are running with their respective mod and all other windows are minimized or behind the games.

---

## Changelog
### v1.1.1
- Fixed bug where Silksong window wouldn't gain focus
- Minor performance improvements
- Updated README formatting

---

## Requirements
- Hollow Knight and Silksong installed and up to date  
- Both games running simultaneously with their mods
- You must be loaded into a save file in both games for the swap to work  

---

## Features
- Switch between Hollow Knight and Silksong on death  
- Automatic window management (active game comes to the foreground)  
- Works with standard game controls  

---

## Other Notes
- Requires no additional mods  
- Other windows must be minimized or behind the games  
- Lightweight, runs in the background while both games are active  

> **Note:** This mod does not give any gameplay advantage. It only changes how you play by switching games—no items, abilities, or saves are affected.

---

## Known Issues
- Other windows covering the games can break window focus  
- Alt-tabbing may interfere with the automatic switch
