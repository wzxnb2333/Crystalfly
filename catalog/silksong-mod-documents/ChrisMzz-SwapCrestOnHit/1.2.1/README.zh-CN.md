# 受击时切换纹章

每次大黄蜂受到伤害时，都会切换她的纹章。  
大黄蜂当前的纹章将与其它已解锁的纹章，或游戏中的任意其他纹章进行切换（默认关闭，可在配置菜单中开启/关闭）。该模组会确保纹章的切换，因此如果你已解锁两个纹章，它们将在两个纹章之间以可预测的方式循环切换。

每个纹章的装备配置是独立的，因此当你在受到伤害时切换纹章，也会随之交替使用不同的装备配置。

可配置：你可以开启一个 `Crest Sanity`。默认情况下该选项是开启的，此时模组只会与其它已解锁的纹章进行切换。如果你将其关闭，游戏中的任意纹章（例如：祭司、无披风、诅咒、或猎人纹章的各个进化形态）都可以被选中（请注意，这些猎人纹章进化形态在内部是独立的纹章）。使用此功能需自行承担风险，如果你只想体验纯粹的混乱。
