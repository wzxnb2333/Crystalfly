# Changelog

## 1.0.0

First public release.

- **Custom Gauntlet** game mode on the New Game menu: skips the opening cutscene,
  drops you into the Grand Forum with every ability and tool unlocked, a bench to
  rest at, and an arena that runs waves you built yourself.
- Wave editor (`F7`) backed by a plain-text wave file you can hand-edit.
- Dev menu (`F9`): take over a room, pin the home point, place the bench, import
  enemies, dump what the room actually contains.
- Enemy library harvested from rooms you visit, plus on-demand importing from a
  list of enemy-dense rooms.
- Free move (`1`), a fallback masks/silk readout (`2`) and camera zoom (`-` / `=`).

Known limitations are listed under **Status** in the README - the short version is
that only part of the bestiary is actually spawnable.
