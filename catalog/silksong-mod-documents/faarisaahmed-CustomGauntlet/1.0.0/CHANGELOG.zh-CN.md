# Changelog

## 1.0.0

首次公开发布。

- **自定义战甲**游戏模式，位于新游戏菜单中：跳过开场动画，直接进入大议会区域，所有能力与工具均已解锁，提供一个长椅供休息，并设有可运行你自行构建波次的竞技场。
- 波次编辑器（`F7`），基于可手动编辑的纯文本波次文件。
- 开发菜单（`F9`）：可接管房间、固定起点位置、放置长椅、导入敌人、查看房间实际包含的内容。
- 敌人库来源于你访问过的房间，同时支持从敌群密集的房间列表中按需导入敌人。
- 自由移动（`1`），作为掩护/缚丝读取的备用方案（`2`）以及摄像机缩放功能（`-` / `=`）。

已知限制详见 README 中的 **状态** 部分——简要说明是，仅部分怪物图鉴内容可实际生成。
