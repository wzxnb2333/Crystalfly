## Gauntlet Song

A map created through Architect that adds a ludicrous amount of gauntlets across the game. Features new enemies, bosses, quests, NPCs, altered progression, and a slightly different story. This map is a work in progress, and likely won't be fully completed for a long time. Information regarding development, updates, progression guides, and more can be found in the Gauntletsong Discord Server: https://discord.gg/gKeRkaJsHA
