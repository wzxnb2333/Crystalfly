# 🌌 GravityFlux - 丝之歌模组

**GravityFlux** 是 _空洞骑士：丝之歌_ 的一个工具，可让你在 Pharloom 中完全掌控物理法则。从精确的重力调节到混乱的“随机模式”，该模组从根本上改变了 Hornet 与世界环境的互动方式。

## 🚀 特性

- **实时控制面板：** 一个集成的用户界面，可随时调整重力设置而无需暂停游戏。
- **精确增量：** 可以以 **0.5x** 为单位逐步增加或减少重力值。
- **混沌模式（随机重力）：** 在设定的时间间隔内，自动将重力切换到一个随机值（介于 **0.2x** 和 **3.0x** 之间）。
- **可配置时间间隔：** 你可以自行决定下一次重力变化前需要经过多少秒。
- **即时重置：** 通过单击即可快速恢复游戏默认的物理设置。

## 🎮 如何使用

安装完成后，可以通过以下操作控制模组：

| **功能**              | **按键**                          |
| --------------------- | -------------------------------- |
| **打开/关闭菜单**     | `F3`                             |
| **快速关闭**          | `ESC`（在菜单激活时）           |
| **移动面板**          | 点击标题栏并拖动                 |

### 菜单说明：

1. **缩放：** 显示当前作用于大黄蜂的重力倍率。
2. **增加/减少：** 修改大黄蜂的重量。低重力可实现巨大的跳跃和缓慢下落；高重力则会像石头一样直接坠落。
3. **随机模式：** 启用倒计时功能。面板将显示下次物理变换前剩余的时间。

## 🛠 安装

1. 确保你已安装 **BepInEx**（适用于丝之歌）。
2. 下载 `GravityFlux.dll`（或通过 Thunderstore 管理器直接安装）。
3. 将文件放入你的 `Silksong/BepInEx/plugins` 文件夹中。
4. 启动游戏并按 `F3`！

## 📝 技术概述

该模组采用动态缩放系统，以确保大黄蜂的移动始终保持流畅且响应灵敏，无论重力水平如何。与简单的物理参数覆盖不同，这种多变量方法保证了跳跃轨迹、终端速度和空中动力均能完美协调地缩放，在任何重力条件下都保持丝之歌游戏手感的紧密性。
