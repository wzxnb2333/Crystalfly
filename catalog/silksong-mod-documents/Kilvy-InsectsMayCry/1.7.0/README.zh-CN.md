核心机制：挑衅键 + 方向输入用于纹章切换

纹章切换发生在完成输入动作之后，实时视觉效果会在屏幕左上角更新。

短按挑衅 + 方向：

向上：

短按：工具大师（建筑师）

短/长按初始切换后：女王

向下：

短按：法术（祭司）

短/长按初始切换后：猎手

向左：

短按：收割者

短/长按初始切换后：战士（野兽）

向右：

短按：流浪者

短/长按初始切换后：女巫

长按挑衅（0.2秒保持）+ 方向：

向上：

长按：QueenCrest（女王纹章）

短/长按初始切换后：工具大师

向下：

长按：猎手

短/长按初始切换后：法术

向左：

长按：战士（野兽）

短/长按初始切换后：收割者

向右：

长按：女巫

短/长按初始切换后：流浪者

延长长按机制：

持续按住挑衅键 3 秒，会循环切换至诅咒纹章。

持续按住诅咒纹章 3 秒，会循环切换至无斗篷纹章。

游戏参数：

无敌帧：纹章切换期间为 0.1 秒。

冷却时间：两次切换之间为 0.3 秒。

灵魂消耗：

纹章切换消耗 0 灵魂（但挑衅动作本身消耗 1 灵魂）。

错误修复：

修复：坐在长椅上现在会正确补全所有纹章物品（不再仅补一个）。

修复：在冲刺斩动画期间切换纹章会导致角色卡顿的问题。

键位说明：

修改键位后，模组需重启才能生效。
