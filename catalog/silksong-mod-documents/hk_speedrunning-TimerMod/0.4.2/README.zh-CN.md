# TimerMod

一个基于触发器的简单计时器，适用于丝之歌。

## 使用方法

- F8：设置开始触发/场景  
- F9：设置结束触发/场景  
- F10：在场景时间与触发时间之间切换

## 设置

按键绑定以及用户界面的位置、大小和可见性可以在 BepInEx 配置中进行编辑。玩家可以在游戏内通过 `BepInExConfigurationManager` 访问，也可以通过 Gale 或 r2ModMan 等安装工具，或直接在位于 `<game files>/BepInEx/config/io.github.hk-speedrunning.timermod.cfg` 的配置文件中进行修改。
