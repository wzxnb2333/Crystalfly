<h1>描述：</h1>  
移除屏幕边缘的黑暗（光晕），以及角色周围亮度过强的现象（英雄光晕）。

这将使游戏画面更加均匀，减少眼睛疲劳。

<h1>链接：</h1>  
GitHub：<a href = "https://github.com/Bigfootmech/Silksong_Remove_Myopia_Filter/">https://github.com/Bigfootmech/Silksong_Remove_Myopia_Filter/</a> <br />  
NexusMods：<a href = "https://www.nexusmods.com/hollowknightsilksong/mods/105">https://www.nexusmods.com/hollowknightsilksong/mods/105</a>

<h1>安装方法：</h1>

<h3>Thunderstore：</h3>  
一切都会被自动处理。

例如：我将此包的依赖项设置为 BepInEx。

<h3>手动安装：</h3>  
首先将 BepInEx 安装到你的 Silksong 文件夹中，  
（注意：这会破坏 Thunderstore 的正常操作）

你可以在以下位置找到它：  
https://github.com/BepInEx/BepInEx/releases  
当前最新的稳定版本是 5.4.23.3

解压后，运行游戏一次，以生成 BepInEx 的文件夹结构  
（即：除了 'core' 文件夹外，还存在其他文件夹）

然后将此 DLL 文件，或包含 DLL 的文件夹，放入  
空洞骑士 <code>Silksong\BepInEx\plugins</code>

<h3>混合模式：</h3>  
如果你 somehow 使用了 Thunderstore，  
并且通过 Thunderstore 安装了 BepInEx，  
但此模组的依赖项出现了问题，

你应该能在以下路径找到 Thunderstore 的 BepInEx 插件文件夹：  
<code>C:\\Users\\{username}\\AppData\\Roaming\\Thunderstore Mod Manager\\DataFolder\\{game}\\profiles\\{profile_name}\\BepInEx</code>

如果你 somehow 在非 Windows 系统上使用 Thunderstore，且我打包时出错了，又不是技术爱好者……天啊，祝你一切顺利。
