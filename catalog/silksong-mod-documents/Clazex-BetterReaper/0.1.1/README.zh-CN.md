# 更强大的收割纹章

在多个方面增强了收割纹章的属性。

## 特性

- 提高从侧面和上方攻击造成的眩晕累积值，从 `1.0` 增加至 `1.5`  
  + 即，首领需要更少的 `1/3` 次击中才会被眩晕（实际情况下需四舍五入）  
  + 类似地，以下内容也相应提升  
  + 提高从下方和冲刺攻击造成的眩晕累积值，从 `1.0` 增加至 `1.75`  
  + 提高从针刺攻击造成的眩晕累积值，从 `2.0` 增加至 `3.5`  
- 轻微扩大针刺攻击的命中范围（在水平和垂直方向上均扩大至 `29/26` 倍）  
- 增强在收割模式下生成丝线碎片的能力  
  + 将每次攻击生成碎片的期望数量从 `1.8` 提升至 `2`  
    - 生成 `1` 片碎片的概率从 `35%` 降低至 `25%`  
    - 生成 `2` 片碎片的概率保持为 `50%`  
    - 生成 `3` 片碎片的概率从 `15%` 提升至 `25%`  
  + 降低碎片的初始速度，降低值为 `25%`  
    - 同时也减少了碎片的总移动距离，减少值为 `25%`  
  + 当碎片自然过期或完成缚丝时，自动收集碎片  
- 当收割模式自然结束，或在结束前再次激活时，恢复 `1` 个面罩  
  + 若生命值已满，则提供 `3` 条丝线代替  
- 在收割模式下受到伤害时，消耗丝线以防止生命值下降，每次消耗 `3` 条丝线  
  + 在熔岩铃、护盾铃和磁铁骰的效果之后应用  
  + 仅影响实际生命值的损失量，受到的伤害数值仍视为原始值  
    - 攻击取消和反冲效果保持不变  
    - 特别地，即使没有实际生命值损失，收割模式也不会结束

# 更好的收割者

从多个方面加强收割者纹章。

## 功能

- 侧向攻击与上劈造成的硬直累计从 `1.0` 提升至 `1.5`  
  + 即 Boss 进入硬直状态需要的攻击次数减少 `1/3`（实际计算时需要考虑四舍五入），以下同理  
  + 冲刺攻击与下劈造成的硬直累计从 `1.0` 提升至 `1.75`  
  + 蓄力劈砍造成的硬直累计从 `2.0` 提升至 `3.5`  
- 小幅增大了蓄力劈砍的碰撞箱（水平与竖直方向均扩大至 `29/26` 倍）  
- 收割状态下攻击产生灵丝团的能力增强  
  + 每次攻击产生的灵丝团的数量的期望从 `1.8` 个提升至 `2` 个  
    - 产生 `1` 个的概率从 `35%` 降低至 `25%`  
    - 产生 `2` 个的概率为 `50%` 不变  
    - 产生 `3` 个的概率从 `15%` 提升至 `25%`  
  + 灵丝团的初始移动速度降低 `25%`  
    - 总移动距离亦降低 `25%`  
  + 灵丝团在持续时间自然结束时或缚丝后自动被收集  
- 收割状态持续时间自然结束时，或期间重复进入收割状态时，回复 `1` 点生命值  
  + 生命满时改为回复 `3` 点灵丝  
- 收割状态持续期间受到伤害时，消耗灵丝抵消生命值损失，每 `3` 点灵丝抵消 `1` 点  
  + 生效于熔岩钟、护佑钟及磁石骰的判定之后  
  + 仅影响实际损失的生命值，不改变伤害量相关的判定  
    - 仍会受到打断、击退等效果  
    - 特别地，实际未损失生命值不会导致收割状态结束
