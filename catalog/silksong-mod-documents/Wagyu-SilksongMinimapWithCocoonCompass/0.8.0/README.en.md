### Silksong Minimap with Cocoon Compass.
This mod Adds a customizable vanilla-looking minimap.
You can customize the style and position of the minimap via the BepInEx Configuration F1 Menu or by 
editing the generated config file (Hollow Knight Silksong/BepInEx/config/com.Wagyu.SkongMinimap.cfg)

## Default Controls
B -> Toggle Minimap UI <br>
X -> Zoom Out <br>
C -> Zoom In<br>
F5 -> Reload config file from disk


## Installation
1. Install BepInEx (preferably with the Configuration Menu)
2. Open Silksong Minimap.zip
3. Extract the folder called "BepInEx" to the root of your Hollow Knight: Silksong local directory
4. Done
