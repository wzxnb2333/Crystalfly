### 丝之歌迷你地图搭配茧指南针。  
本模组添加了一个可自定义的原版风格迷你地图。  
你可以通过 BepInEx 配置 F1 菜单或编辑生成的配置文件（空洞骑士 Silksong/BepInEx/config/com.Wagyu.SkongMinimap.cfg）来定制迷你地图的样式和位置。

## 默认控制  
B -> 切换迷你地图界面 <br>  
X -> 放大查看 <br>  
C -> 缩小查看 <br>  
F5 -> 从硬盘重新加载配置文件

## 安装说明  
1. 安装 BepInEx（建议通过配置菜单安装）  
2. 打开丝之歌 Minimap.zip  
3. 将名为 "BepInEx" 的文件夹提取到你本地的《空洞骑士：丝之歌》目录根路径下  
4. 完成
