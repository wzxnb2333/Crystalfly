# 边缘检测

一款专为《空洞骑士：丝之歌》设计的无障碍模组，为游戏中的关键元素添加可自定义的边缘检测功能。

![Screenshot of Moss Grotto with bright outlines around the terrain, Hornet, and one Mossmir](https://raw.githubusercontent.com/kaycodes13/Silksong.EdgeDetection/refs/heads/main/preview.png)

每一层都可以独立调整其线条厚度和颜色。这些线条不会受到游戏亮度或其他图形设置的影响。

许多常规房间已进行测试，整个游戏应能正常游玩，但我仍需进一步优化，尤其是首领部分。如果发现某个特定房间、物体或首领的边缘显示异常，请 [open an issue on the GitHub repository](https://github.com/kaycodes13/Silksong.EdgeDetection/issues/new/choose)。

捐赠链接：https://ko-fi.com/kaykao

## 安装

使用模组管理器（如 [Cogfly](https://github.com/Nix-main/Cogfly/releases/latest) 或 [r2modman](https://thunderstore.io/c/hollow-knight-silksong/p/ebkr/r2modman/)）进行安装。本模组的依赖项将自动安装。

对于手动安装，请将 `.zip` 文件放入您 Silksong 安装目录下的 `BepInEx/plugins` 目录，并解压。此外，您还需要手动安装：
* [I18N](https://thunderstore.io/c/hollow-knight-silksong/p/silksong_modding/I18N/)
* [ModMenu](https://thunderstore.io/c/hollow-knight-silksong/p/silksong_modding/ModMenu/) 及其依赖项。
