# TAG THE FLEAS

**A new flea game (far from fleatopia) to play tag with a swarm of fleas and finish the game in as little time as possible**

- Go to mountfay room with lifts.
- Exit the room and re-enter to start a new game.
- Tutorial on game's configs: [YouTube](https://youtu.be/0cyvBPZErOI)
- Skip the video if you don't want spoilers.
- Come back to it, like the video and subscribe to my channel if you like my mod 🫶

---
### Scores:
- A timer will start when a game begins (displayed on the screen).
- Score of a game is basically the total time to tag divided by the number of the fleas in the game.
- Time of each game is saved to display on the scoreboard.
- You will need to finish multiple games to start getting logical entries on the board.
- Press left shift key (or assign a different key) to reset your times.

---
### Scoreboard:
- Seth: The least time of all the games.
- Vog: The most common time.
- Mooshka: Average time of all the games.
- Grishkin: A random time (he's high on fleabrew).
- Varga: A score somewhere between the best and the worst.
- Kratt: Obviously the worst time of all.
- Hornet: Time of the last game played.

---
### Configuration:
- Game settings are configurable.
- Scoreboard entries are configurable (independent of language).
- Press F1 to open the menu.
