# 第五乐章

一个丝之歌模组，重新设计了**第四乐章**首领，增加了更快的战斗节奏、额外阶段以及在对抗该首领时的一些便利功能。

## 特性

### 1. 重制第四合唱首领战斗  
第四合唱首领的遭遇战被重新设计，以创造更具挑战性但更有趣的战斗体验。  
攻击模式已调整以避免重复，首领逻辑更加智能，并新增了一个完全不同的第四阶段。

[Watch the showcase on YouTube](https://www.youtube.com/watch?v=qyYajaUgmEk)

### 2. 游戏内首领配置菜单  
按 **F6**（可配置）打开自定义的 **首领配置** 菜单：

- 选择难度，查看描述后点击 **开始** 即可进入战斗

### 3. 难度预设（自由模式 / 简单 / 中等 / 困难）  
每种难度会在传送前调整玩家属性：

- **自由模式**  
  使用当前存档中的装备、工具、面罩和丝线。不作任何修改。
- **简单**  
  7 面罩，9 丝线，无升级。
- **中等**  
  6 面罩，9 丝线，无升级，不包含非战斗类丝线技能（仅保留冲刺和隐身）。
- **困难**  
  5 面罩，9 丝线，无工具，无升级，不包含非战斗类丝线技能（仅保留冲刺和隐身）。

### 4. 即时传送至第四合唱战场  
开始战斗后，模组会直接将玩家传送到第四合唱房间：

- 场景：`Bone_East_08`  
- 门：`right1`  

此功能可在加载游戏后随时使用，只要游戏未暂停即可。

### 5. 存档阻止（安全沙盒模式）  
所有对 `GameManager.SaveGame` 的调用均被拦截并跳过：

- 在模组补丁生效期间，不会自动存档或手动存档  
- 使用此模组不会修改你的原始存档文件  

因此，你无需专门创建一个存档来游玩此模组。任何现有的存档均可使用。  
不过，在使用模组时仍建议备份你的存档。

---

## 安装

1. 安装 **BepInEx**（丝之歌）（请按照您平台的标准设置进行安装）。
2. 编译本项目以生成 `FifthChorus.dll`（或从发布版本中获取）。
3. 将 `FifthChorus.dll` 放入：
   - `Silksong/BepInEx/plugins/`（或 `plugins` 内的任意文件夹）。
4. 启动游戏。

## 使用方法

- 正常加载你的存档。
- 进入游戏后，按 **F6**（默认键位）打开 **第五调谐配置菜单**。
- 选择一个难度：
  - 自由模式 / 简单 / 中等 / 困难
- 阅读说明内容，然后点击 **开始** 来：
  - 应用预设属性
  - 传送至第四调谐竞技场
