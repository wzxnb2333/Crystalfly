# Wisp Hornet
Wisp Hornet skin mod for *Hollow Knight: Silksong*.

## Features
* Completed almost all sprites for a regular playthrough
* Bell Beast Travel animations, using CustomizerCinematic

## Installation
1. Install BepInEx5 and extract it to the game root folder. Run the game and exit.
2. Install Silksong Customizer and extract it to Hollow Knight Silksong\BepInEx\plugins. Run the game and exit.
3. ﻿Install [**CustomizerT2D**](https://www.nexusmods.com/hollowknightsilksong/mods/203?tab=description) file from Cute Hornet mode page and extract it to Hollow Knight Silksong\BepInEx\plugins.
4. Install [**CustomizerCinematic**](https://www.nexusmods.com/hollowknightsilksong/mods/354) file from Cute Hornet mode page and extract it to Hollow Knight Silksong\BepInEx\plugins.
5. ﻿﻿Install this mod and extract it to Hollow Knight Silksong\Hollow Knight Silksong_Data\Mods\Customizer. It's better to keep only one skin folder at the same time here. If you prefer to have multiple folders make sure only one of them have an active.txt file.
