# MusicRando

一个空洞骑士：丝之歌模组，用于随机化音乐。主菜单音乐以及一些未被游戏视为音乐的“氛围”曲目（例如钟楼音效）将被排除在外。

随机模式可在模组菜单中切换：
* OnChange - 每次音乐更换时选择一首随机曲目
* Chaos - 每当游戏尝试设置音乐时选择一首随机曲目——这种情况更频繁
* Consistent - 类似于 OnChange，但同一曲目将始终被随机切换到另一首（直到返回主菜单）
* RandoRando - 类似于 Chaos，但仅在部分时间才会更换曲目
* Disabled - 不进行任何随机化

音乐随机功能目前处于 alpha 版本，可能存在 bug。
