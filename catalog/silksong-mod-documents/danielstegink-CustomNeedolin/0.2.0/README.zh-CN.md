# 自定义需洛林  
部分灵感来自《自定义骑士》，本模组使玩家能够替换需洛林的音效文件为自定义音频文件。

要添加音频文件，请前往您机器上的模组文件夹，打开音频文件夹。然后将您想要的音频文件（.WAV 格式）复制到该文件夹中，与现有文件一同存放。

当您想要的文件放入音频文件夹后，打开 Bepinex 菜单（F1），进入“CustomNeedolin”选项，将文件名输入到“音频文件”字段中，无需包含文件扩展名。例如，要播放 Zambolino 的《Sakura》，请在字段中输入“Zambolino - Sakura”。

## 警告
该模组目前不会静音或覆盖蜘蛛丝工具播放的音频。
