# 王后纹章

一款以《空洞骑士：丝之歌》中的白女士为主题设计的自定义纹章。

这是我为一位朋友制作的模组，将多个原版纹章的元素融合，形成他们理想中的纹章。拥有两个技能槽、充足的蓝色技能槽，结合了猎手的均衡战斗风格、收割者的强力丝线获取能力，以及女巫的多段攻击针刺技能。

该技能组合本身完全可用。未来可添加自定义动画。

*请参见变更日志以了解新版本中的更新与修复内容。*

## 安装

通过 r2modman 或 Thunderstore 模组管理器进行安装。QueenCrest 的依赖项将自动安装。

对于手动安装，请解压 `.zip` 文件，并将生成的 **文件夹** 放入您 Silksong 安装目录下的 `BepInEx/plugins` 目录中。您还需要手动安装 [I18N](<https://thunderstore.io/c/hollow-knight-silksong/p/silksong_modding/I18N/>)，以及 [Needleforge](<https://thunderstore.io/c/hollow-knight-silksong/p/Voidlings/Needleforge/>) 和其依赖项。

## 使用方法

安装模组后，进入任何存档文件时都会自动解锁新的纹章。只需装备即可使用。

请注意，该模组会修改你的存档数据，并为游戏完成度增加一个百分点。使用前请先备份你的存档。
