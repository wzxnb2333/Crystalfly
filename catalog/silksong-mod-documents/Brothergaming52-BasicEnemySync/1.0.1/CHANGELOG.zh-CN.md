# 更新日志

**SSMP 敌人同步插件**的所有显著变更都将记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/en/1.0.0/)，  
该项目遵循 [Semantic Versioning](https://semver.org/spec/v2.0.0.html)。

## [1.0.1] - 2026-08-18

### 新增功能
- **原生 BepInEx 插件加载器 (`EnemySyncingPlugin`)**：
  - 注册为 `bg52.enemysync.ssmp`，依赖于 `ssmp`。
  - 支持自动发现插件，并通过 Thunderstore / r2modman 实现无缝 1-点击安装至 `BepInEx/plugins/`。
- **首领目标 HUD 提示**：
  - 动态将当前首领的目标玩家名称标签在 UI 文本、3D TextMesh 和 TextMeshPro 组件中更改为 **红色**。
  - 当首领更换目标或死亡时，名称标签颜色恢复为原始颜色。
- **尸体快照与死亡同步**：
  - 在敌人被击败时，新增对尸体位置、朝向和击退速度的同步。
- **场景拥有者死亡验证**：
  - 新增 `VerifyEnemyDieRequest` 和 `SceneOwnerNotify` 数据包，以防止幻影重复生成和不同步。
- **增强的弹幕同步**：
  - 新增弹幕动画片段和 `ScaleX` 尺寸的跨网络同步。
- **反重复生成监控器**：
  - 背景实体监控器，用于恢复已禁用的存活实体，并清理场景中的死亡实体。

### 修改内容
- 重构 PlayMaker FSM 中的距离与位置覆盖逻辑（`GetDistance`, `GetXDistance`, `GetYDistance`, `GetPosition`），以实现更精准的目标追踪。
- 优化了被击败的茧机制、自杀快捷键提示界面以及团队清屏的处理方式。

### 修复内容
- 修复了敌人在非主机客户端无法正确注册死亡的同步问题。
- 修复了玩家死亡或场景切换后首领目标锁定卡住的问题。

## [1.0.0] - 2026-07-26

### 新增功能
- **SSMP 敌人同步插件的首次发布**：
  - 实时同步敌人和小首领的位置、朝向和动画状态。
  - 多阶段首领状态同步以及 PlayMaker FSM 动作的镜像同步。
  - 基于距离和视野范围的动态敌人权限获取系统。
  - 为未被占用或超出范围的敌人提供主机备用模拟。
  - 联机模式下的“坠落茧”与队友复活机制。
  - 被困在茧中的玩家可按住快速地图放弃行动。
  - 团队清屏检测及协同复活机制。
