# 放置你的自定义皮肤  
- 按下 F1 键点击 `Open CustomSprite Folder`  
- 创建皮肤文件夹 BepinEx/Config/CustomSprite/`yourSkinFolder`  
- 将你修改的 Atlas 文件放置到  
- BepinEx/Config/CustomSprite/yourSkinFolder/`Knight_atlas2.png`

# 当前支持  
- `Knight_atlas0` ~ `Knight_atlas3`
