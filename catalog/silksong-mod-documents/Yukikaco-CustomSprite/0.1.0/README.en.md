# Place Your Custom Skin
- Press F1 Click `Open CustomSprite Folder`
- Create Skin Folder BepinEx/Config/CustomSprite/`yourSkinFolder`
- Place Your Modify Atlas to
- BepinEx/Config/CustomSprite/yourSkinFolder/`Knight_atlas2.png`

# Current Support
- `Knight_atlas0` ~ `Knight_atlas3`
