Anyway...make sure this folder "clown\_hornet\_skin" is in the BepInEx's plugins folder with the Stitchworks mod folder also in the plugins folder. You can find the plugins folder in the Thunderstore Mod Manager by 

**1st:** click settings in the Thunderstore Mod Manager.



**2nd:** In the setting menu there are sections. Pick Directories.



**3rd:** In the Directories section there should be a section that shows you the file path of where the profile folder is stored on your computer. Click browse. NOT change.



**4th:** After clicking browse, Thunderstore should open a folder that has a bunch of stuff in it but all you need to care about is the BepInEx folder. Open that folder.



**5th:** After opening the BepInEx folder you should see the plugins folder. That is where my clown\_hornet\_skin mod folder and the stitchworks mod folder is supposed to be in.



**6th:** Find where you manually downloaded clown\_hornet\_skin folder and Stitchworks folder(the default is the downloads folder but it can be different). **If it is a .zip extract it first**. Then move the ENTIRE EXTRACTED folders into the BepInEx's plugins folder.



**7th:** Now open the game modded by going back to the thunderstore mod manager and press the modded button at the top. Wait for the game to load.



**8th:** If everything is done correctly you should see a little square at the bottom left of the game screen that says a number of packs, sprites and clips. That means you have stitchworks and its working fine. Press 1.



**9th:** Pressing 1 will open the stitchworks packs menu. There you should see my skin listed(and any other stitchworks dependent mod). It is called "Clown Hornet(low quality)". Next to the scan button there is a switch button. Press it to make it green and then press apply at the bottom.



**10th:** FINALLY! The skin is applied and you look like a clown. Beautiful. Congrats.
