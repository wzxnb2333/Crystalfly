# SuperhotSilkSongMod

通过此模组，**时间随着大黄蜂的行动而流动**。

当她静止时世界会变慢，当她移动时速度会加快——就像在 **SUPERHOT** 中一样。  
从缓慢开始，通过持续按住移动键积累动能，最终达到你设定的最大速度。  
松开控制键后，时间会逐渐回归平静状态。

### 模式
- **基于移动** – 大黄蜂移动时游戏速度保持较高  
- **基于输入** – 当按下特定按键时，游戏速度会提升  

### 控制方式
- **键盘**：多种按键绑定选项  
- **手柄**：支持固定按键和模拟操作  

### 精细调节选项
- 最小与最大速度  
- 速度增长与衰减速率  

### 音频调制：
- 音频会随着游戏速度的变化而动态调整
