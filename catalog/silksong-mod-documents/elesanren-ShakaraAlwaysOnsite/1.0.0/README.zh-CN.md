# ShakaraAlwaysOnsite

丝之歌沙克拉商人常驻模组。

一个丝之歌模组，确保所有沙克拉（地图师）商人在场。

## 功能 / 特性

让 14 个区域的沙克拉商人不因剧情推进而离开，始终停留在原位，可正常对话、购物。

无论剧情进度如何，都会保留所有 14 Shakra（地图师）商人位于其区域。他们将保持原位，并始终可进行对话和购物。

## 安装 / Installation

1. 将 `ShakaraAlwaysOnsite.dll` 放入 `BepInEx/plugins/` 目录。
2. 启动游戏，Mod 自动生效。

1. 将 `ShakaraAlwaysOnsite.dll` 放入 `BepInEx/plugins/` 文件夹。

## 使用方法

无需任何设置，模组加载后自动生效。
