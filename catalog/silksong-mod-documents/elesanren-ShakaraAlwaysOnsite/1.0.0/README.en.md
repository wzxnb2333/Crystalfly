# ShakaraAlwaysOnsite

丝之歌沙克拉商人常驻 Mod。

A Silksong mod that keeps all Shakra (Mapper) merchants on site.

## 功能 / Features

让 14 个区域的沙克拉商人不因剧情推进而离开，始终停留在原位，可正常对话、购物。

Keeps all 14 Shakra (Mapper) merchants in their regions regardless of story progress. They stay in place and remain fully interactive for dialogue and shopping.

## 安装 / Installation

1. 将 `ShakaraAlwaysOnsite.dll` 放入 `BepInEx/plugins/` 目录。
2. 启动游戏，Mod 自动生效。

1. Place `ShakaraAlwaysOnsite.dll` into the `BepInEx/plugins/` folder.
2. Launch the game. The mod applies automatically.

## 使用 / Usage

无需任何设置，Mod 加载后自动生效。

No configuration required. The mod takes effect as soon as it loads.

## 卸载 / Uninstall

删除 `BepInEx/plugins/ShakaraAlwaysOnsite.dll` 即可。

Delete `BepInEx/plugins/ShakaraAlwaysOnsite.dll` to uninstall.
