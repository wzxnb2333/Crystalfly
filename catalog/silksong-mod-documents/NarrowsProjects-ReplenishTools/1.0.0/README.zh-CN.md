# 随时间恢复工具  
此模组改变了红色工具的处理方式。  
大黄蜂将不再需要坐在长椅上，而是会随时间自动恢复她的红色工具。

## 详细说明  
- 工具在长椅上会随时间逐渐恢复  
- 恢复速度基于当前红色工具的容量  
  - 工具袋可提升容量，从而加快恢复速度  
  - 当容量满时，直针每 7.5 秒恢复一个针  
- 击中敌人会使恢复速度在 1.5 秒内翻倍  
  - 若在增益效果结束前再次击中敌人，则恢复加速效果会重置  
- 等离子药瓶与跳蚤酒在未处于长椅时不会消耗等离子或跳蚤酒  
  - 这完全是意外设计，但频繁重新填充会带来烦人的游戏机制，因此我决定保留该设定  
- 工具袋的容量已减半，并根据需要向上取整

## 安装说明  
1) 从 ThunderStore 下载一个预配置的模组加载器：https://thunderstore.io/c/hollow-knight-silksong/p/BepInEx/BepInExPack_Silksong/  
2) 找到你的丝之歌安装文件夹：  
   1) 在 Steam 中：右键点击“丝之歌” -> 属性 -> 已安装文件 -> 浏览  
3) 将 BepInEx 的 zip 文件内容提取到该文件夹中。  
4) 启动并关闭游戏一次  
   1) 这能让 BepInEx 生成它需要插入模组/插件的一些文件  
5) 下载 `ReplenishTools.zip` 文件  
6) 将 zip 文件提取到 `<Your Silksong Folder>/BepInEx/plugins`  
7) 启动游戏
