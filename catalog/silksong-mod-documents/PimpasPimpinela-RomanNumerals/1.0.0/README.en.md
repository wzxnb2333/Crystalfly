This is a Hollow Knight: Silksong mod that causes all numbers in the game to be displayed using the [Roman numeral system][rn]. Values above 3999 are rendered using the
_apostrophus_ convention, rendered with parenthesis (so 4000 is `(IV)`), due to
technical limitations of the font used in the game.

The mod can be toggled in the main Mods menu in-game once installed.

[rn]: https://en.wikipedia.org/wiki/Roman_numerals
