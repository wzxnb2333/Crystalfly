**新炸弹**  
- 一个炸弹会落在舞台区域。  
- Trobbio 和大黄蜂均可触发该炸弹。  
- 被触发时，会产生多个炸弹的爆炸（我相信你一定能从丝之歌中认出这种爆炸效果）。  
- 若由大黄蜂使用下劈动作触发，则每个爆炸中的炸弹会对 Trobbio 造成伤害。  
- 伤害值取决于钉子强度。
