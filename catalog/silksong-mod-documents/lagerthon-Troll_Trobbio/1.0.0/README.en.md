**NEW BOMB**
- A bomb drops on the stage.
- Both Trobbio and Hornet can trigger this bomb.
- When triggered, a burst of multiple bombs is created (I'm sure you can recognize the burst from somewhere in Silksong).
- Each bomb in the burst deals damage to Trobbio if Hornet triggers it with a downslash.
- Damage depends on nail strength.
