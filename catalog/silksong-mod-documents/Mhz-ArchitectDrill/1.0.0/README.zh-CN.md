# ArchitectDrill 模组

将建筑师的下击攻击替换为掘者钻孔效果。无限钻探，按需激活。

## ⚠️ 下击攻击功能丢失

- **格挡系统**：下击攻击时不会触发反击
- **能量恢复**：下击攻击命中不会获得能量回复

## 🎮 使用方法

- “掘矿者钻头”物品会无论装备状态如何被消耗，但向下攻击在耗尽后仍会持续生效  
- 在空中激活向下钻探时，按住工具键（F/RB）可连续向下钻探  
- 向下钻探仍支持平台挑战  
- 与原版一样，支持注入效果（FlintSlate 火焰/Pollip 垫毒）

## 安装

1. 安装 BepInEx  
2. 将 dll 文件放入 `BepInEx/plugins/`  
3. 在配置文件中设置 `EnableArchitectDrill = true`

# 建筑师掘洞钻MOD

将建筑师向下攻击替换为掘洞钻效果。无限钻取，随时启动。

## ⚠️ 下劈功能损失

- **拼刀系统**: 下劈时无法进行反击格挡
- **能量回复**: 下劈击中敌人不再回复绸线能量

## 🎮 使用说明

- 无论是否装备，掘洞钻道具都会被消耗，但道具用完后下劈效果仍可使用  
- 在空中触发下劈后，按住道具键（键盘F键/手柄RB键）可持续向下钻取  
- 下劈变为下钻，仍支持跳跳乐  
- 与原版一样，支持燧石板增强效果（火焰/毒素）

## 安装方法

1. 安装 BepInEx  
2. 将 dll 文件放入 `BepInEx/plugins/` 文件夹  
3. 在配置文件中设置 `EnableArchitectDrill = true`
