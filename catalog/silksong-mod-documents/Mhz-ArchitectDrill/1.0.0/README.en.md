# ArchitectDrill MOD

Replaces Architect's downward attack with Delver's Drill effect. Unlimited drilling, activates on demand.

## ⚠️ Downward Attack Function Loss

- **Parry System**: No counter-attacks when downward attacking
- **Energy Recovery**: No energy gain from downward attack hits

## 🎮 Usage

- The Delver's Drill item will be consumed regardless of equipment status, but downward attack continues working even after depletion
- After activating downward drill in mid-air, hold the tool key (F/RB) to drill downward continuously
- Downward drilling still supports platforming challenges
- Like the original, supports infusion effects (FlintSlate fire/Pollip Pouch poison)

## Installation

1. Install BepInEx
2. Put dll in `BepInEx/plugins/`
3. Set `EnableArchitectDrill = true` in config file

# 建筑师掘洞钻MOD

将建筑师向下攻击替换为掘洞钻效果。无限钻取，随时启动。

## ⚠️ 下劈功能损失

- **拼刀系统**: 下劈时无法进行反击格挡
- **能量回复**: 下劈击中敌人不再回复绸线能量

## 🎮 使用说明

- 不管是否装备，掘洞钻道具都会被消耗，但道具用完后下劈效果仍然可用
- 在空中触发下劈后，按住道具键（键盘F键/手柄RB键）可一直向下钻取
- 下劈变成下钻，仍然支持跳跳乐
- 和原版一样，支持燧石板增强效果（火焰/毒素）

## 安装方法

1. 安装 BepInEx
2. 将dll文件放入 `BepInEx/plugins/` 文件夹
3. 在配置文件中设置 `EnableArchitectDrill = true`
