# 平衡调整

一个空洞骑士：丝之歌模组，用于根据 [Holland](https://www.youtube.com/channel/UCnVGHE75UsCcjCN2DlIOJLg) 的视频建议重新平衡大黄蜂。

Contributions and forks are welcome as long as they comply with the [license](./LICENSE).

## 安装  
### 简单方式  
1. 在你的模组加载器中选择一个配置文件 e.g。 [Cogfly](https://github.com/Nix-main/Cogfly) 或 [r2modman](https://github.com/ebkr/r2modmanPlus)  
2. 搜索此模组并点击安装  

### 手动安装  
0. 下载模组  
#### Cogfly  
1. 选择 `Profiles`  
2. 选择一个配置文件  
3. 点击 `Import Manually`  
4. 选择 `capitalists-Rebalance-<version>.zip`  

#### r2modman  
1. 选择 `Hollow Knight: Silksong`  
2. 选择一个配置文件  
3. 点击 `Settings`  
4. 点击 `Import local mod`  
5. 选择 `capitalists-Rebalance-<version>.zip`

## 编译
```bash
dotnet build
```

## 更新内容

### 刺爪

- 不再需要或消耗丝线

### 猎手

- 下击延迟减少
- 当猎手纹章完全进化时，受到伤害只会降低对应专注值的伤害次数 1（6 点）

### 工具

#### 贝壳碎片吊坠

- 大多数首领死亡时会掉落（100）贝壳碎片（可能需要测试）

#### 重物腰带

- 已移除攻击后坐力

#### 纯净花环

- 现在为黄色
- 持续时间无限

#### 小偷印记

- 每种念珠类型的掉落概率提升（+ 16.6...%）
- 丢失概率固定为 2%
- 丢失上限固定为 10 个念珠

#### 熔岩铃铛

- 现在为黄色

#### 死虫的钱袋

- 蜕皮时会返还所有丢失的念珠

#### 磁铁胸针

- 也会吸引贝壳碎片
- 退出场景时收集
- ~~防止掉落物被尖刺破坏，并提前吸引~~（在此功能上存在困难）

#### 丝速踝带

- 不再需要或消耗丝线

#### 降临之握

- 在墙壁上使用时增加攻击范围

### 跳跃护腕

- 使大黄蜂无敌，而非依赖攻击类型进行回避

### 神秘之眼/神秘之眼（复数）

- 也适用于敌人被击杀时
- 每击杀一个敌人获得 3（神秘之眼）或 4（神秘之眼）片状苔藓

### 防护铃铛

- 爆发时返还 6 丝线

### 蜗牛袋

**燧石板协同**

- 攻击造成的伤害与普通燧石板相同（1.5x 而非 1.3x）

**等离子药瓶协同**

- 紫色护罩不再有固定过期时间
- 由于过期时间已取消，等离子中毒现在成为可能（行为与普通等离子中毒相同，无额外特殊效果）
- 拥有紫色护罩时进行针刺攻击，会施加毒液（与燧石板协同类似，但使用默认针刺伤害）

### 锯齿头环

- 伤害量减半（不会减少头环与物体碰撞时的体积）
- 不再与反弹弹（猎手之歌红豌豆、壳林白花等）发生碰撞

### 破碎面具

- 绑定后恢复

### 多重绑定器

- 绑定时间减少

### 注射带

- 绑定时间进一步减少
- 现在也适用于建筑师的制作绑定

### 绞盘延长器

- 任何进入绞盘延长器的丝线都会完全填满延长器

### 预备绑定

- 使用延迟减少至几乎与普通绑定相同
- 在生命值满时绑定时自动恢复

### 刺爪镜/刺爪镜（复数）

- 伤害提升
- 在制作绑定和普通绑定时均触发

**仅刺爪镜**

- 伤害范围提升至与刺爪镜相近

### 记忆水晶

- 伤害提升
- 在执行针刺攻击时生成

### 间谍拾取器

- 不再从敌人掉落中获取念珠，而是生成新的念珠
- 额外击中造成的伤害与针刺伤害相同

### 电压丝线

- 伤害倍率现为 1.2x（原为 1.25x）

### 快速投掷器

- 当工具被复制时：
    - 仅消耗一个工具
    - 两个投掷工具造成的伤害为正常伤害的 70%
- 提升念珠炮和丝线投射（建筑师）的射击频率
- 减少未被复制工具的冷却时间
