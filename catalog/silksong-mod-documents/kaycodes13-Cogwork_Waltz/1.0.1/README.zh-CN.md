# 机械舞曲

一款《空洞骑士：丝之歌》模组，将机械舞者首领战中的音乐替换为 [Cogwork Waltz by Joe Zeng](https://youtu.be/ZbU_AZupH_w)，该版本对原曲进行了重新编排，以 3/8 拍速呈现。该模组在作者许可下制作。

特别感谢 [Fabulator_K](https://thunderstore.io/c/hollow-knight-silksong/p/Fabulator_K/) 录制了更自然的歌曲版本，该版本被用于本模组中。

## 安装

通过 r2modman 或 Thunderstore 模组管理器进行安装。Cogwork Waltz 的依赖项将自动安装。

对于手动安装，请解压 `.zip` 文件，并将其放入您 Silksong 安装目录的 `BepInEx/plugins` 文件夹中。此外，您还需要手动安装 [WavLib](https://thunderstore.io/c/hollow-knight-silksong/p/SFGrenade/WavLib/)。

## 关于游戏玩法的说明

本模组除了替换音乐外，还实现了一个修复，防止首领与音乐不同步。它不会以任何方式改变原本设定的移动速度，但如果出现延迟或游戏卡顿，首领将精确地在节拍上恢复移动，而不会像原版游戏那样被抛出节奏之外。

## 关于节奏与时机的次要说明

此次重新编排是为了可循环播放，并且（大部分）符合原音乐的节拍——这非常棒，也正是促使我制作这个模组的初衷。不过，有一些细节我想记录下来以供后人参考。

首领AI的瞄准和移动遵循特定的节奏。在每个阶段中，动作的时机分别设定为 1 秒、0.75 秒、0.75 秒 和 1.25 秒。由于首领移动的代码设计方式，首领会始终“缓慢”地与音乐脱节，但这正是设计者的意图。

然而，每个阶段中首领的预期节奏，并不总是与音乐节拍一致。

第 2 阶段是两者差异最明显的部分。该阶段音乐节拍为 75 bpm，而首领移动节拍为 80 bpm。Zeng 的重新编排保留了原音乐的节拍，我也不希望修改首领AI；因此，我略微加快了重新编排中第 2 阶段的节奏，使其与首领动作同步。

有趣的是，在原始曲目中，第 3 阶段音乐节拍与首领移动节拍之间的差异以一种具有节奏意义的方式错开。音乐节拍为 120 bpm，首领移动节拍为 80 bpm。虽然从技术上讲，首领并未完全与节拍同步，但其脱节的节奏产生了“4:3 多拍节奏”或“自然三连音感”，使首领动作与音乐节拍之间形成和谐的互动。然而，本次重新编排是为与首领动作同步而设计的。
