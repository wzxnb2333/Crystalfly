# MagnetiteBroochPlus

A Hollow Knight: Silksong plugin for BepInEx.  
When the **Magnetite Brooch** is equipped, Shell Shards will become attracted to players like the rosaries.

This is my first mod for a game so this was fun, I plan to make more but we all gotta start somewhere. Oh if there any bugs I'll patch it when I have time, but I did not notice any while testing! 

## How it works
- Detects when the Magnetite Brooch is equipped or unequipped.
- Activates/Deactivates the built-in rosary attraction effect globally for shell shards.
- Lightweight, no extra settings required.

## Installation
1. Install [BepInExPack for Silksong](https://thunderstore.io/c/hollowknight-silksong/p/BepInEx/BepInExPack/) via Thunderstore or manually.
2. Download the latest release of this mod from Thunderstore or download the DLL from my gitthub.
- **Option A (Thunderstore)**: Install directly via your mod manager.
- **Option B (Manual)**: Extract the `.zip` into your `BepInEx/plugins` folder.
3. Launch the game and enjoy!
