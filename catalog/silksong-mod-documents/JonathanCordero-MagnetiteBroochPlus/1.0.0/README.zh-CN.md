# MagnetiteBroochPlus

一个为《空洞骑士：丝之歌》设计的 BepInEx 模组。  
当装备了**磁铁胸针**时，贝壳碎片将像念珠一样被玩家吸引。

这是我第一次为游戏制作模组，所以这个过程很有趣，我计划继续开发更多模组，但大家总得从某处开始。如果发现任何错误，我会在有空的时候进行修复，但在测试过程中我没有发现任何问题！

## 它是如何工作的  
- 检测是否装备或卸下磁铁胸针。  
- 全局开启/关闭内置念珠对贝壳碎片的吸引效果。  
- 轻量级，无需额外设置。

## 安装  
1. 通过 Thunderstore 或手动安装 [BepInExPack for Silksong](https://thunderstore.io/c/hollowknight-silksong/p/BepInEx/BepInExPack/)。  
2. 从 Thunderstore 下载本模组的最新版本，或从我的 GitHub 下载 DLL 文件。  
- **选项 A（Thunderstore）**：通过你的模组管理器直接安装。  
- **选项 B（手动）**：将 `.zip` 提取到你的 `BepInEx/plugins` 文件夹中。  
3. 启动游戏并享受吧！
