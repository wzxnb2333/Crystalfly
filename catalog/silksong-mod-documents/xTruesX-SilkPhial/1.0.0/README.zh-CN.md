# Silk Phial

## 特性

• 功能与原版标准工具完全相同。

• 在正常情况下，每次使用都会获得 3 根丝线。

• 当装备了建筑师纹章时，每次获得的丝线会在 1 和 2 之间交替。这一调整确保该纹章上的工具与其他纹章相比不会过于强大。

## 已知问题

• 当前尚未实现使用动画。（因为我不具备实现该功能的能力）

• 本地化仅支持英文，因为该模组会强制使用其自定义的显示名称和描述，无论游戏内的语言设置如何。

## 注意事项

这是我首次在丝之歌和 Unity/BepInEx 中制作的模组，因此可能会存在一些错误（尽管不会太多）。如果想帮助我添加动画或改进代码（代码质量非常差，其中部分由AI生成），欢迎贡献。
