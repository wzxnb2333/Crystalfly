:: 必须的 ::

    BepInEx 5
    Patchwork

:: 包管理器安装 ::

应能无缝运行

:: 手动安装 ::

1. 下载 BepInEx 5，打开游戏文件夹并将 BepInEx 放置在根目录下，运行游戏一次，使其创建必要的文件夹。

2. 下载 Ashiepaws 的 Patchwork，将包含 Patchwork.dll 的 Patchwork 文件夹放入 BepInEx/plugins 中，再次运行游戏并让其创建相应的文件夹。

3. 将下载的 MJ_SR 文件夹放置在 HollowKnightSilksong/BepInEx/plugins/ 目录下。

4. 开始享受吧！
