:: MANUAL INSTALLATION ::

1. Download BepInEx 5, open game folder and place BepInEx at its root, run the game once and let it create the necessary folders.

2. Download Ashiepaws' Patchwork, place Patchwork folder containing Patchwork.dll in BepInEx/plugins, run the game once more and let it create its folders.

3. Place the downloaded MJ_SR folder inside HollowKnightSilksong/BepInEx/plugins/

4. Enjoy!
