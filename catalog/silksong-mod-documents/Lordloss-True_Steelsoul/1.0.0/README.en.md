# True Steelsoul mode

Have you ever found yourself playing Steelsoul mode and at the slightest inconvenience (*almost dying*) you pushed the pause button and returned to the main menu? Or hit Alt+F4 in sheer panic? With this mod such blasphemy can happen no more!

### Features
- Makes the **"Return to Menu"** button unusable while in battle
- Ends your Steelsoul run if you exit the game during battle (e.g. via Alt+F4)
- Turns you into a true gamer who will never back down from a real challenge

You are considered to be in battle if you have taken damage in the past 10 seconds or have 3 or fewer masks remaining.


### Warning! This mod can end your Steelsoul run if you ignore the rules!
