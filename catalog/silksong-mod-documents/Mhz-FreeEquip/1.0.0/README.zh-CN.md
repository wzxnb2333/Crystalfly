# FreeEquip 模组

允许蓝色和黄色工具互换装备槽位。

## 🎮 使用方法

**自动装备模式**：选择任意蓝色或黄色工具并确认，该工具将自动装备到任一可用的蓝/黄槽位，打破原有的颜色限制。

> 当所有槽位已满时，会替换第一个已装备的工具。<br>  
> 支持使用升级后的额外槽位。

**手动槽位选择**：先选择一个槽位，再从可选工具中挑选——这仍然遵循原有同色工具才能共存的限制。

## 安装

1. 安装 BepInEx  
2. 将 `FreeEquip.dll` 放入 `BepInEx/plugins/` 文件夹  
3. 启动游戏

# 自由装备MOD

允许蓝色和黄色工具互换装备至对方的插槽中。

## 🎮 使用说明

**自动装备模式**：选择蓝色或黄色工具并确认 - 会自动装备到任意可用的蓝色/黄色槽位，突破原版同色限制。

>槽位已满时替换第一个已装备的工具。<br>
>支持升级获得的额外槽位。

**手动选择槽位**：先选择槽位再确认 - 此时仍遵循原版限制，只能从同色工具中选择。

## 安装方法

1. 安装 BepInEx
2. 将 `FreeEquip.dll` 放入 `BepInEx/plugins/` 文件夹
3. 启动游戏
