# FreeEquip MOD

Allows blue and yellow tools to be equipped in each other's slots.

## 🎮 Usage

**Auto-equip mode**: Select any blue or yellow tool and confirm - it will automatically equip to any available blue/yellow slot, breaking the original color restriction.

> When all slots are occupied, replaces the first equipped tool.<br>
> Works with upgraded extra slots.

**Manual slot selection**: Select a slot first, then choose from available tools - this still follows the original restriction of same-color tools only.

## Installation

1. Install BepInEx
2. Put `FreeEquip.dll` in `BepInEx/plugins/` folder
3. Start the game

# 自由装备MOD

允许蓝色和黄色工具互相装备到对方的槽位。

## 🎮 使用说明

**自动装备模式**：选择蓝色或黄色工具并确认 - 会自动装备到任意可用的蓝色/黄色槽位，突破原版同色限制。

>槽位已满时替换第一个已装备的工具。<br>
>支持升级获得的额外槽位。

**手动选择槽位**：先选择槽位再确认 - 此时仍遵循原版限制，只能从同色工具中选择。

## 安装方法

1. 安装 BepInEx
2. 将 `FreeEquip.dll` 放入 `BepInEx/plugins/` 文件夹
3. 启动游戏
