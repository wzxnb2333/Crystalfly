# ⚔️ Damage Reduction
*This mod should fix the Problem of almost everything dealing double damage. The Damage should now be set to 1 for most Enemies and Bosses.
*HOWEVER, you can still INCREASE the damage or set it to 0 by going into the BepInEx config folder and change the cfg of com.sky.silksong.damageoverride DamageValue = 1 to any number you like i guess.

---

## 🔧 Install
1. Download BepInEx
2. Drop the Files inside BepInExPack inside your exe, should be at steamapp/common/hollow knight silksong/
3. DOwnload this mod
4. Drop the mod inside the plugins folder inside the BepInEx Folder inside your exe folder. So inside steamapps\common\Hollow Knight Silksong\BepInEx\plugins
5. Done
