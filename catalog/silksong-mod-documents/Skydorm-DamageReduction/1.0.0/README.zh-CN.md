# ⚔️ 伤害减免  
*本模组应解决几乎所有攻击造成双倍伤害的问题。目前大多数敌人和首领的伤害值已设置为 1。  
*然而，你仍然可以增加伤害或将其设为 0，方法是进入 BepInEx 配置文件夹，并修改 com.sky.silksong.damageoverride 的 cfg 文件中 DamageValue = 1 这一行，将其数值改为你喜欢的任何数字。

## 🔧 安装  
1. 下载 BepInEx  
2. 将文件放入你的可执行文件中的 BepInExPack 文件夹内，路径应为 steamapp/common/hollow knight silksong/  
3. DOwnload 此模组  
4. 将模组放入你可执行文件内的 BepInEx 文件夹下的 plugins 文件夹中。即：steamapps\common\Hollow Knight Silksong\BepInEx\plugins  
5. 完成

## 📒 注意

- 我仅在通常造成双倍伤害的环境中测试了此模组，大概是因为它们只是触发两次，所以我认为它们实际上只造成了 1，但我无法确定哪些物体仍然造成 2。
- 大多数首领现在应造成 1 伤害，而非 2。我曾用靠近要塞的首领进行测试，效果正常。
- 我会进行一次带有此模组激活的游玩体验，应该不会出现任何明显错误或问题。下载它，尝试一下，看看是否有效。
