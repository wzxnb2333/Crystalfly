# Crystalfly 1.1.0

## Steam 登录

- 新增**账号密码登录**，与扫码登录并列（下载页 Steam 账号卡片可切换）。
- Steam Guard 验证码（邮箱码 / 手机码）通过弹出对话框收集，验证码错误时给出提示并可重试；取消输入视为取消登录。
- 记住用户名与密码：登录成功后凭据以 DPAPI（当前用户）加密保存，重启自动预填。
- 退出账号时同步清除保存的密码凭据。

## 下载可靠性

- **CDN 内容服务器回退**：加速器/代理环境下 Steam 目录只返回 HTTP 节点时，自动回退使用 HTTP 内容服务器（HTTPS 仍优先），不再立即报 "Steam returned no suitable HTTPS content server"。
- 无法选择服务器时报错附带诊断统计（服务器总数 / HTTPS 数 / 代理数 / 应用 ID），便于排查网络问题。

## 网络健壮性

- GitHub 镜像池：多镜像弹性路由与延迟评估，主源不可用时自动回退镜像。
- 忽略不可用的系统代理结果；Steam 连接跟随系统代理。
- Steam CM 优先 HTTPS 端点；更新清单缺失时优雅降级而非中断。

## 界面

- 速通页底部切换条改为悬浮在内容区之上、锚定页面底部并水平居中。
- 启动时加载器漂移不再阻塞，可强制继续。

## 实例

- 游戏目录注册时自动创建 `.crystalfly` 根目录。
- 侧车元数据缺失时返回 null 而非抛错，避免相关操作中断。

## 稳定性与本地化

- 用户可见的异常消息本地化（跟随当前语言）。
- 本地代理工具目录加入 .gitignore。

本版本仅生成未签名本地 Windows x64 便携包和安装包，并创建 GitHub Release。
