# Crystalfly 1.0.0

## 架构：领域视图模型拆分

- 按业务领域将巨型 `MainViewModel` 拆分为独立领域视图模型：下载中心、模组管理、依赖图、设置、实例、协议服务。
- `MainWindow.axaml.cs` 后置瘦身（3032 → 约 780 行）：动画逻辑抽入 `MotionCoordinator`，事件处理器按区域分组。
- 建立领域视图模型拆分规范，依赖经 `XxxDependencies` 构造注入。

## 下载中心

- 队列批量操作：全部重试、全部暂停/恢复、全部取消、清除已完成。
- 每任务 ETA、下载总览（计数/总速度/汇总 ETA）、完成通知（仅当前会话任务）、错误分类与复制、耗时显示。

## 模组管理

- 文件冲突检测与标红；右侧详情面板（依赖/作者/健康/版本/readme/历史）；检查全部可更新。
- 依赖图缺失依赖修复引导；布局缓存与无变化跳过重建。

## 性能优化

- 模组健康检查哈希缓存 + 并行（重载实例约 10 倍提速）。
- 下载队列投影增量更新（无变化轮询通知量降约 25 倍）。
- 启动并行化：catalog/下载队列提前加载、实例 LocalLow 基线并行。
- 页面动画 vsync 对齐帧驱动。

## 本地化

- 修复语言切换后文案残留旧语言（Avalonia 索引器绑定通知修正 + 各领域系统性重算）。
- 英文查漏补缺：Mod/Loader 术语统一等 53 处修正。

## 界面与稳定性

- 主题色增强：进度条、滑块、开关、列表选中/悬停跟随主题色。
- 二级页面入场动画补全；窗口启动透明帧修复。
- 修复模组市场/游戏版本 section 被遮挡无法交互；整合包列表重复；Shift 范围多选触发区域；列表选中蓝条显示。
