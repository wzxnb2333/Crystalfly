# Crystalfly 0.6.5

## 中文 Mod 市场

- 使用 Crystalfly 独立维护的中文 Mod 名称、说明和标签替换旧表格译文。
- 当前目录与官方 HK ModLinks 的 652 个有效 Mod 一一对应，并保留英文回退与中文搜索。
- 移除 XLSX 导入脚本，新增只依据官方 ModLinks 校验 ID、Schema 和字段边界的维护脚本。

## Loader 与启动

- 修复仅存在 `Managed/Mods` 目录时被误判为同时安装 Modding API 与 BepInEx 的问题。
- 手动安装或外部管理的 BepInEx 可以正常识别；修改 Mod 贴图继续显示完整性警告，但允许强制启动。

## 整合包分享

- 客户端与分享链接改用 `https://crystalflyapi.jwst233.top/` 自定义生产域名。

## 兼容性

- 不修改设置 Schema、实例目录、LocalLow、快照、下载队列或缓存格式。
