# Crystalfly 1.2.0

## 多实例与存储

- 支持同时运行两款游戏，以及同一游戏的多个不同实例；运行期间仍可导航和切换实例。
- 游戏直接读写各自的实例存档，避免共用存档目录争用和退出回写覆盖；同一实例保留重复启动保护。
- 新增“创建共享实例”和“创建完整副本”。共享实例在本地 NTFS 上复用大型游戏资源，模组、程序集、配置和存档保持独立；不支持共享的位置自动完整复制。
- 已有实例可主动“节省空间”，也可转为独立副本；升级不会自动转换现有实例。使用外部工具直接修改游戏资源前，请先转为独立副本。
- 实例页展示来源关系、游戏版本和去重后的实际空间占用，新增多选删除，并保留删除确认、运行检查和共享资源回收保护。

## 模组与整合包

- 改善 Silksong 依赖解析，保留作者声明的版本约束及现有新版依赖处理方式。
- 模组市场优先显示缓存，增加缩略图复用和加载去重，减少等待与重复请求。
- 两款游戏的整合包均支持分享码、HTTPS 分享地址和 `crystalfly://` 链接导入；Silksong 新增生成分享，保留模组版本、启用和固定状态。
- 分享导入先展示安装计划，确认后才安装；修复首次加载模组目录时导入请求被忽略的问题。
- 分享服务已更新并接入新的免费存储；旧分享码不迁移。分享是一次导入，不会自动订阅或更新模组。

## 速通与界面

- 速通实例可绑定 LiveSplit 文件，游戏成功启动后打开对应计时配置；缺失文件或关联错误不会中断已启动的游戏。
- Silksong 新增独立的自定义练习环境，可保留已有模组并绑定 LiveSplit；HK 继续使用正式 RuntimePatches 模板与校验流程。
- 成绩动态用对应游戏标识和 WR、1st、2nd、3rd 角标表示成绩。
- 调整实例目录、操作按钮、下载目录选择和依赖画布的间距；依赖图多选操作栏出现时保持节点坐标和缩放不变。
- 增加页面、按钮、弹窗和依赖连线的连续动效，并响应减少或关闭动效的设置。
- 切换游戏时先显示现有实例缓存，后台重新检查；启动和修改仍依据当前文件状态。

## 升级提示

- 多实例隔离面向 Windows x64 和受支持的 Unity 路径查询方式；无法建立隔离时会阻止启动，不回退到共用存档。
- 共享资源实例不应交由旧版启动器直接修改；降级前先转为独立副本。
- 本版不包含游戏文件、存档或账号信息。
