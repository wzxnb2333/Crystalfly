# Crystalfly 0.7.1

## 外观定制

- 设置页支持全局自定义背景图片，并可调节背景透明度。
- 每个实例可以继承全局背景或使用独立背景，实例设置互不影响。
- 背景文件复制到应用数据目录管理，移除设置不会修改用户原始图片。

## 游戏目录

- 包含 0.7.0 的多游戏目录扫描、Steam 库发现、迁移和风险接管能力。
- 旧 `VersionRoot` 设置继续自动迁移，PNG、Mod 贴图和额外文件不参与默认启动阻断。

## 稳定性与存档

- 稳定实例选择后的页面切换，避免子页动画期间选中状态闪烁。
- 存档快照只创建和恢复四个存档槽及其备份，不再覆盖 Mod 全局设置或其他 LocalLow 数据。
- 旧快照仍完整校验，但恢复时只应用其中的存档文件。
- Mod 目录中的额外资源文件不再被识别成外部 Mod，也不再产生启动问题弹窗。

## 交付

- 版本提升到 `0.7.1`。
- 生成未签名本地便携包和 Inno Setup 安装包，不生成或提交更新签名私钥。
