# Crystalfly 1.1.6

## 多游戏与丝之歌

- 启动页通过小骑士／大黄蜂头像切换《空洞骑士》与《空洞骑士：丝之歌》，两款游戏分别保存版本库、实例、搜索和筛选状态。
- 丝之歌接入 Thunderstore 模组市场：浏览、搜索、分类排序、依赖预览、安装与更新、降级、版本锁定、修复和卸载。
- 丝之歌存档支持账号子目录与 `default` 各自的四槽编辑、导入导出、命名快照和恢复；修正真实存档路径为 `Team Cherry/Hollow Knight Silksong`。
- 未收录的 BepInEx 构建标记为“兼容性尚未验证”，不再直接判定为不支持。

## 错误报告与诊断

- 配置了接收地址的官方构建默认开启脱敏错误报告，可在 **设置 → 常规** 关闭，关闭状态随设置保存。
- 报告只包含应用版本、系统、操作分类与时间；明确排除用户名、计算机名、存档内容、Steam 账号和令牌。
- 新增 `Crystalfly.Diagnostics.Probe` 诊断工程，源码与 Fork 构建仍只保留本地报告。

## 下载与界面

- 下载页增加丝之歌动态最新版入口与固定版本 `1.0.30000`、`1.0.29980`，失败摘要默认折叠原始错误。
- 市场详情进入／返回、封面加载和下载阶段增加短过渡，并遵循减少或关闭动效设置。
- 启动页卡片统一 16 DIP 内边距与间距，窄窗口下社区卡片跟随主卡片宽度，不再截断实例状态。

## 测试

- 精简重复测试用例，执行用例减少约 20%，行与分支覆盖率下降控制在 2 个百分点以内。
- 移除已由新 UI 与更新流程测试覆盖的旧结构测试。
