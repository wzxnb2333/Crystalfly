# Crystalfly 1.1.8

## 模组管理

- 重做 Hollow Knight 依赖图，补全依赖关系，详情改为画布内浮窗，并支持自由拖动到负坐标。
- Hollow Knight 与 Silksong 的依赖图支持 Ctrl/Shift 点击多选、Shift 拖动框选、整组拖动、Ctrl+A 全选和 Esc 清空，选中模组可批量启停、更新和卸载。
- 补齐 Silksong 已安装模组的状态筛选、批量操作、依赖详情、文件检查和目录入口。
- Silksong 模组列表移除复选框，增加缩略图、图标缓存与缺图占位。

## 界面与体验

- 精简多个页面的重复简介，统一按钮间距、对齐和辅助操作图标。
- 改善浅色主题的文字、边框和依赖连线对比度。
- 调整存档编辑、整合包、下载、网络测试及外观设置的布局。
- 实例设置的所有子页面禁用 Shift+Tab 游戏切换，避免编辑时切换游戏；其他页面保留快捷键。
- 通知弹窗下移到顶部导航下方，避免遮挡页面切换按钮。
- 顶部导航增加选中背景横向滑动动画，并遵循减少动画与关闭动画设置。

## 修复

- 修复 Pale Court 等大型模组因下载包大小限制而安装失败的问题，保留下载上限、哈希校验和解压路径保护。
- 不再因尚未核验加载器兼容性而阻止启动或弹出警告。
- 移除游戏目录前显示明确的危险操作确认。
- 修复窗口关闭时通知卡片清理可能导致的界面异常。
