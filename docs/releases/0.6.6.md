# Crystalfly 0.6.6

## Steam 历史版本下载

- “下载 → 游戏版本”支持搜索版本号、构建 ID 与 Steam Manifest ID。
- 新增“其他历史版本”入口，可输入任意非零《空洞骑士》Windows Depot Manifest ID，并加入现有下载队列。
- 已被远程目录验证的 Manifest 使用正式构建身份；未知 Manifest 使用 `steam-manifest-<id>`，仅允许原版启动。
- 远程目录后续收录相同 Manifest 时，实例扫描会校验文件指纹，匹配后原子升级为正式构建身份。

## Steam 账号与队列

- 保留 SteamKit2 扫码登录与 DPAPI 加密令牌恢复。
- 退出 Steam 时暂停进行中的 Steam 下载并保留队列；重新扫码登录后自动继续。
- 下载结果的 AppID、Depot ID、Manifest ID 与暂存目录必须全部匹配，失败或取消不会发布可启动实例。

## 兼容性

- 不修改设置 Schema、下载队列 JSON、实例目录、LocalLow、快照或缓存格式。
- 未验证历史版本不能安装 Loader、Mod 或整合包，也不能进入速通验证流程。
