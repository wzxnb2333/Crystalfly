# Crystalfly 0.9.1

## 速通赛况工作台

- 速通页增加“环境 / 赛况”切换，不改变现有 RuntimePatches 环境管理。
- 按需检查 Hollow Knight 与 Silksong 的整局、单关和子分类官方榜单，只展示新验证的世界纪录与前三成绩。
- 首次使用仅建立基线；后续动态跨重启保留最近 100 条，并逐条显示应用内提醒。
- 结果按游戏、分类和请求类型分离缓存，15 分钟有效；离线或网络失败时回退到本地缓存。
- 刷新支持取消和快速切换淘汰旧请求；外链仅允许 `speedrun.com` 官方成绩地址。
- 关于页补充 Speedrun.com 数据来源说明。

本版本仅生成未签名本地 Windows x64 便携包和安装包，不创建公开 GitHub Release。
