# Crystalfly 0.7.0

## 游戏目录与实例发现

- “选择实例”升级为游戏目录与实例双栏工作区，支持登记多个目录，并继续以当前目录作为唯一活动 `VersionRoot`。
- 首次启动向导可发现 Steam 库或添加自选目录；扫描只检查目录自身与直接子目录，结果确认后才写入设置。
- 旧设置中的有效 `VersionRoot` 会自动登记为普通游戏目录，不打扰现有用户。
- 启动时先扫描活动目录，再在后台顺序刷新其他已登记目录；目录不可用时保留登记并显示状态。

## Steam 接管与迁移

- Steam 安装可迁移到非 Steam 游戏目录，或在明确确认风险后原地完整管理。
- 同卷迁移使用目录移动；跨卷迁移通过 `.crystalfly/staging` 复制、SHA-256 校验和安全发布。
- Steam 原地实例删除可只取消 Crystalfly 登记，也可经过危险确认永久删除目录。

## 完整性与兼容性

- 默认启动完整性仅检查游戏核心文件、Loader 必要文件及未完成事务或下载标记。
- PNG、Mod 贴图和其他额外文件不再参与默认阻断。
- 未知构建继续只允许 Vanilla；已知构建仍通过核心文件指纹识别。
