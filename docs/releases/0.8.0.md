# Crystalfly 0.8.0

## RuntimePatches 速通面板

- 速通页改为专用实例列表与配置详情双栏工作区。
- 从干净 Vanilla 实例创建完整副本，并安装固定的 AssemblyPatches v1.0.2。
- 支持 `1.2.2.1`、`1.4.3.2` 和 `1.5.78`，ZIP 与内部 DLL 均验证 SHA-256。
- 配置保存到实例隔离 LocalLow；所有功能默认关闭，并按版本禁用不可用项。
- 启动报告升级到 v2，技术错误阻止启动，分类规则警告仅提示。
- 旧速通模板保留文件但标记为过期，不再作为当前正式环境启动。

本版本仅生成未签名本地便携包和安装包，不创建公开 Release。
