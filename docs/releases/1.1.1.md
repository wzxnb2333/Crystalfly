# Crystalfly 1.1.1

## 新手引导

- 首次启动自动弹出 **8 步新手引导向导**：欢迎 → 导入游戏目录 → 选择实例 → 安装 Loader → 添加 Mod → 启动游戏 → 更多功能 → 准备就绪。
- 完成后不再自动弹出；**设置 → 常规** 新增"新手入门"卡片（可随时重开），设置 → 关于 也保留入口。

## 游戏目录扫描

- **全盘扫描**：点击"扫描游戏目录"除 Steam 库外，同时递归扫描所有本地磁盘，自动发现非 Steam 的 Hollow Knight 目录（跳过 CD-ROM/网络盘、符号链接、不完整目录）。
- **扫描进度**：扫描时按钮下方实时显示"已检查 N 个目录"。

## Mod 识别与接管

- 接管外部 Mod 后自动**匹配到 catalog 条目**（名称 + Loader 家族 + 版本），唯一匹配自动改写 receipt，歧义时弹窗让用户选择——依赖图与依赖解析随之正确。
- 点取消接管后，下次选中实例会**重新提示**（不再静默跳过）；已匹配的接管 Mod 也可随时重匹配。

## 其他

- Steam 下载快速"暂停→恢复"竞态修复（暂停与恢复串行完成）。
- Speedrun 后台刷新任务退出时等待完成，消除文件锁。

本版本仅生成未签名本地 Windows x64 便携包和安装包，并创建 GitHub Release。
