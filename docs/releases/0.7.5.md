# Crystalfly 0.7.5

## Loader 生命周期修复

- 修复 Loader 卸载在仍有 Mod 文件时先删除收据、随后报错并留下孤立 Loader 状态的问题；现在会在写盘前阻止操作。
- 修复 BepInEx 缓存、配置和日志残留被误判为仍安装 Loader 的问题。
- “修复”始终使用当前收据对应的精确 Loader，而不是下拉框中待切换的 Loader。
- 对旧版本造成的“Loader 收据缺失但受管 Mod 仍存在”状态，可从 Mod 收据推断精确 Loader 并恢复安装与收据。
- Loader 切换继续要求先卸载全部受管 Mod，避免跨 Loader 保留不兼容 Mod。

## 交付

- 版本提升到 `0.7.5`。
- 继续提供 Windows x64 本地未签名便携包和安装包，不创建公开 GitHub Release。
