# 多页面 UI 扫描与优化

2026-10-25。两个 Luna 6（max）子代理分别审查启动／实例／Mod 与速通／下载／设置；主代理核对方案后实施。

目标：减少泛化简介，统一对齐与间距，辅助动作按情况改为图标，关键操作保持清晰。

## 结论与实施方案

1. **优先保证操作可达。** 存档编辑原保存按钮位于 Y=735，超出 900×600 首屏；保存、重置移到列表上方。保留独立的编辑槽位和导入目标槽位，并分别命名。
2. **主次按钮分明。** 整合包的重新捕获、导出、分享、复制、删除使用 36px 图标、8px 间距；保存、应用、安装、创建环境、测速等主动作保留文字。图标保留本地化提示、无障碍名称、原命令与确认流程。
3. **减少固定说明。** 整合包、模组市场、速通动态等页面的泛化简介转为标题提示；删除整合包重复摘要；路径单行省略并保留完整提示。保留模组内容、错误、风险与完整隐私说明。
4. **修正排布。** 设置三个下拉框等宽；常用外观项前置；测速操作与结果分离，五项结果等宽；下载批量操作收进标题工具栏，空队列隐藏；速通按钮增加 4px 间距。
