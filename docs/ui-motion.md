# 全局动效：柔弹触感

用户于 2026-11-01 选择 B。正式界面复用 `MotionCoordinator`，保持现有布局，不改变命令执行时机。

## 节奏与覆盖

| 对象 | 反馈 | 覆盖 |
| --- | --- | --- |
| 页面、子页 | 300ms，Y 从 12 到 -1 再到 0；父子不叠加位移 | 启动、实例、管理、版本、市场、速通、成绩、设置；含 Silksong 加载器、整合包子页 |
| 按钮 | 80ms 按压、320ms 柔和回弹；小按钮 0.96、大按钮 0.99 | 通用按钮、目录操作、图工具条；键盘与鼠标共用按压状态 |
| 悬浮、选择、输入焦点 | 120ms 透明度、160ms 背景及描边过渡 | 列表、目录卡片、模组操作、依赖节点、输入框与下拉框 |
| 新列表条目 | 4px 短距进入，24ms 错峰，每批最多六个 | 实例、目录、模组、快照、整合包、LiveSplit 收藏和成绩动态 |
| 对话框 | 440ms 小幅位移，0.975 起始缩放并轻微回弹 | 通过公共弹窗宿主接入现有对话框 |
| 短暂状态 | 280ms 入场；状态文字变化才重播 | 通知、启动检查、错误提示、图内检查器、批量操作、成绩刷新状态 |
| 依赖连线 | 650ms 沿实际贝塞尔路径展开；打开或重进画布、关系更新时触发 | 两款游戏共用依赖画布；拖动、框选、缩放不增加延迟 |

顶部导航用 280ms 沿真实按钮尺寸滑动。入场曲线将主位移分散到更长时段，避免前 100ms 几乎走完。窗口标题栏和依赖节点不做按压缩放；开关沿用控件自带交互。菜单、Tooltip 和浮层关闭沿用原有控件行为。下载进度绑定真实值，不为动画修改任务进度或业务完成状态。

## 中断与性能边界

- 缓存条目始终可见，不先隐藏再播放入场。
- 系统禁用、减少或关闭动效立即停止空间动画并归位；减少档保留轻量颜色与淡入反馈。
- 页面没有缩放或倾斜。动画仅改变渲染变换，不改变布局尺寸。
- 动态控件卸载时解除事件与过渡；虚拟化复用不继承旧条目的动画。
- 已禁用模组的淡化样式独立于入场，不被归位覆盖。
- 隐藏页面的待执行动画在布局后清理，快速切页不遗留位移。

## 针对性验证

`PageTransitionMotionTests` 覆盖中断、偏好、首帧、嵌套页面、条目数量上限、键盘和卸载；`DependencyGraphViewInteractionTests` 覆盖开启与关闭动效时的多选拖动；`DependencyGraphViewRenderTests` 验证连线与选中样式。

可选 `DocumentationScreenshotTests.Soft_motion_reference_frames_use_native_pages_and_dialog` 使用隔离演示数据，从原生帧驱动导出 60fps 时间采样；设置 `CRYSTALFLY_MOTION_FRAMES` 指定输出目录。这验证关键帧与运动落点，不代表实机 GPU 帧率。未新增全量回归或 CI 任务。

## 帧调度

使用 Avalonia `RequestAnimationFrame`，不硬编码 60/144fps。项目锁定的 Avalonia 12.1.0 Windows 后端使用 SleepLoopRenderTimer，并把目标频率更新为当前会话检测到的最高显示刷新率（至少 60）。这是刷新率匹配的调度，不是每次回调与显示垂直同步信号严格同相的保证；UI 线程阻塞、显卡负载和显示后端回退仍可能掉帧。测试导出的 60fps 只是采样规格。

取消动画保留已排队的帧回调标记，防止重复回调链。静态目标启动时注册，动态目标在 Loaded 时注册，切页不再重复扫描整棵界面树；清理只遍历正在动画的目标。

连线是独立的绘制进度，不受页面／弹窗避免叠加位移的规则抑制。画布父级显隐单独监听，关闭、卸载、减少／关闭动效会复位并释放监听；拖动节点和选择不重播绘制。
