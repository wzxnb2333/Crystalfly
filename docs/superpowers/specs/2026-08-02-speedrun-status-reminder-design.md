# 速通校验提醒设计

## 目标

保留速通校验结果的持续提醒，但避免把完整报告路径放进顶部横幅。用户应能一眼知道环境需要复核、规则警告或被阻止，并能快速跳到速通页查看详情。

## 交互

- 顶部使用紧凑状态条，仅显示本地化的速通状态文本。
- 状态条只在需要验证、规则警告、校验失败或未验证报告存在时显示；完整校验通过且没有警告时不占用顶部空间。
- 点击“查看详情”跳转到速通页。
- 报告路径只在速通页详情区域显示，使用省略显示并提供打开报告、复制路径操作。
- 一般错误继续使用现有错误横幅，不与速通状态混用。

## 状态与数据

`MainViewModel` 保留 `SpeedrunStatus`，新增报告路径和提醒文本状态。校验结果写入报告文件后更新提醒；失败时错误文本只包含简短状态，报告路径保存在实例状态目录并可从详情操作。现有启动阻止和规则警告语义不变。

## 验证

覆盖成功带规则警告、完整通过、失败报告和切换速通实例四种状态，确认顶部不出现长路径，速通页仍可打开报告。执行 App 回归测试、Release 构建和 `git diff --check`。
