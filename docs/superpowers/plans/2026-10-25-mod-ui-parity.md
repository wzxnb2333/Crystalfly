# 模组界面统一实施计划

**目标：** 应用已确认的 HK / Silksong UI 审查建议，以丝之歌两行市场列表为基准，保留各自生态功能。

**设计依据：** `artifacts/ui-checks/game-ui-audit-2026-10-25/report.md` 及用户“应用建议”。沿用 Avalonia、现有样式和 Ursa OverlayDialog，不增加依赖，不改下载/依赖解析/安装事务和数据格式。

## 修改范围

- `CrystalflyTheme.axaml`：连续列表行、悬停/选中/焦点状态。
- `MainWindow.axaml`、`ThunderstoreView.axaml`：市场行、筛选/搜索、目标实例、详情、管理页和预设外观。
- `MainViewModel.Games.cs`、Thunderstore ViewModel：转发错误、结构化计划投影、清除筛选和当前目标。
- 沿用 `OverlayDialog` 增加丝之歌确认视图，保留兼容确认、取消、目标变化保护与错误重试。
- 本地化及现有 Headless 测试随修改更新；保留既有未提交改动。

## 执行顺序

- [x] 添加失败回归：列表悬停/选中、错误通知和确认取消/兼容保护。

- [x] 运行受影响定向测试，保存浅/深色、中/英、窄窗口截图并检查；不自动安装或全量回归。

## 检查重点

1. 鼠标及键盘状态有区分且不引起行位移。
2. 长名称、实例名与英文按钮不越界；长计划可滚动且操作可见。
3. 取消或切换上下文后不能执行旧计划；兼容性确认不可绕过。
4. 多个丝之歌视图共享同一模型时只弹出一个确认和一个通知。
5. 失败后保留计划可重试，隐藏页面不吞错误，HK 的批量/状态/依赖功能仍可使用。
