# 多页面 UI 精简与对齐实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. 主代理执行修改；两个 Luna 6（max）子代理只扫描并提出方案。

**Goal:** 减少重复简介与辅助按钮文字，统一间距，并保证存档保存操作首屏可见。

**Architecture:** 沿用 Avalonia/Semi/Ursa、Lucide 图标和现有 `cfp-icon`；以 XAML 排布调整为主，不改变操作命令、确认流程或数据处理。

**Tech Stack:** .NET 10、Avalonia、xUnit、Avalonia.Headless。

**Spec:** 用户本轮要求及 `docs/ui-scan-2026-10-25.md` 的截图审查结论。

## 约束与范围

- 保留工作区已有未提交修改；不生成安装包、不覆盖已安装版本。
- 图标按钮保留本地化提示和无障碍名称；应用、保存、安装、测速等关键操作保留文字。
- 保留导入目标槽位与当前编辑槽位、隐私披露、风险提示和所有确认逻辑。
- 使用本轮桌面截图与当前源码渲染截图；不以旧截图作结论。

- 900×600 英文长标题不得挤出保存或槽位选择控件。
